# Account workspace demo

Scope: standalone HTML prototype; Operate mode. No application, API, database or design-system changes. All values are illustrative and live only in this page.

## Direction contract

THESIS: One account context owns common creative rules and a subordinate series list. Replace the peer blueprint/series tabs and prominent directory panel with contextual navigation.

OWN-WORLD: Inherit DESIGN.md: cobalt rail, cool blue-gray canvas, white continuous editor, system Chinese typography, compact controls and restrained dividers.

STORY: Select an account, edit its common rules, inspect or override a series, and find the directory under account settings. Save scopes remain independent.

FIRST VIEWPORT: Existing global rail at left; page heading above one workspace. Its 220px local navigation contains account selection, common rules, series and settings. Right editor shows the selected account and content, with a scoped save bar below. No directory panel above the rules.

FORM: User-pinned structure from the preceding recommendation; code-led prototype. No concept tournament required for this specified layout; no seed generated. Signature interaction: toggling inheritance immediately reveals the editable series override while retaining the account reference.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
