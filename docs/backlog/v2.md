# v2 控制台体验与生产可观测性实施清单

本清单对应 `docs/specs/002-control-plane-ux-and-observability.md`。Ticket 在本地确认范围后，再同步到项目 Issue Tracker；每个远程 Issue 使用 `ready-for-agent` 标签。

## A：控制台基础体验

- [ ] T-201 调整导航顺序与 Owner 设置入口
  - 依赖：无
  - 验收：系列运营、生产单、审核、发布队列、复盘、账号按新顺序显示；收起侧栏时底部控件不溢出。
- [ ] T-202 为账号使用稳定身份色和缩写
  - 依赖：无
  - 验收：颜色与账号绑定，不因排序、筛选或分页变化。
- [ ] T-203 改造 Episode 详情为覆盖式抽屉
  - 依赖：T-201
  - 验收：点击遮罩、Escape 可关闭；点击另一条 Episode 可直接切换；内部独立滚动。
- [ ] T-204 重组 Episode 详情卡片与表单样式
  - 依赖：T-203
  - 验收：摘要、待办、预览、材料、审核包、Worker、产物、时间线和技术详情按分组展示；输入框和按钮尺寸统一。
- [ ] T-205 实现列表分页、折叠和归档筛选基础能力
  - 依赖：无
  - 验收：生产单、审核和运营明细不无限增长；归档数据默认隐藏但可筛选。
- [ ] T-206 增加审核和发布待办角标
  - 依赖：T-201
  - 验收：只统计需要 Owner 操作的项目；数量为零时隐藏角标。
- [ ] T-207 统一用户可见阶段名、时间线原因和表单文案为中文
  - 依赖：T-204
  - 验收：技术码、路径、哈希仍可在技术详情中查看。

## B：账号、蓝图与系列配置

- [ ] T-208 将蓝图编辑从原始 JSON 改为结构化表单
  - 依赖：无
  - 验收：定位、资产目录、审核流程、工具、预算、执行器和音频配置均有明确字段说明；保存直接更新当前蓝图规则；阻塞生产单可通过“修复并继续”同步当前规则。
- [ ] T-209 将系列规则从原始 JSON 改为结构化表单
  - 依赖：无
  - 验收：系列定位、格式、角色、地点、视觉、叙事和限制可编辑；高级规则保持兼容。
- [ ] T-210 实现账号硬约束、账号默认值和系列基线校验
  - 依赖：T-208、T-209
  - 验收：系列可覆盖账号默认值，不可覆盖账号硬约束；冲突在保存前给出解释。
- [ ] T-211 固化分层 Prompt 上下文
  - 依赖：T-210
  - 验收：任务快照记录蓝图版本、系列版本、上下文版本和哈希；脚本、视觉、分镜、媒体任务按能力获取相关上下文。

- [ ] T-226 建立外部连接管理与蓝图能力绑定
  - 依赖：T-208、T-222
  - 验收：独立连接管理页支持 Provider/API Key/Endpoint 的安全录入、编辑、删除和连接测试；连接作为全局连接池管理，同一生产能力可保存多个连接，但每个蓝图每项能力选择一个当前连接；蓝图只选择连接并按具体工具声明允许的 MCP 能力，不保存密钥；生产前只检查已启用能力当前选中的连接；当前阶段继续兼容 Worker 环境变量配置。

## C：Episode 生命周期与阻塞处理

- [ ] T-212 支持 Episode 重命名
  - 依赖：无
  - 验收：只修改管理标题，不改变已固定材料、蓝图、系列或任务上下文。
- [ ] T-213 支持 Episode 归档
  - 依赖：T-205
  - 验收：归档不删除数据和本地产物；默认列表隐藏；审计记录保留。
- [ ] T-214 实现 Owner 永久删除测试 Episode
  - 依赖：T-213
  - 验收：二次确认、显示本地路径、清理本地 Episode 目录、任务、产物索引和审计记录，并返回清理结果。
- [ ] T-215 重写 Worker 阻塞项为可执行说明
  - 依赖：T-208、T-211
  - 验收：每个阻塞项显示发生了什么、原因、解决步骤、是否可重试和技术详情。

## D：发布队列与发布记录

- [ ] T-216 建立发布记录数据模型与受控写入接口
  - 依赖：无
  - 验收：一个 Episode 可关联多条平台发布记录；记录平台、账号、URL、内容 ID、时间、状态和备注；历史记录不可被覆盖。
- [ ] T-217 将发布队列改为专用宽版发布弹窗
  - 依赖：T-216
  - 验收：展示视频、封面、发布包、校验、路径和发布信息；不复用通用 Episode 抽屉。
- [ ] T-218 实现人工发布确认和队列反馈
  - 依赖：T-217
  - 验收：Owner 手工发布后可记录平台信息；队列显示已发布、平台、时间和外部链接。
- [ ] T-219 预留自动发布适配器边界
  - 依赖：T-216、T-218
  - 验收：未来自动发布结果可写入同一发布记录模型；本批不操作第三方平台。

## E：Worker 与系统可观测性

- [ ] T-220 展示真实 Worker 任务状态和 Episode 任务进度
  - 依赖：T-211
  - 验收：显示排队、领取、执行、完成、失败、阻塞、尝试次数、时间和 `n/m` 进度；不显示未经证实的百分比。
- [ ] T-221 增加运行中 Episode 的自动刷新和完成通知
  - 依赖：T-220
  - 验收：打开详情时按固定间隔刷新；状态变化和阻塞有清晰提示；支持手动刷新。
- [ ] T-222 增加系统状态图标与详情面板
  - 依赖：T-220
  - 验收：悬停显示 Supabase、Worker、n8n、媒体库、依赖和阻塞摘要；点击打开详细状态。
- [ ] T-223 补充 n8n 编排状态和健康检查展示
  - 依赖：T-222
  - 验收：明确区分 n8n 编排、Worker 执行和控制台连接状态。

## F：复盘演示与验收

- [ ] T-224 创建隔离的复盘演示账号和两条 Episode
  - 依赖：无
  - 验收：一条可继续录入复盘，一条展示完成报告和蓝图建议；均有明确演示前缀。
