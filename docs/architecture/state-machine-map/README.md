# 状态机地图

直接打开 `index.html`，按三个权威分组探索 M01—M48，或选择生成、脚本、候选采用和交付场景。业务对象视图展示九种状态权威。节点详情包含状态、守卫及源码／测试入口。

事实数据在 `architecture-data.json`。修改数据后，从仓库根目录执行 `python3 docs/architecture/state-machine-map/build.py`，复用项目已有地图模板并对场景使用紧凑网格。HTML 可离线使用。

本轮检查范围与运行结果见 [核验记录](verification.md)。完整表格见 [状态机清单](../state-machines.md)。
