# 应用状态机清单

核查日期为 2026-11-11，本批比较基线为 `f7cc5190`。当前清单包含 48 个状态机族，覆盖应用、运行脚本、SQL、原生 Keychain 辅助程序及 Python 对齐入口。第三方 OpenChatCut 内部实现和真实供应商运行状态仍需单独验证。

[交互地图](state-machine-map/index.html) 按权威分层，包含完整清单及四条操作场景。[初轮报告](../verification/state-machines-20261111/REPORT.md) 记录扫描与刷新修复，[0—4 项报告](../verification/state-machines-0-4-20261111/REPORT.md) 记录后续实施与验证边界。

## 决定与使用方式

按状态的**权威归属**组织，保留现有模块。数据库约束管理持久业务事实；Worker 管理一次尝试；供应商记录管理是否已经发送；文件回执管理发布是否完成；UI owner 管理当前访问期间的意图。这些状态可以同时存在，不应合并成一个全局枚举。

初轮修改 M19，逐次调用确认改为类型联合和独立 owner，修复延迟回包跨工作版本污染。后续经批准实施 M22 的共享只读展示及 M18 的交付读取接入：音效未知提交摘要、口播输入与原任务状态差异、交付旧 revision 覆盖均有失败回归证据。决定见 [ADR-0034](../adr/0034-workspace-task-presentation-and-delivery-reading.md)，验收见 [第 1、2 项报告](../verification/state-machines-batch12-20261110/REPORT.md)。其他状态机继续保留各自权威。

第 3 项将 M13／M14／M27 的界面判断收拢到 [workspaceExportDeliveryState](../../src/workspaceExportDelivery.ts)，保留总览历史存在性、最新交付状态和过期导出下的历史下载；持久状态权威不变。决定见 [ADR-0035](../adr/0035-export-delivery-next-step.md)，验证见 [第 3 项报告](../verification/state-machines-batch3-20261110/REPORT.md)。

截至本轮，M17 的工作区操作已归 `useWorkspaceOperations`，M23 的脚本保存与启动已分步恢复，M24 的模型发现已隔离编辑基线，M26 的样音已按选择分配 owner，分别见 ADR-0036 至 ADR-0038。初轮修复 M18 初始／恢复刷新的接收顺序。0—4 项进一步收拢 M12 字幕分步恢复、M21 上传执行、M18 轮询可见性、M24 模型访问、M25 原生保存回执和 M31 偏好互斥，见 ADR-0039。

第 5—8 项补齐规划登记后的只读接续、隔离持久化验收、媒体根界面读取归属与上传放弃。第 9、10 项区分创建／生命周期／模型保存的成功回执与随后目录读取：已确认写入立即结束提交，后续失败仅重读；连接目录共享读取顺序、取消和访问归属，旧结果及旧错误不覆盖当前目录。见 [第 7、8 项](../verification/state-machines-78-20261111/REPORT.md) 和 [第 9、10 项规格](../verification/state-machines-910-20261111/SPEC.md)。

第 11、12 项将人工口播未完成登记按 Owner／生产单／工作区／镜头留在页面会话中，恢复只补未完成阶段；账号目录读／开／复制反馈属于当前账号访问，并提供原地重读。第 13 项复用真实 Owner HTTP、隔离 PostgreSQL／媒体卷验收迁移中重开、读取断连、切换失败后继续、完成及重启后的媒体指纹，不改变持久迁移协议。规格及边界见 [第 11—13 项](../verification/state-machines-111213-20261111/SPEC.md)。

开发者与 Agent 修改某条流程前，先找对应行的 owner，再读相关测试；改变持久状态时沿用最新迁移、事务和恢复协议。表中测试是已有验证入口，不代表本次运行了所有集成测试。`ready` 在任务中表示待执行，在导出中表示导出成功，不能跨上下文互换。

## 覆盖证据与限制

[候选扫描脚本](../verification/state-machines-20261110/census.mjs) 从 Git 跟踪清单读取 TypeScript/TSX、运行脚本与 SQL。它枚举 React state/ref、字面量联合、控制字段写入及 SQL 状态约束，初轮 [逐文件候选证据](../verification/state-machines-20261110/census.json) 与本轮 [扫描摘要](../verification/state-machines-20261111/census-summary.json) 分别保留基线。初轮信号按 44 个族归类。本轮同一脚本扫描 546 个文件，244 个文件含 1517 个候选信号；沿既有权威补核 M45—M48，并检查扫描器排除的原生工具、Python 对齐、UI primitives 与 `db/contracts`；DOM ref、静态选项和纯配置不自动视为状态机，叶子交互归入 M29/M30。SQL 原始迁移含历史定义，当前含义必须沿迁移顺序核对。

0—4 项实施后使用同一脚本扫描 548 个文件，246 个文件含 1525 个候选信号，见 [实施后扫描摘要](../verification/state-machines-0-4-20261111/census-summary.json)。保留初轮摘要用于比较，不因候选数量变化自动增加状态机族。

这份清单是源码审查结果，不是形式化完整性证明。闭包里的布尔值、跨进程故障与外部供应商行为不能仅靠静态扫描穷尽；生产库没有作为本次探测对象。已复现缺陷、结构性改进机会和未运行检查分别记录，不能把“能构造状态组合”直接当成线上缺陷。
