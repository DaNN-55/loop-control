# 从剪辑到下载视频

1. 在分镜台准备图片、视频、声音或字幕，点击“进入剪辑工作台”。也可以先进入剪辑，再按自己的想法调整。
2. 剪好后点击顶部“生成成片”。系统先保存，再生成视频并进入检查页。只打开检查页或刷新不会生成另一份视频。
3. 播放“成片预览”，看看画面、声音和字幕。满意后点一次“确认并完成”，等系统收尾结束后点“下载视频”。不满意就“返回剪辑”。

封面、标题、简介和标签都可以留空，不影响视频完成。技术检查没通过时，先按页面错误提示处理；检查明细和旧文件在“查看详情”。收尾失败点“重试完成”，沿用已经确认的视频。

## 想直接复制文案发布

在“发布资料（可选）”点击“AI 生成发布文案”，或“自己填写”。AI 一次给一套标题、简介和标签，直接编辑即可，内容会自动保存。需要特定口吻时展开“补充要求”，再生成；成功替换后可“撤回本次替换”。没有模型连接时仍可手写和下载视频。

分别点击“复制标题”“复制简介”“复制标签”，贴到发布平台。没有“复制全部”。视频已更新时，资料会保留，请核对它是否仍适用。

展开“封面（可选）”，可以选择已有图片、从实际成片选帧，或上传图片。选好即可使用；刷新后仍能恢复。完成后也能继续改资料，不必重新生成视频。

## 其他文件与完成作品修改

“更多下载”里有交付 ZIP、可编辑工程和已有封面。新 ZIP 使用最新已保存资料，视频仍是原先确认的那份；旧包保持原样。工程仍需要原素材，ZIP 不包含全部源素材。

打开已完成作品查看或选择片段，不会新建生产单。实际修改后点“保存为新生产单”，系统会保存完整副本并进入新单的剪辑台，原作品保持不变。此后普通保存更新同一个新单；可以返回分镜台继续改，再剪辑、生成和确认。
