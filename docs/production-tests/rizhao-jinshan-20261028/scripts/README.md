## 当前使用步骤

1. 在账号中保存创作规则并确认实际素材目录；Owner 的“连接配置”管理图片、视频、语音服务。模型、声音与参数在生产单制作时选择，不在蓝图中配置。
2. 每份脚本创建一条生产单，按下载模板核对解析结果和六个镜头，再明确确认主脚本。`a_roll`／`b_roll` 仅为旧格式来源标记，不限制当前制作来源。
3. 在“素材准备与匹配”中上传或生成首帧，核对产品和场景后采用；视频、TTS 每次提交核对当前连接、模型、输入与费用预留。候选生成完成后明确采用，改选模型不改写旧请求。
4. 按 [素材清单](ASSETS.md) 补齐 BGM、音效及封面，保留素材名与来源。缺失素材需实际补齐；不可把占位文件当作已确认产品素材。
5. 在剪辑工作台核对口播、时长、画面、字幕和声音，保存实际工程并导出；在检查与交付中确认实际导出文件及字幕，生成并校验交付包。

## v2 字段约定

主脚本结构固定为“标题 → 制作设置 → 正文段落 → 本期补充约束”。应用的“下载模板”使用同一份共享模板。

| 字段类别 | 填写方式 |
| --- | --- |
| 口播、画面提示、视频生成提示词、首帧要求 | 文本，可写长句；视频提示词最多 1500 字符，按原文提交 |
| 镜头类型 | `a_roll` / `b_roll` |
| 画幅 | `9:16` / `16:9` / `1:1`，全片设置 |
| 字幕正文模式 | `follow_tts` / `independent`；独立模式必须填写“字幕正文” |
| 字幕样式 | `minimal` / `cinematic`，全片设置；本批使用白字黑描边的 `minimal` |
| 字幕位置与安全区 | 固定位置枚举；`title-safe` / `action-safe` |
| 字幕行数、每行字数 | 1～2 行、1～24 字；本批 2 行、14 字 |
| 转场 | `cut` / `fade` / `studio`；`studio` 会等待人工编辑 |
| 构图 | `full` / `2up-horizontal` / `2up-vertical` / `pip` / `grid-4` |
| 首帧、背景音乐、音效、封面 | 素材名称，可带常见扩展名；不填写磁盘路径 |
| 音量、语速、音效起点及长度 | 数字；dB 范围 -60～12，语速 0.5～2 |
| 生成时长 | 2～15 的整数秒，或“默认”；默认按最终口播时长及现有模型下限选择 |
| 视频费用预留（分/镜头） | 已核定的整数分，或“默认”；用于单次制作请求的费用预留，不代表供应商账单 |
| 视频模型 | 填“默认”，在当前制作选择中核对实际模型，脚本不能指定密钥或绕过预算 |

“默认”是历史 v2 的继承标记；当前制作中核对实际选择，历史技术配置仅作初次预填。音乐、音效填“无”表示明确关闭。已保存的本次制作选择与人工修改具有实际效力，不会因重新读取脚本被覆盖。未知字段、重复字段、错误枚举和数字会报告具体行号，不会静默丢弃。

历史系列规则中的 `production_defaults` 曾统一设置 `voice`、`speakingRate`、`captionStyle`、`bgm`、`videoReservationCents` 等字段，仅用于旧格式兼容读取或初次预填，不是当前制作配置的权威来源。当前音色、模型、参数按本次制作选择保存并冻结；未配置音色或必要费用预留时，在本次提交入口补齐。音乐和音效仍来自上传素材，不经 Provider 生成。

本批统一竖版 9:16、旁白 0 dB、BGM -18 dB、音效 -24 dB、中等音乐闪避、硬切。原有 36 段提示词和口播均保留。每段对应稳定镜头编号；超出单镜头时长上限会提示拆分，不会截断口播或自动改写脚本。

## 修改与恢复

每次提交保存不可变执行快照；未知提交先恢复或核对供应商回执，避免重复计费。旧候选与已采用内容保持原身份。主脚本修订、候选替换、最终确认均通过当前显式操作完成；历史审批和工程继续可读。
