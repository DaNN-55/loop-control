## 使用步骤

1. 在账号与系列中确认视频执行配置、连接、旁白音色和语速。图片、配乐和音效采用外部上传路径。日常服务启用新版本前，需由现有迁移流程应用 `db/local/074-script-production-v2.sql`；本轮仅在隔离测试库应用。
2. 上传一份 v2 主脚本，再按素材清单上传图片、BGM、音效和封面。上传时保留与脚本相同的素材名称，选择对应用途。文件被系统规范重命名后，仍保留原上传名称用于检索。
3. 在生产单的“脚本制作计划”核对素材。唯一匹配可直接绑定；同名不同内容需要选择，缺失素材需要上传。可以先保存计划，再补齐素材。
4. 准备正式生产时，核对调用预算后点击“确认并启用审核后继续”，再确认主脚本并开始制作。当前六份文件没有填写新预算，不会替你决定充值或消费额度。
5. 到审核关卡时确认或修改；确认后由本机服务继续。修改制作计划前先暂停；已开始的任务仍按原有任务和预算处理，暂停只停止安排后续动作。

当前生产单的同名素材优先；跨生产单复用限定为当前账号、同一系列的已批准素材。保存时核验文件哈希，并导入本期不可变副本。归档和历史导入的生产单不参与新制作素材检索。封面可后补；缺少封面会停在发布包准备前。

## v2 字段约定

主脚本结构固定为“标题 → 制作设置 → 正文段落 → 本期补充约束”。应用的“下载模板”使用同一份共享模板。

| 字段类别 | 填写方式 |
| --- | --- |
| 口播、画面提示、视频生成提示词、首帧要求 | 文本，可写长句；视频提示词最多 1500 字符，按原文提交 |
| 镜头类型 | `a_roll` / `b_roll` |
| 画幅 | `9:16` / `16:9` / `1:1`，全片设置 |
| 字幕正文模式 | `follow_tts` / `independent`；独立模式必须填写“字幕正文” |
| 字幕样式 | `minimal` / `cinematic`，全片设置；本批使用白字黑描边的 `minimal` |
| 字幕位置与安全区 | 固定位置枚举；`title-safe` / `action-safe` |
| 字幕行数、每行字数 | 1～2 行、1～24 字；本批 2 行、14 字 |
| 转场 | `cut` / `fade` / `studio`；`studio` 会等待人工编辑 |
| 构图 | `full` / `2up-horizontal` / `2up-vertical` / `pip` / `grid-4` |
| 首帧、背景音乐、音效、封面 | 素材名称，可带常见扩展名；不填写磁盘路径 |
| 音量、语速、音效起点及长度 | 数字；dB 范围 -60～12，语速 0.5～2 |
| 生成时长 | 2～15 的整数秒，或“默认”；默认按最终口播时长及现有模型下限选择 |
| 视频费用预留（分/镜头） | 已核定的整数分，或“默认”；用于需手填费用预留的官方视频接口，不代表供应商账单 |
| 视频模型 | 填“默认”，使用生产单冻结的执行配置，脚本不能指定密钥或绕过预算 |

“默认”表示继承；音乐、音效填“无”表示明确关闭。优先采用本期已有人工修改，其次采用脚本明确值，再采用冻结系列默认值。未知字段、重复字段、错误枚举和数字会报告具体行号，不会静默丢弃。

系列规则中的 `production_defaults` 可统一设置 `voice`、`speakingRate`、`captionStyle`、`bgm`、`videoReservationCents` 等字段，使用同一套类型校验。未配置音色或必要费用预留时，续接会显示缺少项并等待。音乐和音效仍来自上传素材，不经 Provider 生成。

本批统一竖版 9:16、旁白 0 dB、BGM -18 dB、音效 -24 dB、中等音乐闪避、硬切。原有 36 段提示词和口播均保留。每段对应稳定镜头编号；超出单镜头时长上限会提示拆分，不会截断口播或自动改写脚本。

## 审核与修改

| 停止位置 | 需要确认的内容 | 确认后继续 |
| --- | --- | --- |
| 主脚本 / 开始制作 | 本期主脚本和输入 | 整理已上传视觉材料 |
| 视觉审核 | 产品、场景、首帧参考 | 按 v2 字段编排分镜 |
| 分镜审核 | 段落、提示词和镜头安排 | 应用设置，安排配音和视频任务 |
| 每镜音频正文核对 | 当前音轨、正文、对齐版本 | 生成同步预览 |
| 每镜同步预览确认 | 当前字幕、声音、画面和时长 | 全部确认后生成整片审核视频 |
| 整片 QC | 当前审核视频 | 最终成片及发布包准备 |

自动继续不包含审批、充值、发布或上架动作。缺失/歧义素材、预算未配置、执行失败、提交结果未知、过长口播、已有 Studio 工作版本冲突都会等待处理，不会反复创建付费任务。

本期分镜草稿、声音设置和 Studio 仍可编辑。已人工修改的镜头不被脚本初始化覆盖；编辑导致输入指纹变化时，沿用现有重新核对及预览确认规则。关掉浏览器不会撤销已经确认的本机续接授权；本机服务重启后读取持久化计划继续，点击“暂停自动继续”可撤销后续安排。
