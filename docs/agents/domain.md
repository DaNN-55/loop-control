# Domain Docs

This repository uses a single-context domain model.

Before exploring implementation, read:

- `CONTEXT.md`
- Relevant files under `docs/adr/`

Use the glossary vocabulary from `CONTEXT.md` in issue titles, specs, tests, and implementation discussions.

If an implementation appears to conflict with an ADR, surface the conflict instead of silently overriding it.

The domain documentation layout is:

- `CONTEXT.md` at the repository root
- `docs/adr/` for architectural decisions
