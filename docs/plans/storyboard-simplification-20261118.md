# 分镜台精简实施合同

## 范围与已确认决定

用户为有脚本、能判断结果但不懂模型或剪辑术语的人。分镜台准备可用画面和声音，剪辑台组织全片。保留实际创作自由，减少重复信息、中间操作和无意义的确认。

- 删除独立画面提示，输入框沿用已确认拍法；额外LLM补写仅明确请求，人工输入不自动覆盖。
- 保留切换候选预览/试听；选择预览不采用。无时长/字幕/其他片段影响时一次使用，存在影响时保留一次具体核对；后端版本、素材、权限、未知回执和费用校验不放宽。
- 图片可作最终画面，也可直接进入视频生成输入；参考图不算最终画面。候选本来保留，不另设“保留备用”用户操作。
- 允许模型在一条分镜内部生成切镜、运镜和不同景别，保留所选模型支持的单/多镜头设置；按整体候选管理，不自动拆行。
- 保留简单选用区间；短素材明确提示差额，不自动拉伸/循环/改变已有时长。仍可提前进入剪辑台处理。
- 主声音四选一：无主声音、视频原声、生成口播、上传口播。提取/登记是内部步骤，生成/上传后仍可试听选择；原声和口播精细混合由剪辑台承接。
- 制作设置为本期默认＋镜头覆盖，默认预填不提交；单镜改变不自动改本期默认或旧任务、结果。未启用能力不制造待办。
- 进度统一统计可剪辑镜头，列表一列准备情况给出缺项；就绪不代表人工质量验收。
- 字幕正常自动校时和应用；文字/时间直接修正不要求原因、不调用LLM、不强制重识别。模型失败允许人工完成；仅合法性检查不以模型置信度否决人工结果。
- 同版音频/镜头的人工修改不被晚到自动结果覆盖；新声音、时长变化需重新核对，旧结果保留。最终字幕随实际成片统一确认，不加逐镜头审批。
- 口播路线推荐先声音后画面，原声路线先视频，无声路线按脚本时长；不强制执行顺序。

## 实施步骤与验收

1. S1 准备情况：复用真实已采用源/主声/字幕证据计算，覆盖图片最终用途、仅参考图、关闭能力、失败/运行/未知、多个画面片段。表格和顶部使用同一结果；定向单测＋类型。
2. S2 素材选择：准备/应用协议继续独立校验，对用户合并无影响操作；生成图可直接作视频输入或显式替换最终画面，旧备用历史仍可读。覆盖预览不改工程、同长替换、时长变化确认、短视频提示；定向回归＋私有HTTP。
3. S3 主声与默认：统一入口，原声内部准备后显式/授权链路接入；旧工程/音轨保留；默认值跨刷新生效、镜头覆盖不污染其他镜头。定向回归＋私有HTTP。
4. S4 字幕：系统协同请求/轮询/应用，处理未知和失败，不盲重试；轻量人工编辑可从当前预览设置句子起止，失败无cues有待调整草稿。覆盖人工修改与晚到任务竞态、刷新恢复、版本变化、字幕错字不强制重跑、有效人工结果可导出。测试先RED后GREEN，关键边界用实际PG/HTTP。
5. S5 联合验收：正式业务只读保护；使用独立私有数据库与浏览器、可回收测试生产单和本地样本，脚本→准备/比较→主声/字幕→剪辑→导出/最终确认/交付完整路径。桌面及390px、键盘、刷新、失败后恢复。真实本地WhisperX及原生剪辑/导出按环境可用性实际运行，不以mock充当关键证据；付费调用只在确需验证实际Provider时明确限制为本轮小样本，不碰原生产单。发现bug复现修根因再跑。
