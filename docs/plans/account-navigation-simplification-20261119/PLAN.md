## 最终决定（实施合同）

### 日常导航和生产单
- 服务按需配置；账号页只管长期创作规则。合并工作台和生产单，默认生产单，旧 operations URL 兼容转入生产单并保留有效筛选。
- 顶部仅全局搜索、待处理、设置；齿轮直接打开设置。全局搜索跨生产单/账号/素材，列表搜索只筛选生产单，范围明确。
- 左侧保留账号展开列表及新建入口，不新增账号数据页。收起侧栏、系统状态保持底部工具。
- 生产单默认名称/账号系列、当前阶段、状态、最近更新和操作；花费/后台用时/生成次数由“显示统计”展开并记住选择。
- 默认状态标签、搜索、账号筛选；系列、阶段、归档、排序收进筛选。已用条件一直可见、可清除，默认最近更新。
- 列表右侧基础预览，桌面默认打开、可收起记忆；窄屏可关闭面板。点行空白预览，点名称进入制作，保留键盘操作。
- 预览为标题/账号系列、封面/已有视频、阶段状态、简短问题或下一步、单一进入制作/查看成果按钮；无画面展示已有脚本摘要，无脚本提示。点击播放、不自动生成或导出，来源标签不冒充实时未导出工程。
- 回收站迁入生产单入口，恢复/永久删除/容量清理规则不变。

### 账号规则
- 新建账号默认只填名称；稳定标识自动生成，默认上海时区；高级资料按需查看/调整，不破坏已有标识。
- 通用规则四类选填：内容定位（做什么给谁看）、说话方式、画面风格、内容禁区；已有额外/嵌套规则按需展开、无损保留。
- 系列为可选扩展，按需展开，优先显示系列自定义内容；完整生效规则按需查看。定位/画面风格覆盖与限制同时生效的现有语义不改。
- 普通保存取消二次确认，清楚提示只影响之后新建生产单；保存状态替代日常版本号，后台版本/冻结引用保留。
- 账号设置改更多操作：重命名、打开文件夹、查看资料、归档/恢复、删除；删除常驻刷新，错误重试保留。

### 设置和维护
- 5项主分组按序：制作服务、文件存储、界面与通知、登录与安全、维护工具（系统状态/日志/高级密钥）。标题简称设置。
- 删除自定义头像和显示名称功能，保留登录邮箱，外观/语言/行距保持；历史数据不批量清除。
- 通知默认接收渠道，事件分类收进自定义提醒；不重置旧选择，关闭通知不隐藏待处理事项。
- 左下状态快捷打开同一维护系统状态界面；后台任务、资源、运行版本只用同一展示，不保留另一份独立抽屉。
- 文件存储默认当前路径、打开文件夹、更换位置；更换后才展开选择/盘点/确认/迁移/恢复。日志目录移到日志维护。
- 删除连接即时搜索的重复提交、只读历史/无账务接口页无效保存按钮和重复打开入口；普通连接Key在对应服务管理，全局秘密库存仅维护区。
- 账号归档/删除、秘密查看权限/逐次验证、不可变连接版本、媒体目录身份/迁移恢复、未知请求不重发等既有保护不降低。

### 按需服务配置和首次使用
- 空工作区先必要的存储初始化，再创建内容账号/新建生产单；不强制填写规则、系列或全部连接。
- 制作服务同时涵盖生成与素材检索；实际检索、口播编辑/生成/试听仍在生产单。上传和本地剪辑不依赖无关服务。
- 保存并验证串联创建/换Key；验证失败保留保存结果和可修正提示，不悄悄重试/换连接。
- 默认使用已有适配模型范围，调整按需；不启用供应商全部模型、不重置现有选择；检索服务无模型必填。
- 从制作位置进入配置时保留原输入/镜头；“使用此服务并返回”明确回填所选连接/模型并刷新目录。生成仍由用户另点；旧失败/未知任务不自动重发。
- 普通验证“保存并验证”；豆包实际合成短句，按钮“保存并测试语音”，提示可能消耗额度，提供仅保存；验证不宣称所有模型可推理。

### 独立剪辑（覆盖早期移除决定）
