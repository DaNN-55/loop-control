# 检查与交付精简：验收清单

对应 [实施方案](PLAN.md)。日期：2026-11-19。状态：隔离实施与验收完成。逐项证据见 [验收报告](../../verification/delivery-simplification-20261119/REPORT.md)；日常服务／数据库未激活，硬件与供应商验证范围以报告为准。

每项记录“实际步骤、预期与实际、证据位置、已验证/未验证”。发现失败，按用户路径修复并重跑该项和受影响回归。不能仅凭按钮文案或 mock 判定文件/副本/模型能力通过。

## A. 零基础主流程

- [x] A01 从已有可剪辑素材进入剪辑台，完成修改；点击“生成成片”一次，实际保存后进入检查页并生成对应视频。保存失败不开始生成。
- [x] A02 从步骤栏进入检查页、刷新、离开再返回，均不自动渲染、不产生额外 AI 请求；进行中的原操作可以恢复查看。
- [x] A03 播放实际导出的 MP4，可查看画面、声音和字幕；不是工程实时预览或旧文件冒充本次成片。
- [x] A04 封面、标题、简介、标签全空且无大语言模型连接，也能“确认并完成”，完成后下载有效视频。
- [x] A05 只有一次人工“确认并完成”，系统自动收尾，不另要求“准备交付”“验证交付包”“采用文案”或填写完成理由。
- [x] A06 未观看满意可直接“返回剪辑”；仅查看/选择片段再返回不使视频失效，实际内容修改后显示需重新生成。
- [x] A07 技术检查失败、文件缺失、过期或必要字幕不合法时不能确认；就近显示具体原因和返回修改/恢复/重试入口。
- [x] A08 同一当前结果不重复显示“已交付/交付已完成/已确认/验证完成”等多层结论；历史事实和当前失败仍能在详情中分清。
- [x] A09 主下载为“下载视频”；ZIP、工程、已有封面进入“更多下载”，无不存在的产物链接；无“复制全部”。
- [x] A10 技术明细、文件信息与导出历史在“查看详情”可读，失败原因不被藏进必须先发现的折叠层。

## B. 确认、文件和恢复

- [x] B01 检查实际 MP4 的时长、画幅、音频、黑帧、代表帧和文件身份，保留现有有效保护；人工确认绑定该 MP4 与对应工程内容。
- [x] B02 导出后修改实际工程、替换文件或篡改 SHA/大小，旧确认不能通过，旧文件不能被包装为当前已确认结果。
- [x] B03 双击生成/确认、超时重试、刷新重入，不重复渲染、排队核心收尾或登记多次完成。
- [x] B04 人工确认成功但后台收尾失败：保留确认；重试继续原文件，不额外渲染、不另要求封面/标题、不替用户确认新文件。
- [x] B05 曾完成但文件后来缺失/损坏：不能只剩“需核验”死状态；恢复原文件后可重新校验，无法恢复时可通过新生产单副本重新制作并确认。
- [x] B06 历史包仍按 `publish-package/v2` 原合同验证/下载；旧包缺封面或 metadata 不能因新规则而被假判有效。
- [x] B07 新核心清单无封面/文案也有效，包含视频、对应工程、检查证据与身份清单；Worker 不重渲染已确认视频。
- [x] B08 历史成功和最新失败同时存在时，不将最新失败伪装成成功，不屏蔽仍有效历史文件的下载。
- [x] B09 检查视频、工程、ZIP 的真实字节和清单归属；工程下载提示仍需原素材，不声称 ZIP 是含全部源素材的完整备份。

## C. 发布资料、自动保存和复制

- [x] C01 “发布资料（可选）”紧凑可见；空白时可选 AI 生成或自己填写，有内容时可直接编辑和分别复制。
- [x] C02 视频确认前、完成后均可修改发布资料；不强制选平台、受众、语气或营销强度，无单独保存按钮。
- [x] C03 修改标题、简介、标签和补充要求后刷新、离开再回来，实际恢复最新已保存内容；切换生产单/Owner 不串草稿。
- [x] C04 封面保存的是可恢复的真实图片/来源身份；刷新后仍可预览和下载，不只恢复文件名后要求重新选图。
- [x] C05 模拟断网、服务失败、两个页面同时编辑及旧响应晚到；不丢最新内容、不覆盖他页新修订，保存失败明确显示。
- [x] C06 只更新发布资料不改变视频内容版本、确认或完成状态，也不创建新生产单；更新工程视频内容才走相应重新生成/副本路径。
- [x] C07 视频更新仍保留文案和封面，出现一次核对提示，不自动清空、标成已核对或请求 AI。
- [x] C08 分别复制标题、简介、标签，粘贴验证真实剪贴板内容；标签使用正确井号格式，无额外“复制全部”或复制格式设置。
- [x] C09 空值、长文、重复/超量标签等按合同处理；保留字段标签、错误和无障碍信息，不把字段校验变成视频完成门槛。
- [x] C10 完成后改文案/封面并自动保存：旧 ZIP/清单 SHA 不变，新下载包带新资料快照及同一已确认视频；保存失败不把未保存资料说成已包含。

## D. AI 文案

- [x] D01 只有明确点击生成/重新生成才发模型请求；打开页面、自动保存、生成视频、确认、刷新均不自动调用。
- [x] D02 一次返回一套可编辑标题、简介、标签，不展示多方案选择、采用、文案批准或新的必填配置。
- [x] D03 不填写补充要求也可生成；填写时确实进入本次固定输入，并结合账号/系列创作规则。
- [x] D04 用“三件商品脚本、实际工程删去一件”的案例，检查发送给模型的上下文排除已删内容，输出不宣传未保留商品。
- [x] D05 验证部分口播、裁切、变速、静音及关闭字幕的案例，不把完整源音频文字冒充实际完整台词；无法确认的内容不编造。
- [x] D06 无口播/字幕时仍能根据实际画面安排和已知规则起草；首版不暗中增加整段视频理解、ASR 或其他额外模型调用。
- [x] D07 默认沿用脚本页最近明确选过且可用的模型；可更换。没有可用模型时引导选择/配置，不静默换供应商，手填/复制/视频下载仍可用。
- [x] D08 手工改标题后，重新生成实际参考当前文案和补充要求；成功替换后可撤回到替换前的完整文案。
- [x] D09 模型拒绝、请求失败或结果格式不合法，保留旧文案、人工修改和封面，给出可操作错误，不误报生成成功。
- [x] D10 重复点击、超时未知、刷新恢复不产生重复请求；结果未知时先核对原请求，不自动重发。
- [x] D11 生成期间切换生产单、修改文案、改动工程或另一页面先保存，晚到结果不覆盖新内容或应用到错误作品。
- [x] D12 已完成原单也可使用文案 AI；不为绕过脚本页完成单写保护而解除原工程保护。
- [x] D13 至少一次真实已配置模型生成、一次按要求改写并核对结果和实际请求数；mock 仅用于错误/并发反例，不替代真实成功链。

## E. 封面

- [x] E01 已有封面一次选择即可使用，无“使用已选封面”的额外采用步骤；仍验证文件身份、真实图片和可读性。
- [x] E02 从实际成片指定位置选帧，核对图片来自该帧，刷新后仍可用；保存视频身份和时间位置，不是播放器界面截图。
- [x] E03 本地上传真实 JPG/PNG/WebP 成功；空文件、超限、伪造扩展名、损坏图片正确报错，当前有效封面不被误清空。
- [x] E04 取消选择、来源失效、视频更新或磁盘暂不可用时不丢已有封面；无法使用时可替换，且不阻挡视频完成。
- [x] E05 没有封面也可完成与下载视频；不新增 AI 制图、封面排版或方案审核入口。

## F. 完成单修改与生产单副本

- [x] F01 打开已完成原单、播放、选择片段、查看后退出，不创建正式生产单副本，不改原工程或完成状态。
- [x] F02 实际修改并首次保存：创建不同 Episode/workspace 的完整生产单副本，保存本次修改，列表可找到；不是只另存到 OpenChatCut 独立剪辑库。
- [x] F03 首次保存成功后保持在新副本的剪辑台，不自动跳交付、不自动渲染；原单标题/工程/视频/交付清单等指纹保持不变。
- [x] F04 新副本返回分镜台更换素材/口播/字幕，再进入剪辑台，所改内容和原时间线均保留，可以正常生成、确认、下载。
- [x] F05 新副本也可不回分镜，直接继续原生剪辑后生成成片，独立完成自己的确认和交付。
- [x] F06 副本继承原脚本、制作依据、创作基线、素材/采用关系、声音/字幕/时间线及发布资料；账号规则后来更新不悄悄改写副本的原创作基线。
- [x] F07 对比原生切镜、位置、裁切、变速、音量、字幕正文/时序/样式与来源映射；除本次明确修改外，其他内容一致。
- [x] F08 副本不继承原单的成片确认、已完成状态、交付回执、旧问题或可执行任务；不重新付费生成已采用素材，不复制凭据秘密。
- [x] F09 副本继续保存更新同一个新生产单，重复点击、未知回执和进程中断恢复不产生第二/第三张副本。
- [x] F10 首次保存失败时保留当前修改，原单不变；半成品复制可恢复或清理，不能在列表中伪装成可继续制作的完整副本。
- [x] F11 修改副本素材或工程不穿透原文件；按隔离夹具验证回收原单后副本仍能打开/导出。文件生命周期保护不能依赖日后不会清理测试单。
- [x] F12 原单旧视频仍可按原身份下载，副本新视频按新身份确认/下载；不能将原视频误显示为副本已经完成。
