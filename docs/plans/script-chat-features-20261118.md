# 脚本多会话与图片附件

## 已确认行为

新对话仅以当前原文与总时长为创作输入，保留系统约束和Owner当前模型／推理选择；不带旧消息、修改要求、候选分镜或图片。旧回执和人工编辑仍留在旧会话，编号可切回；空会话刷新后仍为空。原文／时长／基准变化继续切换相应范围，不能跨Owner或生产单混用。点击+、切换、上传均不调用模型、不采用、不制作。

编号条位于聊天输入框上方右侧，初始仅虚线方框+；已有或创建后显示1、2等编号，+常驻。单行约3–4格，更多项在区域内滚轮横移／触摸横滑，保留键盘操作及可辨当前项。

附件图标放在Brain推理入口左侧，支持本地选择、输入框拖图及已有本期素材选择。上传复用既有素材入库和不可变身份；待发送缩略图可移除，移除不删除素材。发送成功后清待发送项，已发图片仍是本会话后续上下文；新会话不自动带图，旧会话切回仍可恢复图引用。图片与原文冲突时提示，原文优先，不能借图或历史建议改写原文。

## 数据与接口边界

会话迁移211只加元数据；旧隐式链虚拟为列表项，不重写旧回执。新scope增加可选conversationId。conversations/newConversation负责列出／创建；conversation读取指定会话；Provider和manual回执绑定会话。去重命中先恢复，fresh dispatch和新建须检查全原文scope未决请求，不能换会话绕过unknown。

附件回执只保存材料ID／SHA／MIME／文件大小／名称等小引用，保持128KiB快照上限与旧无附件hash身份；实际派发前验证Owner／Episode／文件身份并读取为input_image。系统提示图片为参考数据，不扩大原文权限。型号逐项登记实际图像输入能力，不按前缀或供应商假定；不支持时阻止附图发送，保留草稿和已入库文件。

初步限额：每轮新增最多4张，PNG/JPEG/WebP，单张10MiB，会话累计最多16张、发送图片原始合计24MiB；前后端同检，超限明确报错，不静默丢旧图。避免DeepSeek 48MiB请求体和base64膨胀问题；保持原文件，不新增自动压图副本。

## 验证和交付

新功能各自定向测试，主agent组合验证：空会话刷新、切回历史、草稿隔离、scope错误、重复提交、unknown、人工修改／删除；图片选取／拖入／入库与复用、非法／超限／伪装文件、跨Owner材料、文件变动、失败重试、不支持型号、历史图延续和新会话不带图。使用私有PG／实际HTTP与真实浏览器，关键真实模型图像输入使用合成图片和既有已授权连接，回执核对真实型号／推理／usage，不启动制作。

正式业务旧单只读，新增验收单明确命名；不动既有素材／连接或旧对话。不保留大量原始产物，最终仅保留精简验收报告；必要截图供本轮界面验收，临时数据验收后清理。测试、构建、审查和真人操作通过后按功能提交，不推送。


## 用户后续确认与最终范围

附件扩展为图片和常用文档PDF、TXT、Markdown、CSV、JSON、DOCX；音视频留后续。最新批注保留小型弹层，仅一个上传槽，格式／大小短文放槽内，去掉素材选择列表；点槽调用系统文件窗口，槽位和聊天均支持拖入。文档上传即进入本期素材库，不能用作文档镜头拖放；通过文档过滤和受控下载查看原件。OpenAI支持的PDF走原生input_file，DeepSeekPDF不隐式启用额外付费解析；DOCX只提取有界文字、不读内嵌图片。实现和验收以两个REPORT及ADR72追加合同为准。
