# 蓝图配置完整性检查清单

## 目的

用于后续检查和补充账号蓝图配置。本清单以 MoneyPrinterTurbo 当前的短视频生成参数为参照，同时遵循本项目“蓝图声明”和“Worker 运行前置条件”分离的边界。

本清单只描述配置缺口，不代表这些字段已经实现，也不把 API Key、Worker 注册状态或真实模型权限写入蓝图。

## 当前已覆盖

- [x] A-roll、B-roll、旁白、配乐 / 音效四项生产能力开关
- [x] Provider、Adapter、模型、Prompt 版本
- [x] 能力级预算、尝试次数、并发数和供应商并发上限
- [x] 旁白语言、音色和语速
- [x] 资产目录、审批关卡和本地读写工具
- [x] Worker 注册、命令可用性、凭据存在性和媒体库的生产前检查

## 明确缺少的配置

### P0：补齐后才适合声明为可生产

#### 1. 外部连接与凭据引用

- [ ] 每个核心执行器和已启用生产能力选择一个 `credential_ref` / 外部连接引用
- [ ] 外部连接至少能表达 Provider、Adapter、Endpoint、模型和凭据状态
- [ ] 支持同一 Provider 下选择不同连接，而不是只填写 Provider 名称
- [ ] 蓝图和 Episode 配置快照只保存非秘密引用，不保存 API Key、Token 或密码

检查标准：蓝图能明确回答“这项能力使用哪个连接”，但不能从蓝图内容还原秘密。

#### 2. 网络权限

- [ ] 工具白名单支持 `network`
- [ ] 能力级配置能够表达 `network + write` 等实际所需权限
- [ ] Worker preflight 能区分“蓝图未声明网络权限”和“运行环境当前无法联网”
- [ ] 代理、TLS 和请求超时归入外部连接或 Worker 运行配置，不写入创作语义

当前已知问题：远程 Provider 需要 `network + write`，但蓝图表单目前只能选择 `read/write`，因此远程 B-roll、旁白和配乐能力无法完整声明其运行权限。

#### 3. 视频输出规格

- [ ] 画幅：`16:9`、`9:16`、`1:1`
- [ ] 输出分辨率
- [ ] 单个 B-roll 片段默认时长
- [ ] 片段播放速度
- [ ] 素材拼接模式：随机或顺序
- [ ] 转场模式：无、淡入淡出、滑入滑出、缩放等

检查标准：同一蓝图创建的 Episode 能得到稳定一致的输出画幅、素材切换节奏和转场规则。

#### 4. 字幕与音频混音

字幕：

- [ ] 字幕开关
- [ ] 字幕生成方式：TTS 时间戳或 Whisper
- [ ] 字幕位置和自定义位置
- [ ] 字体、字号、文字颜色
- [ ] 描边颜色、描边宽度
- [ ] 背景色、背景开关和圆角背景

音频：

- [ ] 旁白音量
- [ ] BGM / SFX 来源：随机、本地文件或指定供应商
- [ ] BGM / SFX 音量
- [ ] 音乐提示词或按分镜检索规则
- [ ] 旁白、BGM、SFX 的混音优先级和时长裁剪规则

检查标准：成片的字幕样式、旁白音量和背景音乐行为不依赖 Worker 内部默认值。

### P1：补齐后才能覆盖更完整的短视频生产场景

#### 5. 素材来源与检索策略

- [ ] 素材来源选择：Pexels、Pixabay、Coverr、本地素材或其他已注册来源
- [ ] 素材来源备用顺序
- [ ] 每个分镜的搜索词数量上限
- [ ] 是否按脚本叙事顺序匹配素材
- [ ] 是否允许指定本地素材覆盖在线检索
- [ ] 素材方向、分辨率和最小时长要求

检查标准：B-roll 配置能说明“去哪里找、找不到时怎么办、如何判断素材可用”。

#### 6. 脚本生成参数

- [ ] 默认视频语言
- [ ] 段落数量或目标时长
- [ ] 脚本生成提示词
- [ ] 自定义系统提示词
- [ ] 脚本候选数量或批量生成数量

Prompt 版本只标识提示词版本，不能替代语言、长度和候选数量等生产参数。

#### 7. 本地语音、字幕和渲染运行配置

- [ ] 字幕 Provider：Edge 或 Whisper
- [ ] Whisper 模型、设备和计算类型
- [ ] FFmpeg 路径或 Worker 命令引用
- [ ] 视频编码器
- [ ] 本地模型或字体资源的可用性检查

这些字段更适合 Worker 运行配置或外部连接配置；只有会改变账号默认产出的部分才进入蓝图。

## 不应写入蓝图的内容

以下内容是运行前置条件或环境事实，不是账号蓝图规则：

- API Key、Token、密码和代理认证信息
- Worker 是否已注册、实际运行在哪台机器上
- 当前网络是否可用
- Provider 是否接受本次请求
- 模型权限是否真的有效
- FFmpeg、Whisper、字体等本机依赖是否已安装
- 当前媒体目录是否挂载且可读写

蓝图可以保存非秘密的凭据引用、所需 Provider / Adapter、模型名称和工具权限；Worker 在生产前或执行阶段返回实际检查结果。

## 后续检查顺序

1. 先检查外部连接引用和 `network` 权限，否则远程能力无法可靠运行。
2. 再检查画幅、片段时长、字幕和音频混音，否则成片行为仍依赖默认值。
3. 再补素材来源策略和脚本生成参数。
4. 最后检查 Worker 的模型权限、网络连通性、本地依赖和媒体库状态。
