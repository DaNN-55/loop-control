# 制作声音使用观测 v1

日期：2026-11-14。状态：C2 声音切片已专项验收；同步导出活动／资源观测及完整 C2 尚未完成。依据 ADR-0069 与已批准实施规范。不应用日常迁移，不启用日常采集。

## 记录什么

以实际持久化的原生工程版本为依据，遍历当前活动时间线及其可达子序列窗口。配乐、音效、口播、提取原声、视频独立原声、环境声和其他音频分别保留用途；同一素材放置两次是两个使用实例，不是两次供应商生成。

准备／检索／导入尚未采用的素材不产生使用。实际采用为 `sound_used`，明确静音／隐藏／删除／替换后的旧来源为 `sound_withdrawn`，同来源的实际窗口、增益、关键帧、淡入淡出或混音变化为 `sound_changed`。原候选采用与声音使用是不同合同，不相加当使用总量。

只识别同一生产单的登记素材、音轨或任务产物，并核对路径与原生来源哈希。素材 ID 前缀只是定位线索，不作为已登记或归属的证明。同路径有多个来源且无明确身份时保留未知，不取第一条。内嵌视频音频额外核验实际文件指纹并通过本机探测确认音频流；没有音频流的视频不算声音使用。每次事务内按素材提示／路径／SHA缓存解析与探测；不同别名仍可能重复探测。实际音频流起止与源入点／速率映射共同限定叶窗口，不将裁到源结尾之后的片段算作使用。

## 可听性与未知

轨道静音和隐藏排除叶媒体及其子序列。音频／视频自身的音量关键帧覆盖静态音量；全零窗口不算可听，静态音量为零但关键帧有效也不能自动排除。父序列项的音量／淡入淡出不向子音频传播，以当前 SDK 实际渲染行为为准。

对子序列考虑源入点、有效窗口与原生末帧裁剪；SDK 当前拒绝父子 FPS 不同的序列，不能凭假设生成跨 FPS 兼容统计。对无法可靠解释的非单倍嵌套、超调曲线、转录剪辑、缺失或冲突的来源，记录 `sound_unresolved`，不计入已确认的使用／撤回／变化。未知不等于无声；同一实例从已知转未知、再恢复可解释状态，不因此虚构一次撤回和重新采用。

只读汇总 `detail.soundUse` 分别给出使用、撤回、变化、用途分类及 `unknownEvents`。这些是覆盖期内记录到的变化次数，不是当前活动音轨数量、独占使用时长或声音质量结论。原阶段、候选、请求和费用指标含义不变。

## 保护与保持

194 仅新增一个受控 SQL 统计函数，无新增表或回填。复用当前工作区 Owner／主脚本／历史／回收站栅栏和版本保护；Worker、其他 Owner 与普通直接私有写入不得越权。现有通用事件类型和 payload 白名单不扩大；新增入口只接受固定用途、动作、同单关系和哈希。事件不含正文、名称、路径或秘密。

工程版本和事件同事务持久化，注入统计写入失败不得留下虚假的采用成功。关闭采集后不产生事件，重新开启不补造关闭期间的编辑；重开、无变化保存及回执重放不重复计数。统计绝不授权重发供应商，未知请求仍走既有恢复协议。

## 验收范围

本切片使用真实 Owner HTTP、SDK 文档保存、隔离 PostgreSQL、本机音频提取与实际文件边界；仅受控测试素材，不调用视频或其他真实付费 API。非空 193→194 升级、注入失败回滚、原数据／序列／ACL／ledger 与整库恢复必须保持。最终关联回归及独立审查闭环前，不将局部绿灯当作完整 C2／G 完成。

声音194原阶段8文件27集成、4文件27单元、类型及schema矩阵通过；安全对象清单数量577，不是577项测试。后续195导出／资源与声音补充矩阵见持续实施记录，不能用原阶段数字代替后续或全项目验收。

环境声已通过当前Owner命令完成本地提取、人工口播采用、环境混音及真实导出；330Hz口播与440Hz环境声频谱分别验证，角色使用／增益变化／撤回和重开不重计。非单倍嵌套、超调曲线与转录剪辑通过实际SDK保存验证为unknown，从未知恢复不虚构撤回／重新采用，随后真实变化可继续观察。

65个相同来源实例的本机单次测量中，统计关闭保存约332ms、开启约609ms、无变化约244ms；来源探测分别0、1、0次，表明现有事务内缓存避免按实例重复探测。这些数字不是性能SLA，也不代表大文件、多别名或多来源工程。

实际卡住30秒的观察子进程曾把保存拖到约31.4秒，宽限15秒断言先失败；现在仅可选的`inspectAudioStream`探测设置5秒超时，失败沿原合同记unknown，真实保存与音量仍持久化。媒体提取／渲染执行、实际文件SHA和来源归属验证没有放宽，其他媒体执行仍保持原300秒配置。采集关闭不运行此观察。

文件核验仍在Owner业务事务和工作区锁内；5秒只是每次统计探测的超时，不是整次保存上限。大文件读取、多来源／多别名总体开销和最终G规模／故障矩阵仍需验收，不宣称普遍低开销。
