# 四步制作观察合同 v1

状态：实施中；来源 ADR-0069、完整规范 C1／C2。只在隔离环境验证，采集仍默认关闭，日常未应用。

| 里程碑 | 权威事实 | 阶段／去重 |
| --- | --- | --- |
| `production_created` | 当前新单实际插入 | 脚本；单据 ID；旧创建不补录 |
| `script_revision_saved` | 主脚本实际登记／修订并成为待确认版本 | 脚本；脚本版本；未保存草稿不计，实际修订终止旧阶段 |
| `script_confirmed` | 当前主脚本确认并进入 `script_approved` | 准备；脚本版本；重复阶段跳转不重复确认 |
| `workspace_prepared` | 独立工作区建立或接入新基准 | 准备；工作区＋基准；不表示素材已全部完成 |
| `editing_opened` | SDK 成功打开且核验、持久化完成 | 剪辑；工作区＋基准＋原生保护版本＋覆盖起点；页面标签不算 |
| `native_edit_saved` | 实际 SDK 编辑／恢复保存了内容变化 | 剪辑；工作区＋基准＋原生保护版本；字幕设置、素材采用不凭计数器冒充此事实 |
| `export_ready` | 实际导出与检查成功后落库 | 交付；导出 ID；失败／阻断不冒充成功 |
| `export_confirmed` | 当前精确文件核验并首次确认 | 交付；导出 ID；重复确认不增加 |
| 既有 `delivery_completed` | 交付 Worker 完成有效任务 | 结束观测区间；沿用原交付合同，不再造一个产量事件 |

`workflow_milestone` 的固定字段为 `version`、`milestone`、`phase`、`script_revision_id`；按事实追加工作区、基准、原生保护版本、工程内容版本／SHA、导出 ID。不输出正文、路径、名称、凭据或媒体内容。内部追加函数构造字段，不扩宽既有通用统计 payload 接口。

阶段经过时间从有证据的里程碑开始，到下一阶段、完成交付、覆盖结束或窗口截止。相同阶段的多次保存合并，不重复累计；重新编辑可返回前步。关闭后重新开启不延续原区间，旧 `coverage_observation` 的数据库阶段不能补成制作阶段。未知协议作为覆盖断点，不能把未来里程碑猜成当前阶段。

这些时间包含等待和并行活动，不是纯人工工作时间、供应商等待或单任务资源消耗；不能将各生产单时间简单当作主机总忙碌时间。无阶段证据时返回 null，保留现有数据库阶段指标供单独解读。

尚待 C2 补齐本机导出开始／结束及完整声音使用；本合同不将缺少的观测推测为已发生，也不启用日常采集或 Dashboard。
