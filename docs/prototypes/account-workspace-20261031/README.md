# 账号工作区交互 Demo

访问 http://127.0.0.1:5174/docs/prototypes/account-workspace-20261031/index.html ，或用浏览器直接打开同目录的 `index.html`。

演示账号切换与局部导航、通用规则编辑、系列继承与单独覆盖、账号设置中的目录路径；支持新建示例账号／系列、保存、撤销、未保存切换确认及查看示例历史版本。

示例数据只保存在当前页面内存中，刷新恢复初始值；不调用 API，不创建目录或移动文件。新增字段仅用于演示方向，正式数据映射尚未确定。

`desktop.jpg`、`series.jpg`、`settings.jpg`、`mobile.jpg` 由真实浏览器生成，仅用于视觉验收，不代表正式应用或业务集成已通过验证。

沿用现有设计风格；本 Demo 的局部布局与交互不构成新的全局设计规范。
