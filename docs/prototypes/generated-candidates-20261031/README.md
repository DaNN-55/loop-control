# 生成后选择占位 Demo

打开同目录 index.html，或访问运行中本机服务的同路径页面。

生成结果位于上方，左侧是固定 260px 高、可纵向滚动的缩略图栏，右侧是大图预览。点击「生成图片／视频」产生占位候选，点缩略图预览，再点击「采用此图片／视频」更新左侧镜头状态。候选编号、模型和采用按钮合在预览下方的一行；不重复显示当前镜头状态。

连接与模型、参考图、提示词和生成参数位于下方连续表单，不设「设为本期默认」。再次生成保留旧候选及采用状态。切换镜头和图片／视频分别保留结果；「重置演示」恢复初始空态。

所有模型、素材与操作均为页面内占位演示，不读取账号数据、不调用服务、不写入数据库，刷新清空结果。正式页面未改。

实际浏览器已验证结果在表单上方、左侧缩略图滚动、选中才显示采用按钮、预览时就绪数量仍为 0、明确采用后为 1、追加生成保留旧候选与采用状态。当前紧凑页脚高度为 40px，重复状态节点不存在。empty.jpg、candidates.jpg、adopted.jpg 为当前版本的桌面截图。此次页脚调整未重新完成移动端验收，已移除旧版移动截图，避免混用证据。

当前桌面紧凑页脚经只读 Agent 查看截图并核对源码，结论为 ship；仅限该占位原型的桌面调整，不代表正式生成链路验证。
