# ADR-0048：旧规划写入退役与只读配置归档

状态：Accepted（仅待采用基线及隔离验证）。日期：2026-11-12。

## 决定

用户批准按 10→1→2→5 顺序收口，保留现有功能和历史，冲突跳过。日常库不应用本轮 SQL，也不切换；仅并行三份 CSS 可单独本地提交。

- 沿用 ADR-0044 的当前本地正文/v2准备、显式媒体请求及 ADR-0047 的代际迁移边界。新增 `db/current` 编号迁移，不覆盖此前基线、转换或归档原文。
- 旧规划 SQL 写入/排队/重规划入口保留权限与归属校验后明确拒绝；取消只服务退役规划的预填和冻结触发器，历史行不改写。只删除已核对依赖的内部纯规划辅助函数。
- 旧全局规划默认及 Harness 表重命名为 `historical_planning_defaults`、`historical_planning_harnesses`，保留全部 ID、字段值、时间和 Owner RLS。业务角色只读，不作为新制作默认。旧导出先按原 schema 对账，转换后恢复发布按固定历史表映射核对原行，不重写数据或伪造来源。
- 旧媒体编排仅关闭明确废弃且无当前消费者的入口；仍被旧任务修复、结果回写或当前领取链调用的包装保留，记录建议和实际影响。不把 `legacy` 命名当作无用的证据。
- 退役 SQL 保存在不可变历史基线/迁移中；当前 Worker 核心、协议转换、创作规则版本、媒体、SQLite、Keychain、租约及产物发布保护保持。

## 追加决定：旧旁白入口（2026-11-12）

用户批准在确认无旧旁白执行中或待结果后退役。日常库只读盘点显示任务及旁白提交、发送事实、发布、预留均为空；字幕预览隔离库只有已完成旁白，无待结果记录。

移除旧 `generateTts` 执行分支、旧自动继续动作和没有当前制作选择的重试 fallback；Owner 旧命令保留归属校验后返回 410，SQL 生成和编排函数以新迁移明确拒绝，保留签名与权限。Worker 不再领取或执行旧生成快照。当前 `selectionVersion: 1` / `production-request-v1` 旁白、手工音频、历史读取、采用、原产物发布恢复和未知请求核对保持。旧专属测试归档，当前集成不再过滤旧在途失败案例。

共享的旧策略修复/指纹、草稿与设置、历史 submission/received 兼容不因名称包含旁白而删除；涉及当前历史读取或恢复的部分列为冲突保留。历史 SQL 原文不修改，日常库不应用新迁移或切换。

## 验证

每项独立在无网络、无持久挂载的专属 PostgreSQL 容器验证。覆盖权限/归属拒绝、历史行精确保留、空库/旧导出升级、失败回滚、幂等及当前准备、媒体、字幕、Studio和交付。日常业务、schema、配置、PID和CSS指纹另行只读复核。
