# ADR-0026：原生剪辑宿主模块依赖集中登记

状态：Accepted。日期：2026-11-09。Owner 已批准集中依赖装配并补齐回归，沿用保存和消息协议。

原生剪辑宿主模块使用单一登记表保存虚拟身份、源文件和公开入口。Vite 插件按来源文件位置解析已登记模块的相对引用，兼容源码中的 `.js` 引用与实际 `.ts` 文件；不再逐条维护 importer 条件。未登记的宿主相对依赖明确失败，错误包含来源和依赖，不开放宿主源码目录或搜索未登记文件。

源码在 Studio 启动时一次读入；同一进程内重复加载使用该快照，重新打开的新进程才读取新源码。React 与 SDK 的 `/src/persist/*` 引用继续由 SDK 的 Vite 解析，不另建原生工程存储或改变 React 归属。TypeScript 类型引用不进入浏览器运行图。

启动配置、第三方源码适配和独立 Vite 缓存仍由现有启动脚本负责。保持 ADR-0015、0016 的原生时间线、保存和身份校验；本次不扩大 ADR-0025 的发布物范围，不将宿主适配源码宣称为固定后台发布物。

通过 Vite 插件及真实 HTTP 依赖图验证新增传递依赖、全部虚拟入口、未登记拒绝和启动快照；以隔离剪辑器及浏览器验证打开和保存。登记表不是依赖边清单，新增已登记模块之间的引用不需要修改登记。
