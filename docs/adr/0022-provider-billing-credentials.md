# ADR-0022：供应商账务凭据与生成凭据分离

状态：Accepted。日期：2026-11-01。Owner授权接入账务；OpenAI Admin Key由Owner稍后在控制台创建后安全录入。

沿用现有本机Owner HTTP、Origin／CSRF、PostgreSQL RLS、不可变Keychain端口及供应商适配边界。新增账务设置属于外部连接管理，不属于内容账号预算或生产单执行选择。生成Key不升级为管理员Key，账务失败不改变生成资格。

账务凭据显式绑定一条外部连接，余额／近7天均注明供应商账号／组织范围，不能假设同供应商连接属于同一个云账号。服务端固定官方主机、动作及鉴权，不接受自定义Endpoint。账务读取不生成内容、不充值、不改变云权限。

PostgreSQL只存Owner、连接、凭据不透明引用、不可变请求摘要及状态。密钥仅经现有Keychain保存，不回显或进入日志。轮换追加记录，保留旧引用用于秘密库存和审计；后台秘密库存识别账务用途。断开仅撤销本机关联，不删除供应商Key或旧Keychain值。

验证并保存先校验有效Owner与绑定修订，再读取供应商接口；至少一个适用指标成功才保存。余额与账单可分别失败，不将未知值变为0；重试和并发通过操作标识、修订与连接锁处理。读缓存仅在当前凭据修订内有效，5分钟缓存、有界分页和响应大小，任何不完整账单不能作为完整7天总额。

阿里取官方QueryAccountBill.PretaxAmount，标注「账单7天」及应付金额口径，不把应付额当现金扣款；火山取官方PaidAmount，OpenAI用Costs API的amount。所有字段必须通过供应商返回值校验，注明币种、范围、账期、入账延迟。无公开余额API的指标保持不支持。先以供应商账务账号总额接入，不猜测产品代码或由调用量估价。

2026-11-01真实接入修正：阿里已授权的实际按日账单只返回PretaxAmount，未提供PaymentAmount。早期现金支付口径会拒绝整段7天合计；改为统一汇总官方应付字段并显式命名，不按某行是否有现金字段混用口径，也不将缺字段变为0。权限仍只有余额和QueryAccountBill两个查询动作。真实响应结构的回归先失败，修复后通过。

同次真实接入发现视频／语音连接可以使用同一火山账务账号；各自限速会合并超额。供应商reader内的云请求共享队列和间隔，继续按连接修订隔离缓存与结果。保留原请求期限和页数上限，识别AccountFlowLimitExceeded为限流而非权限问题。无需增加权限、合并连接或复制主账号凭据。

验证：固定时间／凭据的签名对照、跨月分页／负值／缺字段／失败边界；隔离HTTP＋PG＋Keychain端口验证Owner／CSRF／轮换／重复提交／秘密不回显；真实浏览器验证输入清理、错误恢复、刷新和表格更新。真实供应商数据仍须Owner录入账务凭据后实测，测试夹具不能充当真实余额。
