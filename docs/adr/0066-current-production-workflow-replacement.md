# ADR-0066：以当前制作模型替换旧执行链，保留版本化历史恢复

状态：Accepted，实施中。日期：2026-11-13。Owner 批准 [实施规范](../specs/current-workflow-replacement-20261113.md)，按批完成当前制作链、历史接入、旧执行入口退役和命名统一；不整体重写项目，不提交、不推送。

当前新单复用了旧审核包、镜头草稿及音轨模型；仅删除带旧名字的函数会破坏当前制作或恢复。选择先修交付来源和历史引用，再建立独立制作基准与稳定镜头、迁移当前读写和旧单操作，最后通过明确运行版本门槛撤下旧执行合同，收敛 SQL 包装和当前名称。旧程序原样执行不作为永久兼容目标，原包、冻结快照、审批、草稿、音轨和归档迁移仍保留为可读取／恢复的历史证据。

交付说明必须从已确认原生工程中的明确音轨身份解析，不能以共用文件路径首条匹配取代采用证据。没有明确身份的旧来源仅允许唯一匹配，歧义拒绝；裁切、变速或静音不能声称已使用完整来源正文。逐项历史投影保留原版本选择与追加语义，先装脚本／系列引用目标再装新增生产单，核对同生产单、账号归属及所选来源 Owner，不覆盖当前已存在记录。

全部分批改动保留 Owner／RLS／ACL、租约、冻结输入、确切导出、费用确认、未知请求和恢复保护。统计仍默认关闭，新增事件不带正文／路径／秘密，不补造历史。日常部署、重启和采集启用另行授权；本轮先完成源码、迁移和隔离验收。最终新 clean 基线须与前向升级及完整／逐项恢复结果一致，旧已采用 SQL 和 ledger 不改写。

当前默认制作模板和页面示例使用v3，默认只表达画面意图，不预设视频生成或费用。原v2以固定协议样本继续验证读取和拒绝语义；当前模板不再承担旧测试输入的身份。独立基准文件不伪造成旧审核产物，由同单数据库引用通过原Owner文件白名单读取，继续验证实际目录、文件大小及SHA，未登记文件不因位于同目录而可见；旧schema按对象存在性保持原读取路径。

D执行版本门槛实施约定：新准备包使用manifest v5，并把`production-workspace/v1`执行协议写入版本身份哈希。当前受支持的应用工厂、Worker服务／CLI和prepared启动入口复用同一检查；完整的v4原包得到明确的退役错误，损坏包仍是完整性错误。显式prepare发布新目录和指针，不改23个原包字节，旧包仍可作为历史格式／冻结来源证据由当前恢复器读取。该检查不终止已运行进程，也不是对Owner手动执行任意旧文件的操作系统权限隔离；日常切换须另行授权并在撤下SQL合同前核对和停止旧执行消费者。后续撤下更多执行合同时提升协议版本，避免把过渡包永久当作当前可执行版本；此门槛不代表旧计划接入或E1/E2已完成。

D旧计划读取约定：保存记录是历史快照，读取不再根据现主脚本、系列默认值或素材池重新解析；现主脚本已变v3也仍可查看原计划。读取只经过原Owner成员关系与script_productions既有RLS，不恢复整期启用或消费原授权，不核验文件的历史展示明确标记sourceVerification=not_checked；实际接入必须另行核对源脚本、计划指纹、同单素材和真实文件，不将展示成功当成执行资格。原记录/文件不写回，当前工程不覆盖；旧命令和读取路由的最终退役仍在D接入完成后的E1，不以本只读切片宣布完成。

D保存计划接入采用独立的plan-import基准及196前向注册函数。Owner命令固定现脚本ID与原计划SHA，核对原脚本字节/段落和原绑定素材；原保存根路径不授予宿主权限，跨单来源只在同账号与原许可核验后通过受控复制/复用证据接入。准备文件仍为production-preparation/v1，原record整份保存在source_evidence，不重写原记录。计划首帧是候选，配乐/音效是准备项，不能被当作已采用；口播文本和声音只预填为none，费用/连接/授权不消费，实际采用和生成仍走当前命令。已有当前工程拒绝覆盖，已有原生/HTML编辑走原工程接入而不重建。此步骤的后续矩阵包括原设置、素材别名/迁移、未知请求、回滚、升级/恢复和UI，未通过前不宣称完整D可退役。

D旧手工绑定接入使用`legacy-shot-workbench/v1`来源快照：Owner只读检查返回原脚本/分镜/草稿/引用任务与素材的指纹，明确接入须重读并锁定原记录，按准确指纹核验真实文件和原确认。无原生或HTML产物时，已确认且可验证的绑定通过现有原生工程构造器接入当前工作区，原记录整体进入不可变恢复来源；不调用旧编排、不生成新供应商请求。已有原生编辑优先，混合来源请求拒绝。未确认/部分草稿不伪造原确认，后续按当前输入/候选承接；此首条能力不代表完整D、历史矩阵或旧入口退役已经完成。

197将原工作版本来源读取限定在私有Owner函数中，保持原表ACL，不借旧Studio持锁函数做只读检查。接入时优先保留已保存原生及已完成HTML/JSON工程；从绑定构造只适用于无这些成品的来源。声音按每个原确认具体ID/任务/路径/SHA核验，不以同cue的最新候选替代原采用；各原确认有冲突则要求明确选择，来源全部保留。source预览旁白ID的null约定与tts实际轨身份分别处理；音轨产物生产任务须一致且未失效。

D未确认草稿通过独立的`importLegacyDraftInputs`明确导入当前输入和可选文件，不借用旧批准、口播确认、字幕确认、预算或连接授权。原草稿/任务/音轨整体保存在不可变来源；可核验素材/完成音轨可准备为候选，尚未采用的内容不写成工程已使用。缺失文件保留来源和提示，不虚构可用结果；含已确认镜头的混合来源按子集核验并保留原采用，不能整体降为草稿。接入后的新外部调用核对原请求在途/未知状态，本地编辑和明确采用已核验文件不受旧授权驱动。当前本地音轨准备可按准确已登记track/产物/生产任务/文件复用，不新增素材或任务；采用时重核验，重复/重试/批量或跨单输入不能绕过调用确认。

D混合镜头接入约定：同一次来源快照中的确认镜头仍通过原预览/冻结契约/实际文件/原声音版本严格核验；待确认/跳过镜头只建立当前空画面、输入和候选。完整制作基准保留全部稳定镜头，不把确认子集注册为整单。原生工程只首次登记一次，不将原确认导入伪造成当年发生的采用或新的生成；后续Owner明确采用按当前实际变化采集。确认内容的原文件区间不随待处理镜头插入而推进，主声音和镜头音效随所属镜头移动；原选择合同仅允许整期配乐与镜头音效，接入不增加整期音效的假想分支；音效须映射准确的确认镜头，无法核验的窗口明确拒绝且保留原版，不静默丢弃原采用。原记录和未采用结果保留，过期指纹/原确认失效/当前编辑/原生或HTML成品优先仍拒绝覆盖。原设置全字段、实际UI与完整恢复矩阵仍是D后续条件，不以本子集实现宣布D或A–G完成。

D原呈现设置接入采用`workspace-render-preferences/v1`当前预填协议，放在当前镜头绑定/原生镜头元数据中；只允许主声音/配乐/音效增益、配乐闪避、字幕样式与转场，不携带服务/连接/预算/执行授权。源设置在接收边界转换，当前采用逻辑消费当前类型，不在每次采用时重读可变旧计划。它只影响首次明确采用的初始呈现；现有音轨增益、路由、窗口和人工样式优先，替换不得重新套原默认。当前原生保存/导入核验版本和字段；原冻结计划及已确认工程不改写。逐镜头差异、旧草稿的构图/裁切与封面接入仍须分别验证，不以全局单镜样例宣布D完成。

保存计划的呈现预填由原冻结段落设置转换；未确认镜头工作版本由原混音数值/闪避/转场列及同脚本计划/原系列字幕样式转换，确认子集不重套默认。旧计划不属于同一脚本时只保留来源和明确问题，不把该计划样式套入当前输入。内部初次组装接受已核验的按镜头预填映射，不对HTTP新增覆盖当前工程的参数。逐镜头配乐音量/闪避不一致时建立当前的分段配乐及独立声轨；共享源按实际时间连续取样。再次明确采用替换所有受控配乐实例的来源，保留各实例人工窗口/增益/路由，源长不足仍整笔拒绝，不自动循环或叠加原配乐。

D原声采用与明确混音分别处理：首次采用才使用呈现预填，已有主声节点的人工增益、轨道/路由、时间窗口、变速与淡入保留；替换同一原片的提取音轨时，按两次提取的原片起点换算源帧，保持原声实际区间，不把新音轨的零帧冒充原区间。新来源不能表示原区间时返回409且保持最后工程，不循环、不截断或恢复默认。该行为只用于采用入口，Owner明确混音命令仍按所选操作改变主声。采集不因无变化重复采用虚构声音变化；严格呈现协议不接受字符串数组代替枚举。

更早或原生导入的原声资产元数据缺SHA时，当前采用边界从准确登记音轨、完成且未失效的原任务与产物、实际文件核验，并从原冻结workspace_source重建可信提取起点/帧率/原片SHA；仅更新当前工程的私有副本，不写原历史。同SHA的原生asset别名可正确换算，无法核验则409，不能用新提取起点替代旧起点；HTTP仍禁止source与audioTrackId的混合准备输入。

D未确认画面接入使用严格的当前workspace-visual-draft/v1内存输入；原clip_segments/构图只在历史接收边界转换。全屏多段顺序相加，分屏/画中画/四宫格按原槽位和最短并行窗口建立空画面，保留fit/焦点/转场边缘；确认子集仍保留原采用，不重新构造。原图按每个当前窗口时长建立候选，原视频候选附workspace-source-range/v1初始区间，登记不等于采用。Owner明确准备采用时才使用该初始区间，明确区间覆盖优先，当前人工构图和运动优先；源越界只保留原草稿/问题与空画面，不造可用结果、不循环或补发。初始区间属于受核验的内部登记参数，不增加HTTP注册命令字段；原来源/SQL/历史文件保持。实际来源UI及候选面板初始区间的显示/默认值随D界面批次继续验收，不以后台专项宣布完成。

内部图片接入按当前空占位的严格整数帧窗口登记，公开HTTP图片登记仍限制0.1–120秒。视频采用在本地声音提取和采用证据写入之前核对量化后的源终帧，不能借小数四舍五入越界。SDK桥接明确传入半开导出帧区间以保留短片，代表图按实际视频帧号取样，不以音频封装时长猜测视频取帧位置；不修改SDK或放宽原导出检查。

D候选区间面板对未采用选择使用核验后的初始区间，显示、预览和提交的起止一致，明确0秒也是有效覆盖。已采用内容直接以当前原生节点的源起点、帧长和播放速率决定预览，不被导入初值或尚存表单值覆盖；完整源的倍速同样保留。选择和准备不等于采用，仍需Owner第二次明确确认，后台源长、帧边界、工程版本与来源保护保持。候选区间UI专项不代表完整旧来源选择UI、原声意图／封面映射或全部恢复矩阵已经完成。

D统一来源入口约定：空工作区与只读workspace-source-options/v1摘要在同一次Owner只读事务读取，已有当前工程不再扫描旧来源。原生编辑优先，完成的HTML／JSON按原冻结分镜关系选择，原工程无法核验时保留阻塞而不静默改由计划或镜头绑定重建；无这些工程时保存计划和镜头工作版本由Owner明确选择。摘要不授予文件或执行资格，接入重核验原身份和当前版本。脚本确认回调须等待来源判定，无旧来源保留本地准备；当前工程修订可使用已确认回执的新脚本ID衔接父页面刷新。选择不提交，操作归属防止重复及迟到回执覆盖；原查看下载保留，不恢复旧授权。此子批完成不代表原声意图／封面、完整恢复矩阵或D／A–G完成。

D封面接入使用当前`workspace-cover-source/v1`候选引用，精确固定kind／同单ID／SHA。保存计划原封面在接入边界转换，登记历史cover产物可列候选；枚举不等于文件已核验，不自动采用。Owner明确使用后预览，交付再次核验同单登记、实际文件大小／SHA与图片类型；引用和手工字节不得混用，metadata保存来源，当前人工封面优先于迟到读取。原证据、原路径和原字节不写回；此子批不替代所有来源完整恢复与原声意图映射。来源显示的可读名称由F1收口，不能通过改原文件身份实现。

D原生预览JSON接入明确区分冻结重建与已保存编辑：原确认指纹及冻结文件继续证明出处，当前原生音量、静音、删轨、字幕增删和播放速率以原工程为准，不再强制匹配冻结时的声音模式或字幕集合。实际源消耗按源起点加时间线帧长乘播放速率核验，快放越界仍拒绝；当前输入按实际原生字幕同步，native_edit_revision已大于0的工程重开不再初始化补造字幕，不以版本理由字符串判断人工编辑。原文件／任务／轨／确认保持，导入不恢复审批或外发授权。
