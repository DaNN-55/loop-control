# ADR-0049：退役旧任务修复、派单和自动续跑

状态：Accepted。日期：2026-11-12。用户明确授权：只读确认无旧在途或待核对任务后，清理旧任务修复、自动派单、旁白重试、自动续跑和无用表单文案。原型归档暂缓；当前功能、历史、恢复和保护代码保留。

## 决定

日常库的生产单、任务、旁白/图片提交、费用预留、发送事实、产物发布及旧续跑记录均0，满足执行条件。日常数据库不迁移、不切换，日常服务不重启。

删除旧修复表单、旧技术配置读写表单和专属测试；保留当前账号/系列创作规则转换，表单不再构造Codex默认执行器。历史阻塞仍显示原始原因、任务ID和核对说明，改为明确在当前分镜台提交新请求。

旧配置/连接修复命令及重新启用旧自动续跑的请求，在身份、CSRF和Owner归属检查后返回410，先于旧幂等回执重放。移除旧修复执行分支、自动扫描器的应用启动、timer、自动动作执行器和自动唤醒。手动读取旧计划、历史授权/进度和共享制作能力保留。

170前向迁移替换14个旧修复/自动派单函数为受控拒绝，保留原签名、ACL和历史行；仅在原来可调用的角色边界返回0A000，原未授权调用继续42501。`script_production_scopes`返回空集合，防止旧扫描器重新发现旧启用记录。当前Worker显式请求路径、领取/租约、发布回执、未知请求保护、字幕与音轨恢复不变。

第3项旁白由主对话完成169前向迁移和执行入口退役，本轮复核并在组合源码上验证。不可删除共享TTS草稿、声音设置、音轨恢复和目录中的历史预设；保留它们不表示旧执行入口可用。

## 历史与恢复

旧SQL归档、冻结基线、原任务/音频/产物、两张规划历史表、逐单旧选择、表名恢复映射和原工程接入保留。退役执行专属源码/测试以文本归档在`docs/archive/legacy-flow-retirement-20261112/`；不把旧执行能力重新加入运行产物。原型文件及其依赖不迁移。
