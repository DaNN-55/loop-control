# 外部连接按版本冻结并由 Worker 解析秘密

外部连接归 Owner 工作区全局管理，Owner 只能为随 Worker 部署且声明认证方式的 Adapter 创建连接；蓝图只能选择与一个已注册生产能力、Provider 和 Adapter 兼容且已验证的连接版本，Episode 和任务仅冻结业务数据库中的非秘密连接版本 ID。最小持久化模型分为外部连接、连接版本和追加的连接验证结果；连接版本拥有 Provider、Adapter、官方 Endpoint 和不透明的秘密引用，认证材料本身只由 Worker 秘密存储解析，蓝图则拥有模型、Prompt 等静态执行配置，声音与语速由 Episode 的本期 TTS 设置拥有；预算只作为实际成本记录，文件读写能力与有效并发由 Worker 平台运行时约束计算并写入任务快照。服务端在蓝图保存、Episode 创建和显式修复的同一事务验证版本归属、兼容性与验证状态；Provider、Adapter、Endpoint 或认证材料变更创建新版本，显示名称和说明不创建新版本。Owner 经一次性受保护写入路径把认证材料交给 Worker 的秘密存储，页面永不回显原值，Worker 在生产前和每次任务执行时分别解析；本轮只定义这一秘密存储边界，不绑定具体产品。连接版本可保留为草稿或测试失败记录，Owner 显式测试会追加脱敏验证结果，并仅验证 Endpoint、认证和最小权限；配置或秘密变更后必须重新测试，临时可重试失败保留上次已验证资格，首期不做后台监控。当前蓝图可继续编辑并供新 Episode 使用，已有 Episode 则先保留旧快照；若 Episode 以人工素材供给某项能力且不创建外部任务，就不要求连接。连接轮换或撤销会阻塞仍需该连接的 Episode，不自动故障转移，Owner 只能通过显式修复受阻 Episode 来切换新版本；已引用版本不硬删，未引用草稿可删除，以保留可追溯性并避免静默改变生产来源。

首期不导入 `pexels-default` 等硬编码默认连接：当前蓝图仅为测试数据，全局连接池从空开始，由 Owner 创建、填写认证材料并显式验证。已部署迁移历史不改写；实施只添加前向迁移以清空测试蓝图的五项可选生产能力旧 Adapter/连接配置和默认引用，保留账号、核心脚本流程、系列、Episode、素材和审核数据。
