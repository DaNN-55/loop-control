# ADR-0038：样音选择归属与模型编辑基线

状态：Accepted。日期：2026-11-10。Owner 批准剩余状态机专项复查的第 1、2 项；不提交、不推送。

## 决定

样音组件按语音选择的 capability／provider／adapter／model／preset／connectionVersionId 与 voice 分配独立播放器实例。选择变化卸载原实例，取消客户端等待、停止播放并结束原确认；迟到回复和 finally 不能操作新实例，A→B→A 也属于新一次访问。语速、标签与按钮样式不改变样音身份；相同来源复用原缓存并按最新语速播放。保留服务端样音缓存、首次合成确认与供应商恢复限制，不自动重新合成，客户端取消不能撤回已经发出的供应商请求。

模型弹窗把最新目录／服务端设置与编辑基线分开。未编辑时刷新随服务端启用值更新，不制造草稿；真实草稿在启用基线未变时保留，并允许采用仅目录发现引起的新 revision。若服务端启用值已改变，保留本地勾选与原 revision、显示冲突并阻止保存；不把旧勾选与新 CAS 拼接。连接版本不符的响应拒绝接入。关闭／保留草稿仍记录原编辑基线，重开沿用既有按版本恢复规则，不跨版本移植草稿，也不提供强制覆盖入口。

服务端 Owner、连接版本、启用模型校验、幂等保存及 CAS 语义保持不变。无需新依赖、SQL、公共状态框架或新恢复协议。

## 验证

通过真实样音组件与客户端 HTTP、真实模型弹窗公开交互／保存参数验证；只在网络或外部回调处控制响应，不 mock 新私有实现。覆盖语速复用、音色／模型／连接切换、迟到与 ABA、首次合成确认，以及无编辑刷新、真实草稿、并发设置、仅发现 revision 变化、保存拒绝和连接版本变化。隔离浏览器检查真实播放、宽窄屏、冲突草稿与保存参数，不调用真实供应商或操作业务数据库。
