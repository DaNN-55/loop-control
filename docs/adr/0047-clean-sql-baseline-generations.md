# ADR-0047：当前 SQL 基线与不可变历史迁移分代

状态：Accepted（仅隔离实现与验证）。日期：2026-11-12。日常目标库切换另行授权。

## 决定

- 沿用 PostgreSQL 与 `pg`，保持业务表、稳定 ID、冻结快照、权限、租约及产物发布屏障。数据库、OpenChatCut SQLite、媒体与 Keychain 的职责不变。
- 冻结的第一代 SQL 原文移入 `db/archive/legacy-v1/`；manifest 固定文件名和 SHA-256。旧 ledger 不改写为“执行过新基线”，未知版本、内容改变和不完整映射均拒绝。
- `db/current/` 保存当前有效结构的第二代基线、精确前向转换和代际 manifest。空库只执行新基线；旧库先按原顺序补齐第一代迁移，再在同一事务完成转换与第二代标记。新库不伪造历史迁移执行记录。
- 共享迁移目录解析用于维护、恢复与隔离夹具。旧逻辑迁移路径保留解析兼容；第二代已覆盖的历史迁移不再次执行。
- 默认日常迁移器不自动跨代。旧导出先完成原始行、序列和安全指纹审计，再在全新恢复目标执行转换；失败保留恢复证据，不覆盖源库。
- 清理退役执行分支，不把旧供应商任务改为新供应商，不重新计费或重生成。历史原文、记录、字段值保持。

## 取舍与冲突

蓝图退役保护与精确删除旧能力的两个函数仍需区分旧标识和其他未知值。直接用“非当前服务”替代会改变未知扩展及历史快照语义；此次跳过这两处旧名称清理，保留安全保护，并在报告列出建议及实际影响。其余当前生产链路保留签名和权限，仅缩小已退役分支。新基线不宣称旧名称为零。

## 验证

在无网络、无主机端口和挂载的专属 PostgreSQL 容器中验证空库、旧数据升级、旧导出恢复、幂等与失败回滚；对账全部业务行、序列、目录、角色与 ACL，运行当前业务集成测试。主工作区 CSS、日常配置、进程和数据源保持。隔离验证通过也不等于已采用新日常库。
