# ADR-0040：Owner 日志查看与独立存储位置

状态 Accepted。日期 2026-11-11。Owner 已批准迁移日志预览并在个人偏好中配置日志存储位置。

## 决定

- 日志入口放在右上角 Owner 菜单，以现有弹窗与焦点协议打开。正式页面不引用原型、模拟数据或静态历史摘录。
- `/api/local/logs` 沿用本机来源与 Owner 会话校验，只读取服务端装配的固定日志文件。单次读取有字节、条数和记录长度上限，不接收任意文件路径，打开／手动刷新时读取。
- 服务端提取结构化记录或明确的错误／调用栈后脱敏。未知时间、生产单、关联编号保持未知；不把导入／读取日期当作发生日期，不凭时间接近建立关联。只有明确的生产单和 operationId 才支持同操作上下文。
- 日志目录属于本机运行设置，以私有原子文件保存；个人偏好中独立保存，不混入账号素材根或创作规则。目录选择／保存使用 Owner＋CSRF 接口，当前进程保留原文件描述符，新位置下次启动生效。旧日志不搬迁或删除，默认旧位置仍可读取。
- 自定义目录必须是本机已有、当前用户拥有且可写的规范目录，日志文件仅追加并以 0600 创建；符号链接、非普通文件和不安全的现有文件拒绝。重启时目录不可用则回退默认目录并提示。
- 14 天／1 GB 为原型中建议的后续采集保留策略；本次不宣称其已启用，不自动清理现有运行日志，不改变任务回执、快照或业务记录。

## 验证

真实临时文件验证读取上限、脱敏与目录持久化；真实 HTTP 验证来源、会话、CSRF 与方法约束；公开组件验证读取失败、恢复、过滤、上下文与关闭焦点。正式构建依赖图确认不含原型。配置保存不自动重启或执行生产命令。
