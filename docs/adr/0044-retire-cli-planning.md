# ADR-0044：退役 CLI 视觉与分镜规划

- 状态：Accepted，2026-11-12 用户明确授权。
- 替代范围：ADR-0018中“普通脚本使用Codex/Prompt Harness规划”的约定；其他制作选择、目录、冻结版本和权限约定保持。

## 决定

当前普通正文在本地按段落建立镜头，v2脚本读取已编写分镜。保留当前`start`确认主脚本及`prepareWorkspace`；退役Loop-Control内旧视觉/分镜设置、重试、修订/审核命令、Codex注册、CLI包装器及部署visualCommand；原会话、CSRF和归属边界后明确拒绝旧操作，不能通过旧幂等回执复活。

当前工作台显式提交任务入队；Native Worker停止调用仅服务旧输入链的SQL自动规划器。历史SQL、任务、审批、输入和快照只读保留，不卸载全局Codex。没有因退役而切换到其他文字Provider或自动生成主脚本。

保留共享Worker协议与媒体任务的验证、进度、租约及结果发布；`codexRunner.ts`是历史模块名，当前仍被媒体执行和Studio使用，不把整个文件误当作CLI执行器删除。保留当前脚本到分镜的纯转换函数和历史分镜格式验证。

## 影响与验证

旧输入链不会再隐式补建规划任务，旧规划无法新建、重试或通过修复配置重启；用户应使用当前四步工作台。默认正文/v2准备、媒体候选、旁白、手工字幕、Studio及交付保持。验收覆盖拒绝边界、现有流程和历史读取；不改写已应用SQL或历史业务数据。164前向迁移只收紧领取、资源计数与过期恢复资格，确保旧ready/running规划记录不被Worker改写；在隔离库验收后应用。

原生PG、SQL新基线、埋点和后置组件方案是后续计划，见[迁移计划](../plans/native-postgres-and-clean-schema-20261112.md)，本ADR不授权执行它们。
