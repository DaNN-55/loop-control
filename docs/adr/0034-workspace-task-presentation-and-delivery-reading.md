# ADR-0034：生成任务展示与交付读取保护

状态：Accepted。日期：2026-11-10。Owner 已批准状态机建议第 1、2 项，不提交、不推送。

## 决定

在 `workspaceTaskPresentation` 中集中任务状态的只读投影：完整标签、紧凑摘要、发布 hold、提交未知、普通重试与原任务恢复入口的现有可用条件。图片、视频、口播和音效复用该投影；已加入、已采用、实际时长和本地素材可用性继续由各自工程／素材状态表示。投影不发命令，不替代服务端权限，也不推断新的付费重试资格；图片未知提交例外仍由原入口判断并再次确认。

准备状态与原任务状态可以不同，例如当前口播输入修改后为 pending，而原任务仍在 running。摘要与详情优先解释实际任务；普通音频准备重试仍按准备记录的 status 加原 hold／unknown 条件判断，不因任务状态不同而扩大资格。

`WorkspaceDeliveryPanel` 复用已有 `useWorkspaceReading/useWorkspacePolling`，保留 2500ms 轮询间隔、原 HTTP 读取地址和错误文案。读取归属于 episode、workspace 及当前交付；变更工程、交付或停止轮询后，旧回复与旧错误不能发布。接收命令结果先观察／发布，以阻止待返回旧读取覆盖新结果。沿用现有 revision 和请求排序规则，不增加第二套读取状态机。

## 约束与验证

服务端确认、费用、任务租约、未知提交、publication hold、候选采用及交付导出绑定不变。没有 SQL 迁移、新依赖或自动恢复。展示与读取是两个独立模块，不合并持久状态。

通过真实任务摘要／详情和交付组件验证；受控 HTTP 延迟仅替代网络，不 mock 读取 hook。覆盖状态优先级、恢复入口与回调、已加入／时长保留、旧 revision、同 revision 新命令、交付／工程切换、卸载、过期请求失败、2500ms 节奏及不重叠。实际浏览器核对宽窄屏和恢复交互；不使用正式账本或真实供应商。

## 2026-11-11 刷新入口补充

`ProductionWorkspacePanel` 的初始／恢复刷新同样记录请求发出时的工程对象。命令在等待期间已发布工程时，拒绝旧工作版本及同 revision 的迟到投影；同一工程的更高 revision 仍可接入。请求期间没有命令更新时，允许权威读取切换工作版本，避免阻断正常 replan。两条失败回归复现旧回包覆盖，新增测试覆盖更高 revision 和合法工作版本替换。实现与验证见本轮状态机报告。
