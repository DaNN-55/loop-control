# ADR-0017：旧 HTML 工程接入可编辑工作区

状态：采用（2026-10-30）。

旧生产单的渲染工程是声明式 HTML，素材页只能回看冻结记录。Owner明确要求这些订单支持逐镜头上传、替换与原生剪辑，并保留旧工程。

沿用 `adoptLegacyWorkspace` 的 Owner、主脚本、当前分镜和文件 SHA 校验，以及现有不可变工程版本与媒体恢复登记。GET不迁移；显式接入操作才建立可编辑副本。最近保存的原生工程优先；冻结渲染中的原生文档次之；没有原生文档时，解析受支持 HTML 导出的声明式时序，结合对应任务的冻结源文件、原片区间、口播身份、字幕和分屏生成原生副本。

HTML仅作数据读取，不执行脚本，不使用其中的任意资源URL。缺镜头、冲突时间、未知声音、未能对应的字幕或当前路由不能表达的多段原声必须拒绝，不能降级占位并宣称迁移完成。计划时长不覆盖HTML最终时间；视频与字幕边界按工程帧率统一量化（30fps时最多半帧偏差），连续区间共用量化边界，避免一帧间隙或字幕超出画面；旧成员的镜头内起点转换成HTML绝对时间。新副本的字幕元数据与主声路由使用当前编辑器合同，不回填旧任务，也不继承新工作区的批准、生成权限或交付确认。

原HTML、媒体、渲染成片和审核记录不改写。已知淡入淡出、分屏、画面滤镜和缩放映射到原生属性；HTML专用暗角、字体阴影及字幕入场动画不保证逐像素还原，原成片仍用于历史回看。接入后须在剪辑工作台核对新输出。
