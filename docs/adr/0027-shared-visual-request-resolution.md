# ADR-0027：视觉调用解释规则集中管理

状态：Accepted。日期：2026-11-09。Owner 已批准第二项架构优化的首轮范围。

图片生成、候选视频与首次填充视频共用制作选择、创作上下文、素材身份、最终 prompt、主声窗口和供应商时长的解释规则。准备确认、消费确认和实际入队仍按各阶段当前状态分别解释，不把准备时结果缓存为执行事实。运行条件、事务授权和 SQL 动态并发检查留在入队处。

维持现有确认摘要、contextHash 输入结构、费用算法和任务快照格式，保留各阶段既有的参数拒绝语义。首次填充仍先按既有流程装配已有口播，再读取实际工程；不将副作用放入请求解释。口播、音效及其恢复路径不纳入本轮重划。

沿用 ADR-0018、0024：同事务消费确认与创建任务、Owner 调整费用不能替换其他输入、原连接版本与不可变快照、幂等回放和未知提交阻断保持原样。不新增数据库迁移、Provider 或通用持久化抽象。

通过真实 Owner HTTP、隔离 PostgreSQL、原生工程和受控 Worker 比较确认内容与实际请求，检查旧确认因输入变化而失效，以及消费确认后入队失败的事务回滚。使用已有首次填充、模型约束和未知提交回归验证各阶段规则。
