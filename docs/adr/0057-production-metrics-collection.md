# ADR-0057：默认关闭的生产统计采集

状态：已接受代码与隔离验证；日常 schema 经后续单独授权应用，采集仍关闭，新应用未部署。日期：2026-11-13。

2026-11-17 更新：用户决定移除业务质量档。迁移 206 清除质量版本、任务／交付分档及质量字段，日汇总按原币种与测试标记合并，保留制作次数和金额。下文质量档决定为历史记录；当前验收见 [清理记录](../verification/business-quality-retirement-20261117/REPORT.md)。

## 背景

第 14 项 A/B 已提供现有事实的只读汇总。Owner 批准 D1–D10，需要补齐阶段、排队、请求、费用依据、候选决定、质量档和资源事实，同时保留当前制作、付费请求恢复与历史记录。

## 决定

- 沿用本地 PostgreSQL、Owner 事务、Worker attempt/lease 权限边界，不引入第二套数据库或消息服务。
- 新采集具有 Owner 开关，默认关闭。资源调度还要求显式运行时配置。仅在隔离工作树和自有测试数据库启用；日常迁移、启用与部署另行授权。
- 后续单独授权：在 ADR-0058 的清理、完整隔离验证及日常备份候选演练完成后，用户明确授权 177 → 178 顺序应用并保持采集关闭。此授权仅包括日常 schema 迁移，不包括启用采集或部署新应用；实际对账见 `docs/verification/disconnected-prerender-20261113/REPORT.md`。
- 关键最小事实与业务写入在同一事务提交。来源身份幂等，同键不同内容拒绝；失败阻止本地提交，不能授权再次调用 Provider。HTTP 响应、发送标记、产物回执与供应商实际收费分别记录。
- 新事件不保存提示词、正文、秘密或文件路径。历史缺口保持未知，启用时仅写观察快照，不回填发生事件。现有 A/B 读模型保持可用。
- 业务质量档可选，默认未指定；版本变更可追溯，任务按提交时、交付按确认时冻结，不修改执行参数或费用门槛。
- 资源每 30 秒在有活动时采样，空闲不写样本，GPU 无证据时为空，失败与间断可识别。采样失败不使制作失败。
- 事件明细保留 12 个月、原始资源 30 天、匿名日汇总 24 个月。永久删除生产单清除其统计明细，只保留不含对象身份、正文、名称或路径的匿名日汇总；旧日志、业务历史与文件不按统计策略清理。

## 影响与验证

增加少量事务内写入与维护负担，换取重试、撤回、请求未知状态和统计覆盖范围的可追溯性。匿名汇总无法恢复已删除对象的详情；过期明细不提供伪造的精确分位数。自动账单获取、完整 HTTP 日志、细粒度 GPU 及 Dashboard 均不在本阶段。

验收使用版本化 SQL 建立的隔离数据库，覆盖默认关闭、跨 Owner、Worker 过期 lease、幂等、业务回滚、采用/撤回/再次采用、估算未知、质量冻结、保留/删除和资源间断。运行现有制作回归，实际打开质量字段页面。不以静态检查替代这些集成边界。
