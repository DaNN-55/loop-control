# ADR-0074：成片完成与发布资料分开，完成作品修改为新生产单

状态：Accepted。日期：2026-11-19。来源：检查与交付精简 Q1–Q23 的最终共识。

## 问题与决定

用户只想完成视频，却被标题、封面、手工问题记录和多次“准备／验证／确认”阻挡。现将主流程统一为：剪辑台“生成成片”先保存并关闭剪辑，再生成当前工程；观看实际 MP4 后一次“确认并完成”，系统自动收尾，成功后主要入口是“下载视频”。查看、步骤导航和刷新不发起渲染。

新核心清单采用 `publish-package/v3`，必需项仅为已确认视频、对应完整工程、检查证据和身份清单；封面与 metadata 可选。旧 `publish-package/v2` 仍严格要求原五类产物，绝不以新规则放宽旧包。确认、Worker 租约、文件 SHA／大小／归属、失败重试和审计继续保留。重试收尾不重渲染，不替用户确认另一份视频。历史视频／包保留原身份和下载校验；最新失败不会被历史成功遮住。页面只核对最新交付，旧交付在明确下载时校验，避免每次打开都重读全部历史视频。

人工问题记录及门槛整体退役：删除表、依赖函数中的门槛和删除语句、列表查询、接口读写、类型和界面；旧客户端写入返回 410。专项测试结论退出产品，验证报告保留。此决定不授权整体清理测试生产单、素材或其他报告。

## 发布资料

资料按 workspace 独立修订，Owner／会话／CSRF／位置身份与并发修订校验生效。标题、简介、标签、补充要求自动保存；封面保存实际图片字节。资料可在视频确认前或完成后修改，不改变视频内容版本或完成状态。旧 ZIP 不变；明确下载新包前先等待保存，再固定当前资料和原确认视频的快照。

AI 只在明确点击时请求，一次返回一套可编辑文案。沿用脚本页最近明确选择且仍有效的模型，可更换，无有效选择时提示，禁止静默换供应商。上下文只含当前保留画面安排、可证明实际保留的字幕／完整口播、冻结创作规则、当前文案和补充要求。裁切、变速、静音、无法证明文字覆盖的声音不冒充完整台词。不增加整段视频理解或 ASR。请求账本冻结身份与资料修订，拒绝重复、未知重发或晚到覆盖；成功替换可撤回最近一次文案及其视频基准。视频变化保留资料并提示核对，自动保存不会悄悄消除此提示。

封面支持已有图片选中即用、实际 MP4 指定时刻解码、本地 JPG／PNG／WebP 上传。来源与指纹可追溯，失败不清空当前封面，也不阻挡视频完成。只分别复制标题／简介／标签。

## 完成作品修改

原单与已确认视频不可变。查看使用隔离临时工程；选择片段和未改内容保存不创建正式副本。首次明确保存实际视频修改时，建立新 Episode／workspace，继承原脚本、制作依据、冻结账号／系列创作基线、采用关系、时间线／字幕／声音和发布资料，并重新归属必要媒体。新单停留剪辑台，可回分镜台修改，也可直接成片。

不继承原确认、完成、交付、可执行任务或凭据，不重新生成已经采用的素材。文件通过独立 inode 的写时复制／受控复制保存，副本不依赖原单目录继续存在。保存意图和目录创建回执支持失败／进程中断恢复，不发布半成品生产单，重试不额外建单。仅在完整成功回执后清理已核对的暂存文件，失败输入继续保留。

沿用 ADR-0073：实际原生工程决定成片，不恢复补充工具。宿主仅保留保存、导航、选择和只读工程检查；工程内容比较忽略 JSON 对象键顺序，保留数组顺序与实际值变更的冲突保护。

## 实施、迁移与限制

有效迁移 213 为既有原生权威迁移，本任务使用 214–219。退役迁移只删人工问题条件，保留原生工程交付分支。新资料表、请求／文件账本与副本初始化均有 Owner 边界；媒体身份核对使用流，ZIP 不将整段视频读入内存。下载工程仍依赖源素材，ZIP 不是全部源素材备份，ZIP32 上限沿用原规则。

替代 ADR-0035 的人工问题门槛、标题／封面完成门槛和历史成功遮盖当前失败的部分；替代正式界面“仅另存独立剪辑库”的完成作品保存结果。旧库中历史独立剪辑工程仍可读取。本轮在独立数据库、媒体根和浏览器验证；日常服务未重启，日常库新迁移待下次正常启用程序时执行，不在本轮直接删除日常数据。
