# ADR-0020：连接模型设置与执行快照分离

2026-11-01，Accepted。保持新建连接和制作入口不变，在连接的「模型设置」中读取供应商目录、筛选并启用模型。连接保存模型启用清单，未配置时沿用全部已注册模型；显式空清单表示暂停此连接的新模型选择。该设置不创建凭据版本，只约束新的明确制作提交，不参与 Worker 对既有执行快照的解析。

供应商目录不等于推理授权或本平台适配能力。读取操作只在 Owner 明确点击时访问当前版本的密钥和官方只读端点；目录结果仅属于本次窗口、绑定请求版本，不持久化原始响应或秘密。未适配模型只展示、不能启用；无公开目录、缺管理凭据或读取失败时保留已注册模型及原选择。轮换或撤销期间的结果拒绝应用；保存使用版本和设置修订号防止覆盖并发修改。采用连接级偏好而非复制凭据／模型连接，以保留历史任务、现有连接和制作界面。
