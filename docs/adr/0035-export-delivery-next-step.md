# ADR-0035：导出与交付的下一步判断

状态：Accepted。日期：2026-11-10。Owner 已批准状态机建议第 3 项；不提交、不推送。

## 决定

新增共享纯函数 `workspaceExportDeliveryState`，统一当前导出、检查、未解决问题、确认资格及交付视图的解释。它返回两个展示上下文：检查与交付总览，以及最新一次交付；同时集中下一步提示、主操作标签和禁用原因。禁用原因使用内部语义标识，界面沿用现有文案与组件，不新增说明层。

历史语义保持：总览依据所有交付记录判断「曾完成／有已验证交付」，包括隐藏重新导出及问题写入的原规则；交付区继续依据数组首条记录显示最新状态、重试和下载。不能把两者统一成「只看最新」，也不按当前导出 ID 过滤历史交付。已验证交付即使当前导出过期，仍可下载原文件。

本地活动仅影响已有按钮资格。准备交付期间仍允许按原规则继续编辑文案，确认失败、过期工程、封面检查、标题／文件缺失各自保留原限制；原交付重试不新增封面或标题要求。标签和封面验证、草稿、2500ms 读取保护、命令参数、服务端 SHA／版本校验均不改变。

## 验证

先通过真实组件固定历史行为，再对公开纯函数验证已批准状态表，两个页面实际使用同一结果。验证无导出、检查失败、未解决问题、当前／旧／stale 导出、确认、排队／运行、失败／受阻、完成待核验及已验证交付；包含历史已验证而最新失败的读入记录。使用隔离浏览器核对状态、按钮、历史下载路径与命令参数，不以合成状态推断线上缺陷，不调用真实供应商或操作正式数据。
