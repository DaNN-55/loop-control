# ADR-0018：制作按次选择与账号目录归属

- 状态：Accepted，按 #166 与子票逐步实施。
- 日期：2026-10-31。
- 替代范围：ADR-0005、ADR-0007 的蓝图媒体工具归属和审核配置，ADR-0016 的当前 A-roll / B-roll 工具路由；其余历史与权限约定保留。

## 背景与决定

账号蓝图只拥有版本化创作规则。普通脚本的 Codex 分镜规划仍是核心制作能力；现有模型、Prompt Harness、规划额度和技术执行输入从蓝图迁至制作准备入口，并冻结到原有规划任务。复用已注册执行器和现有 Owner 规划命令，不新增文字 Provider、不删除普通脚本规划，也不让未使用的规划设置阻塞 v2 直接准备。Owner 全局连接按 Adapter 的真实图片、视频、语音、音乐与音效能力分组；分组引用兼容连接，不复制秘密或改写连接历史。工作空间拥有本期默认与镜头当前选择，默认只预填，不限制后续选择。

Owner 明确提交时，服务端统一解析连接版本、Provider、Adapter、模型及参数，将创作上下文、输入文件指纹、目标版本和费用依据冻结到既有任务与候选机制。Worker 读取冻结输入，不重新读取蓝图工具设置；改选不改变运行中任务、旧候选或已采用素材。继续保留预算、幂等、未知提交恢复、Owner / CSRF 与原生工程冲突保护。连接当前版本轮换不改写已入队任务，已冻结版本仍须保持未撤销、验证资格和本机秘密绑定；执行时不自动换用新版本。

视频统一 AI 生成、Pexels 检索和上传。Pexels 使用查询、预览、导入与明确采用，不伪装成模型。历史 A-roll / B-roll 只兼容读取，不作为新工具的前置条件。

移除蓝图审核设置、检查 / 就绪入口和派生阻塞，保留实际脚本确认、候选采用、成片确认及执行和交付技术校验。历史审核不重写、不自动批准。

账号拥有独立实际资产根，生产单按稳定 ID 归档。复用授权根与路径校验，禁止跨账号同根、父子根和符号链接别名重叠。旧记录通过受控位置映射继续读取；有文件的账号改根必须经盘点、复制、指纹 / 引用校验、原子切换与失败恢复，保留原文件。全局数据库、秘密、共享运行程序及独立历史库保持原职责。

## 迁移与验证

以兼容扩展、逐渠道迁移、最后退役蓝图限制实施。只添加前向迁移，不改已应用迁移字节。已完成和归档生产单保持只读。

复用已确认的正式页面 / Owner HTTP → 真实数据库与持久任务 → 受控 Provider / 原生工程 → 隔离账号目录实际文件的主要验收边界。验证跨服务候选、冻结任务、费用与未知提交、字幕时序、账号隔离、迁移中断恢复、原生保存重开与交付。受控通过不代表真实供应商质量验收；不迁移日常目录、不调用付费服务。
