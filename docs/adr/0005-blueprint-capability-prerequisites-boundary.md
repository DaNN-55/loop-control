# 蓝图能力声明与运行前置条件分离

为支持蓝图可保存而不把机器状态或秘密冻结进生产单，账号蓝图只声明当前五项可选能力（静态视觉 / 图片生成、A-roll、B-roll、旁白和配乐 / 音效）、Provider / Adapter / 模型 / Prompt 等静态执行配置和每项能力的非秘密凭据引用；凭据档案归 Owner 所属工作区而非单个账号，实际秘密、Endpoint、文件读写能力和运行并发由 Worker 平台持有，Episode 只冻结这些声明和引用。
生产前检查由 Worker 返回统一结果，至少说明能力、检查项、状态、原因、可执行动作和影响范围：静态配置或凭据引用缺失/无效可编辑蓝图并修复受阻 Episode，临时连接故障可重试，Worker / Provider 未注册、模型无权限、凭据缺失/失效或有效资产目录不可访问交给环境管理员；草稿保存不受这些运行态失败阻断。
核心生产步骤不进入能力开关；视觉规划将收敛为视觉资产准备。本决定不实现前端秘密录入、连接管理器、自动故障转移或新的 Provider，未启用能力及未选择的连接也不参与生产前检查。
