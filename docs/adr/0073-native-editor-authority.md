# ADR-0073：原生剪辑工程决定最终成片

日期：2026-11-19。状态：接受。依据：Owner 明确要求删除全部补充工具，原生导入和编辑为准，文件归档与保存核验后台完成。

## 决定

分镜台建立初始工程。首次进入剪辑时，将已有准备页的声音开关落实到原生轨道，再把工程标记为 `loopControl.editorAuthority=native`，数据库保存对应 `editor_authority=native`。此后画面、声音、字幕、时长和导出均读取当前原生工程。原生新增片段可以没有分镜身份；允许删改原画面，保留主动设置的背景和时间线空档。

删除整个补充工具、上传重定向和宿主媒体/字幕改写桥接。宿主只协调真实保存、返回准备页和交付；原生素材池、字幕、撤销/重做和 Agent 继续采用 SDK 交互。保存先等 SDK 写入成功，再登记不可变工程版本；同一 iframe 节点保持不动。

保存和恢复时，将本期 SDK 上传目录中的图片、视频、音频按流式 SHA-256 复制到本期不可变素材目录，并在同一 Owner 事务中登记素材。保留原生 URL 映射与归档回执，重复保存不重复登记；临时上传丢失可从已核验的归档恢复。路径归属、目录身份、普通文件、真实字节与并发版本检查继续有效。无法归档的格式或不完整上传会明确阻止确认保存，原始 SDK 工程保留以便处理后重试。

返回修改脚本不自动重建已有原生工程，不以旧字幕确认、旧镜头数或旧素材绑定阻止最终保存、导出与交付。只有明确重新规划才替换初始制作依据，并回到准备态。数据库迁移 213 只放宽已进入原生编辑的保存/交付与观察记录，生成授权仍使用原有制作基准校验。

## Agent 连接

复用 SDK 原生 Agent、工具执行、所有权、保存和对话记录。已有 OpenAI / DeepSeek 连接经本机 `StudioAgentBridge` 接入；真实密钥只在服务端按请求从 Keychain 读取，SDK 仅持有临时本地能力凭证。每次发送重新核验 Owner、生产单、当前连接版本、在线验证资格和已启用模型；只允许两个已接入的供应商固定 API 路径。关闭剪辑台撤销凭证，凭证最多八小时有效。SDK 供应商设置、CLI 和外部 MCP 的原生入口保留。

SDK 一个供应商只有一个连接槽；同一供应商多个可用连接时采用首个，并提供该连接已启用的全部模型。连接或模型设置变化后需保存返回并重新进入剪辑。文本调用沿用原生 Agent 的主动发送交互；工作台的图片/视频/语音逐次确认合同不因此改变。

## 影响与验证

此决定替代 ADR-0015/0016 及剪辑承接方案中“旧分镜基准约束最终工程、剪辑页补充工具、逐条字幕确认”的部分；初稿准备、供应商生成、不可变历史、跨生产单隔离、真实文件指纹和最终文件确认继续有效。
