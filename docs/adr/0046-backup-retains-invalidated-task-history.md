# ADR-0046：备份保留已失效终态任务的未知历史

状态：Accepted。日期：2026-11-12。

旧视频请求被上游修改失效后，任务可以正确结束为 failed，但仍保留供应商已接收、费用未结清的事实。账号目录占用判断同时保护移动、删除和供应商恢复，直接复用到备份与空库恢复，会让此类历史永久阻止完整备份。

备份与恢复沿用原占用判断，只在存储归档边界排除满足全部条件的历史任务：已失效、状态为 failed 或 blocked、有结束时间、任务租约为空、没有 running 尝试、没有原生产物发布保护。其他占用原因继续拒绝。数据库快照、两次素材指纹盘点和原生 Studio 占用检查保持。

归档保留原始状态、冻结输入、供应商 ID、提交事实、费用账本和暂存文件；恢复不补写成功、不清账、不重发、不让历史任务恢复执行。账号目录移动与删除继续使用原有严格判断。本决定补充 ADR-0008 的完整备份要求，不改变 ADR-0023 的发布未知保护。

代价是恢复后仍可能看到待人工核对的供应商历史；成功恢复只证明这些事实和素材被完整保存，不能证明供应商结算已完成。持续阻止所有备份会增加数据无法保存的风险；伪造任务成功或移除未知事实会损害追溯，因此均不采用。

验证：真实 PostgreSQL 集成覆盖有效未知请求、未结束尝试、租约和发布保护仍拒绝；失效终态历史可完整备份恢复，恢复前后任务/提交字节不变，账号目录严格占用仍存在。另用前轮真实 API 样片复验。
