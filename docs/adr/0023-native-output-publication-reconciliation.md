# ADR-0023：原生产物发布未知结果的显式核对

状态：Accepted。日期：2026-11-02。

原生产物发布同时涉及文件替换和数据库结果登记。数据库 `COMMIT` 的回应丢失时，进程退出无法证明失败；普通失败回报或租约回收重排任务可能重复调用 Provider，也可能覆盖已登记产物。因此，在文件发布事务前持久登记当前任务、尝试和租约的发布保护，成功登记结果时在同一事务移除保护；能够确认安全回滚时单独解除保护。无法确认时保留文件、旧版本备份和私有发布凭据。

沿用 `tasks` 和 `task_runs` 的状态、租约与冻结输入权威，不新增队列或任务状态枚举。保护中的未完成任务仍为 `running`，普通失败回报、自动租约回收及转为 `ready` 均不能绕过保护。原生 Worker 必须先验证 SQL133 的权限，再执行生产任务；父子进程以绑定任务和尝试的专用消息传递发布未知结果。

显式恢复只接受任务 ID 和尝试序号，从数据库解析租约和当前位置，继续核验目录身份、冻结输入、凭据指纹、候选及旧文件。恢复可以为同一受保护尝试续租，不领取新尝试、不执行 Provider；数据库已完成时核对结果，未完成时登记原凭据中的结果。凭据缺失、损坏、输入或目录变化均拒绝自动恢复并保留现场。代价是异常任务可能需要人工核对；这比根据进程退出猜测结果并重发更可靠。操作见 [恢复说明](../agents/native-output-recovery.md)。
