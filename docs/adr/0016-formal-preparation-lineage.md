# ADR-0016：正式四步入口与制作依据

> 当前 A-roll / B-roll 工具路由及蓝图规划技术选择由 [ADR-0018](0018-per-request-production-and-account-storage.md) 替代。下文保留原决定的历史语境；不可变任务、连接秘密、权限和原生工程原则继续适用。

- 状态：Accepted，实施与验证见 #165
- 日期：2026-10-30
- 替代范围：ADR-0015 的临时 opt-in 入口、ADR-0014 的六步可见流程；历史决定保留。

正式入口统一为脚本确认、素材准备与匹配、剪辑工作台、检查与交付。导航只读，不按页面顺序写批准、任务或阶段。首次生成在准备阶段明确提交，剪辑阶段允许局部候选比较和采用。

`workspace_preparations` 记录实际计划产物和 Owner 确认的主脚本来源；`workspace_shot_inputs` 按工作空间、准备版本和稳定镜头保存来源、不可变基准正文和明确选定的能力。来源包括 v2 已编写段落、原规划 Adapter 的真实产物、已有合法历史分镜和原生新加镜头。新增镜头的主脚本基准正文为空，局部正文独立记录；不能改写旧脚本或造旧分镜批准。

普通脚本继续用蓝图已选 Codex Adapter、模型、Prompt Harness、预算与工具，经过真实任务、产物验证和明确匹配确认。v2 编写的段落可直接形成可验证的计划文件。准备产物沿用 review package 的不可变文件引用，但不代表旧阶段批准。脚本确认不再以先有视觉素材为条件。

原生工程仍是时间、轨道、裁切、构图、声音和字幕的唯一编辑权威。准备表保存生成输入与来源，不保存另一份时间线。当前主声从实际原生路由读取，候选只有明确采用才改变工程；采用正文绑定真实音轨和不可变任务版本。

首次切换若发现旧 Studio 持久文档，必须先保留可恢复快照及来源映射，由 Owner 明确选择保留编辑或封存另起。GET 不做恢复或迁移。已切换工作空间的旧任务可以完成历史文件及账务登记，旧审核触发器和发布完成命令不能推进当前生命周期；新完成仅由确切已确认导出的真实交付验证产生。

测试库使用同一只读快照中的 schema 和技术迁移记录，检查已应用迁移 SHA，仅对新随机数据库执行尚缺的前向迁移。日常数据、凭据、原片和已安装 SDK 不因此改写。受控 Provider 验证说明执行协议和实际字节链路，不代表实时付费服务或语音质量已验收。

## 2026-10-30：原生编辑与一次成片确认

Owner确认第三步以原生剪辑器为主。外围补充工具默认收起，仅保留生成、候选版本、素材登记与字幕声学对齐；字幕正文、样式、布局和普通混音由原生控件编辑。首次打开按冻结输入组装可编辑字幕，后续重开不覆盖原生修改。

原生保存同步实际字幕cue的时序证据，不伪造人工正文审批。有效的原生手工校时可直接参与技术导出；仅音轨或片段变化而cue未调整时，旧时序仍失效。第四步明确“确认成片与字幕”，在校验同一工程版本、导出字节和当前字幕后一次记录正文核对，取代逐镜头重复确认；变更内容后旧成片不能继续交付。未对齐、缺失或越界字幕继续阻断导出；关闭或删除的字幕以实际原生工程为准。
