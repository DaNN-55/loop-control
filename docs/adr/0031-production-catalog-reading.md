# ADR-0031：制作目录读取生命周期统一

状态：Accepted。日期：2026-11-09。Owner 已批准第六项架构优化。

画面、口播、音频与独立 Pexels 入口共用 `useProductionServiceCatalog` module，集中请求归属、取消、请求序号、focus、重试及读取状态。HTTP seam 复用 `localRequest`，使当前目录请求的 401 进入现有登录失效流程。client 在响应解析后、登录副作用前遵守 AbortSignal，已取消请求的迟到 401 不影响当前归属；目录结构只在读取 seam 校验。各入口保留媒体筛选、错误提示、选择、参数与草稿。

内嵌 Pexels 直接消费视觉父层的目录读取结果，模型显示、检索按钮、错误和重试使用同一快照，不再另发目录请求。保留独立入口时使用同一读取 hook。各独立读取实例仍分别拥有生命周期；不做跨入口／工作区／登录的缓存、TTL、后台轮询或全局状态库，不新增后端目录端点。

归属绑定当前读取实例及 episode／workspace，不绑定任意 revision、SHA、提示词或镜头草稿。重新激活、focus、手动重试与显式刷新触发当次读取；新读取取代旧读取，旧响应、错误与收尾不得覆盖新状态。scope 改变、停用、卸载或登录失效使旧读取失效，即使 transport 忽略 AbortSignal 也不能发布旧结果。Owner ID 不冒充登录会话标识，不导出新的认证 token；现有认证树和登录失效事件继续约束生命周期。

普通刷新失败保留上次展示和草稿，显示可重试错误；失效会话清除目录。目录刷新不自动换连接、模型或声音，不影响不依赖在线服务的上传。沿用 ADR-0020、0024，制作目录不是推理授权，实际提交仍由服务端重新解析并逐次确认。取消 fetch 不承诺撤回已到达服务端的 SQL，本次不承诺未测量的延迟收益。
