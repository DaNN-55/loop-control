# ADR-0052：删除无消费者的旧编排空壳

状态：Accepted。日期：2026-11-13。用户授权逐项检查 20 个旧编排空壳，确认不影响当前功能和历史恢复后删除，保留必要对象并说明原因，不放宽保护。

本决定仅替代 ADR-0048、0049、0051 中对下列无消费者编排签名的保留决定。日常库的有效函数体、结构依赖、当前源码与动态调用边界已核对：19 个无消费者空壳通过 172 前向迁移删除；原始基线、历史迁移、历史表和数据保持。使用明确签名的 `DROP FUNCTION`，不使用 `CASCADE` 或忽略缺失对象。

保留 `public.orchestrate_storyboard_tasks_for_episode(uuid)`：`public.request_studio_storyboard_revision(uuid,text)` 仍直接调用它。调用者先使审核包失效、更新阶段并写入状态转换，再调用空壳；空壳抛出 `0A000`，使整个事务回滚。当前 HTTP 命令已在归属校验后拒绝旧规划，但数据库仍保留该拒绝边界；本轮不改写调用者，也不把明确退役错误改成缺失函数错误。

保留不属于 20 个空壳的审核渲染、最终成片编排，以及 `local_identity.plan_input_tasks` 等拒绝入口。当前 Worker 使用封闭的领取/回写接口，`plan()` 不再调用旧编排；当前制作按显式请求入队。权限、Owner 归属、费用预留、旧快照领取过滤、冻结文件身份、发布恢复、租约和容量保护均不变。

历史恢复先恢复原始 schema 并核对原行、序列与 ACL，再执行当前前向迁移；19 个空壳不承载历史数据。验收覆盖迁移中断回滚、结构依赖阻止删除、完整旧格式逻辑导出恢复、全部未删除安全对象、当前制作与拒绝边界。逐项名单和实际结果记录在 `docs/verification/orchestration-shell-cleanup-20261113/REPORT.md`。日常应用前保留私有完整逻辑导出和对账快照；不重启服务、不删除旧库和恢复材料、不提交或推送。

后续：ADR-0053 在确认旧 Studio 结构修订入口本身已无当前消费者后，替代本 ADR 对最后空壳的暂时保留决定。该调用链按173一起删除；此处保留172时的决策依据，不再作为当前残留清单。
