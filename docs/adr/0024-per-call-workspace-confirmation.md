# ADR-0024：在线制作逐次确认

状态：Accepted。日期：2026-11-02。Owner 已确认取消「本期在线制作」独立开关，改为每次调用前确认。

分镜台和剪辑工具共用逐次确认入口。图片、视频、口播生成及在线音效检索先由服务端解析实际连接、模型、素材、正文和数量／时长，返回费用预留及有期限的确认记录。取消不生成任务、不预留费用；线下上传、采用已有素材和原声提取沿用原流程。恢复已有供应商任务仅查询原任务，不再次发起生成。

确认记录有效期为 10 分钟，绑定 Owner、生产单、脚本、工程版本和完整请求。确认接口接收记录标识、版本和可选的本次费用预留，不接受替换模型、素材或正文。同一事务重新解析并校验当前连接和输入，消费一次确认并创建任务。失效、参数变化或重复确认均不增加任务；命令原有幂等结果回放继续有效。

新任务绑定本次授权摘要，不写入整期启用状态。Worker 继续使用不可变执行快照；历史整期授权仅供已有任务兼容读取，不能绕过新调用确认。新排队授权只在消费确认的事务内有效，不能复制旧任务摘要取得新授权。在线音效重试展示原冻结连接和检索词，保留原连接版本，而不是静默换成当前默认。

保留现有单次费用上限、费用预留、任务租约、同镜头进行中限制、未知提交阻断及已保存供应商任务标识。费用预留不是供应商精确报价。已退役的账号累计预算不重新启用。

验证以隔离 PostgreSQL、真实 Owner HTTP、原生工程和受控 Worker 为准，覆盖取消、跨 Owner、过期、工程与连接变化、并发确认、未知提交及各媒体通道；浏览器检查真实表单与宽窄屏。测试不调用真实付费供应商。

2026-11-02 自动估算：服务端按已核对的模型价格、图片数量／像素／质量、实际供应商请求时长和口播字符数自动建议费用预留，附 20% 余量并满足现有最低预留。图片 token 费用采用明确标注的本地保守估算，未核实套餐／通道价格明确回退，不冒充供应商报价；美元使用注明的规划折算值，不作为实时汇率。所有估算在本地完成，不为读取价格发起供应商调用。

Owner 在确认框调整金额，服务端校验整数分、最低预留和单次上限，在消费确认、保存最终金额／授权摘要、创建任务的同一事务中冻结结果。金额调整不改变原确认的其他输入。估算依据和最终金额保存在确认记录中；已经排队的任务不受价格表或界面后续变更影响。
