# ADR-0042：生产单先入回收站，保留原关系与精确清理边界

2026-11-11，Owner 批准迁移紧凑列表回收站。正式删除入口先保存回收站成员关系，保留原 Episode ID、脚本、工程、任务、冻结快照和文件；归档保持独立。回收站期间采用既有归档执行栅栏，并在公共输入锁、任务资格与旧规划入口明确拒绝制作。恢复按原归档状态返回原账号与系列；已完成状态不倒退。父账号仍包含该 Episode，因此不能留下不可恢复的孤儿；本轮不增加系列删除能力。

不移动到一个新目录，也不复制来源文件：现有统一存储解析器继续拥有实际位置和迁移血缘。入站流式记录当前目录普通文件的 SHA256、相对路径、物理身份与真实字节；容量按 dev/inode 跨条目去重，包含受保护共享／未知文件的保守占用，不等同可释放容量。不跟随链接。GET 只读取登记和必要的目录身份，不递归扫描或重哈希大视频；恢复和清理时再次检查实际文件。

容量上限默认 5 GB，可显式保存为 0.1–1000 GB。只有新入站或明确保存上限触发 FIFO，升级、迁移和 GET 不触发清理。刚移入的项目、单项大于上限、共享引用、未知文件、离线、身份变化、活动任务／原生进程、未确认提交或待恢复文件均保留；超限明确提示。清理沿用 ADR-0001 的逐文件永久删除管线和持久 intent；预提交失败恢复，提交后待清理继续保留完整占用，直到文件清理回执完成。

同 Owner 的入站、恢复、上限与清理由持久会话 advisory lock 串行；入站／恢复和既有永久删除共享 Episode 删除锁。删除计划还绑定 Episode 状态、文件身份与版本，恢复后旧计划失效。普通永久删除仍保留精确确认保护；回收站的永久删除另外绑定成员 revision，显式输入名称确认。原 `LocalDeletionRecovery` 保留在“文件恢复与清理”，不隐藏旧任务。
