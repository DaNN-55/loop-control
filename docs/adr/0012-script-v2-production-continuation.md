# ADR 0012 脚本 v2 与审核后自动继续

状态：Accepted，2026-10-28，用户明确批准实施。

保留 Markdown 主脚本入口，v2 使用固定中文字段和受控枚举，口播、画面及视频提示词保持文本；导入解析与执行端共用类型和校验。默认、明确关闭、指定值互不混淆，未知字段不静默忽略。旧格式保持可读，不自动开启批量消费。

图片、视频首帧、BGM、音效全部使用用户上传材料。仅在当前生产单及当前账号可复用系列范围精确检索；歧义和缺失可保存草稿，但阻塞相应执行。引用冻结素材身份与哈希，跨生产单复用经原有导入边界建立本期不可变副本，不授予跨账号访问。

使用现有 Episode、审核包、镜头草稿、Worker 和本机调度。v2 解析结果作为制作输入，不建立平行审批状态机。显式设置落入现有生产契约，无法支持的值返回具体诊断。本期已确认修改优先于脚本，脚本优先于冻结系列/账号默认；硬约束和连接权限不允许脚本覆盖。

新增按主脚本哈希持久化的自动继续授权，默认关闭。确认启用后，本机服务只允许创建/执行生产动作，不自动调用审批动作；视觉、分镜、字幕正文、同步预览及 QC 确认关卡继续生效。所有自动动作必须校验当前 Owner 归属、脚本版本、审核版本与授权，使用确定性幂等标识，重启后依照数据库状态恢复。

ADR 0008 的逐次显式请求继续适用于未启用自动继续的旧生产单；新模式以已确认制作计划与预算授权代替逐镜按钮，沿用原有付费预算预留、供应商任务 ID 和未知提交停止机制。不得仅移除通用规划器的跳过逻辑。当前实施与验证不调用真实付费接口，不部署或启用日常生产单。

验收：六份真实脚本逐字段解析；缺失/重复/未知字段准确诊断；素材类型/归属/歧义/哈希检查；默认与关闭及用户覆盖正确；自动推进不越过审核、不重复付费提交，浏览器关闭/服务重启后可恢复；字幕/音量/衔接进入真实渲染工程。
