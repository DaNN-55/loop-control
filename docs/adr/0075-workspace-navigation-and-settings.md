# ADR-0075：统一生产单入口与按需设置

状态：Accepted。日期：2026-11-19。来源：账号、导航与设置精简 Q1–Q38 最终共识；独立剪辑按最后确认保留左下位置。

## 日常入口

工作台和生产单合并，默认进入生产单。旧 `operations` 书签规范化为 `episodes`，有效筛选及分页继续保留。列表提供只读基础预览，点行预览、点名称进入制作；统计与低频筛选按需展开，已应用条件始终可见。预览不启动制作、渲染或导出；详情、设置打开后停止背景预览和媒体播放。

左栏保留内容账号展开列表和新建入口。账号页只管理长期创作规则，不新增账号数据页。顶部保留全局搜索、待处理和设置；回收站回到生产单场景。全局搜索与列表搜索明确各自范围。

## 账号规则

新建默认只填名称，前端一次生成稳定标识并沿用上海时区，高级资料按需展开。通用规则为内容定位、说话方式、画面风格、内容禁区四类选填；额外、嵌套及未修改的历史类型无损保留。系列规则按需填写和查看，不强制建立系列。

普通保存直接执行并展示保存状态；现有生产单的冻结版本及覆盖、限制语义不变。版本号与内部资料降为按需查看。更多操作集中资料、打开文件夹、改名、归档和删除；保留未保存离开、归档和永久删除保护。

## 设置与服务

主分组依次为制作服务、文件存储、界面与通知、登录与安全、维护工具。系统状态、日志和全局高级密钥归维护工具；左下状态仅为同一页面的快捷入口。取消自定义头像和显示名称的编辑入口，但保留历史数据；界面和通知统一保存，不重置原选择。

制作服务同时管理生成和素材检索连接，正式检索、口播制作及试听仍在生产单。保存并验证由明确按钮串联；豆包固定短句验证注明额度影响，并保留仅保存。默认模型范围不改，不静默启用供应商全部模型。按需配置保留原制作位置和输入，使用并返回时重新核对准确连接版本和模型；不自动生成、不重试结果未知请求。

连接版本、执行快照、Keychain 绑定和逐次秘密查看权限继续沿用 ADR-0011、ADR-0020、ADR-0022。保存成功但验证失败不撤销保存事实，也不把下一次验证变成重复创建或轮换。

## 存储状态

媒体根读取新增 `initialized`，仅表示当前是否已有实际绑定；`canInitialize` 继续表示工作区为空时允许初始化的能力。两者不能互相替代。首次必要设置依据绑定状态引导，已绑定空工作区可直接创建账号；已初始化的更换位置仍通过盘点、确认与迁移/恢复流程。目录身份、容量及权限校验不变，不新增 schema 迁移。

## 独立剪辑

左下现有位置命名“独立剪辑”，始终以新标签打开 Owner 专属原生工程首页。无需内容账号或生产单，不自动新建或覆盖工程；复用原生多工程、导入、自动保存、历史版本和导出。关闭标签不删除工程，不加入自动清理，也不并入生产单回收站；原生永久删除保留清楚提示与确认。

生产单内的剪辑入口继续打开该单工程。完成作品修改仍遵循 ADR-0074 创建新生产单，与独立工程库的临时剪辑用途分开。
