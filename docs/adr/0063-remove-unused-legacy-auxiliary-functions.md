# ADR-0063：移除最后四个无消费者的旧辅助候选

状态：Accepted。日期：2026-11-13。

用户授权检查旧历史计划及其业务指纹、旧账号配置锁和旧冻结镜头源音频派单函数，只有当前功能、保存运行包与历史恢复无依赖才删除；不删除历史数据、不放宽保护、不提交、不推送。

日常 182 中，`history_episode_delete_plan` 仅调用同组的 `history_episode_business_revision`，后者没有其他调用者。`lock_owned_account` 与 `queue_frozen_shot_source_audio` 无当前代码或有效 SQL 消费者。四者均无传入目录依赖；23 个不可变保存运行包无精确标识符引用。原前缀扫描命中实际是 `lock_owned_account_row` 等现行锁，不能当成本组函数。当前历史／业务删除引用锁、Owner／会话、账号存储锁、源音频提取与旧回执续处理均走保留路径。

183 按计划→指纹的顺序，以默认 RESTRICT 删除四个明确签名；无 CASCADE、数据 DML、权限授予、触发器拆除或历史 SQL 修改。没有陈旧客户端类型需要删除。本组无必须保留目标；下游共用引用核查、历史视图／行、冻结保护、当前账号 row／directory 锁及旧运行包兼容契约保持。统计启停 SQL 仍属既定人工授权边界，不因无页面调用删除或启用。

验收采用非空历史来源／版本／文件／保护／旧回执，以及真实已确认冻结的 source 草稿、完成音轨和失败运行包，完整导出恢复后严格比较所有原行／序列／角色／其余目录和 ACL；覆盖四种真实依赖阻断、失败回滚、幂等、冻结篡改拒绝及实际文件字节。当前账号修改／目录操作、源音频制作、回收／删除、旧回执与保存包模块及发布恢复另行集成验证。完整备份、候选恢复演练和无漂移复核后应用日常，保持采集关闭、不重启。报告 `docs/verification/residual-helper-cleanup-20261113/REPORT.md`。
