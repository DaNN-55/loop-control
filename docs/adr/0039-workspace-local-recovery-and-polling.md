# ADR-0039 工作区局部恢复与轮询生命周期

状态 Accepted。日期 2026-11-11。用户批准状态机优化 0—4 项，当前分支本地提交。

## 决定

连接模型、偏好与字幕操作按本次访问管理结果及收尾归属，同步互斥覆盖同周期重复事件。字幕操作保存冻结意图与已完成阶段，原生保存成功后，后续读回或服务端登记失败从未完成阶段继续；继续前重新读取当前工程，核对工作版本、脚本、字幕及原生文档证明。恢复原服务端命令时沿用原数据与幂等回执。原生字幕已应用而服务端保存未确认时，Studio 依据同一文档指纹继续原保存。变化的文档要求重新核对。

上传的会话、队列执行和素材导入回执由局部共享模块管理。素材栏与候选区分别声明接收规则及导入后的动作；成功素材可以继续登记候选，旧页面结束后保留队列的未完成责任，成功队列按消费情况释放文件引用。

纯读取轮询按页面可见性暂停并在恢复时读取权威，与显式读取共享在途互斥。口播和音频刷新含原有服务端处理，保留命令顺序和幂等语义，页面生命周期管理等待与调度。

后续第 5 项将相同的局部恢复原则用于规划设置：全局／本期保存消费命令已确认返回的配置和 revision，省去多余客户端读回；Harness 登记后的列表读取失败保留已创建版本，继续同一输入仅重新读取。同步锁和访问清理保护异步收尾，管理弹层关闭后不自动选择旧回包。服务端 revision 与既有命令协议保持。

第 9、10 项继续沿用局部权威：创建生产单、生命周期写入与模型保存的成功回执独立于后续目录读取。界面立即接受已确认结果，读取失败保留成功事实与重读入口，重读不重放写入；真正写入失败仍保留原输入及幂等意图。连接目录读取以当前访问、请求顺序和取消信号共同保护数据与反馈，成功的新读取清除旧错误，结束访问使旧读取失去发布资格。服务端连接资格、版本和秘密协议不变。

## 验证

使用真实公开组件和 Studio 宿主，控制 HTTP 及 iframe 消息边界。覆盖部分成功、断网、切换及重新打开、迟到回包、同周期重复事件、版本变化、隐藏恢复和宽窄屏。已有任务恢复及持久状态继续通过现有事务和测试入口验证。
