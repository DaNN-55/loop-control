# ADR-0076：分镜台批量生成的确认边界

状态：接受。日期：2026-11-23。所有者已认可交互原型，实施规格见 [GitHub #240](https://github.com/DaNN-55/loop-control/issues/240)。

所有者一次确认同一生产单、同一生成类型的一组镜头。系统按确认清单将整组授权与任务一并写入，提交时复核影响授权的输入、资格和费用。任何待提交项变化时，整组回到核对页。这样一次点击能精确对应所有者看过的费用和任务范围。

入队后每镜沿用独立的执行快照、费用预留、任务状态与候选。局部失败按原请求状态逐镜恢复，回执未知先查原任务。逐镜采用继续沿用当前流程。相关约定见 [ADR-0024](0024-per-call-workspace-confirmation.md) 和 [ADR-0043](0043-request-outcomes-and-receipt-recovery.md)。
