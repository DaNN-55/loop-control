# ADR-0069：独立的制作里程碑与覆盖区间

状态：Accepted，依据已批准规范 C1／C2 分步实施；日期：2026-11-14。不应用日常，不启用采集，不提交或推送。

保留原数据库 `stage_changed`／阶段驻留指标。新增 `workflow_milestone`，协议 `workflow-milestones/v1`，由实际业务事实写入：新单建立、主脚本实际保存／确认、独立工作区建立、SDK 成功打开／内容变化保存、精确导出与确认。已有 `delivery_completed` 作为已验证交付结束事实。页面切换与读取不推进制作阶段。

数据库事实通过专用统计触发器与原业务同事务记录；SDK 事实在真实操作、文件核验和当前版本持久化后，通过受控函数记录。`native_edit_revision` 还用于字幕、采用和结构保护，不能将其增加自动解释为开始剪辑，既有计数器语义不变。

新单和主脚本实际登记／修订对应脚本阶段，确认后为准备阶段，实际 SDK 编辑为剪辑阶段，成功导出／确认进入交付阶段，交付完成结束该次已观测区间。重复打开相同版本不重复记录；采集重新启用后，新的实际打开可以开始新的覆盖内观察，但不补录停用期间的编辑或旧单创建。内容变化、脚本改版和再次编辑可以返回前一阶段，不自动判为质量返工。

只读汇总新增独立制作观察字段，原 stage、候选、费用、队列和资源字段含义不变。仅合计同一生产单、同一采集覆盖期内有起点证据的经过时间，包含人工等待和其他并行工作，不是独占劳动／CPU 时间；交付、停用、未知协议和观察窗口均结束或截断区间。没有证据的阶段为 null，不以 0、当前页面或旧数据库阶段补造。读取窗口之前的最近制作锚点只用于已观测区间裁剪，不计入窗口内次数。

事件只含协议、机器原因、关系 ID、版本号和哈希，不记录正文、文件路径或秘密。Owner／账号／生产单、当前基准、历史与回收站栅栏、RLS／ACL 保持。内部追加与触发函数不对普通角色开放；SDK 入口仅对认证后端开放并复用当前工作区保护。关闭采集不产生事件，不借统计改变业务或授权重发 Provider。

C2 的完整声音使用、同步本机导出活动及资源覆盖仍单独实施；不能以里程碑存在宣称 C1／C2 或全项目已完成。最终需真实命令幂等／失败／回退／停用、跨 Owner、非空升级／回滚／恢复、查询边界及独立审查。
