# ADR-0037：四步工作区操作转换

状态：Accepted。日期：2026-11-10。Owner 批准状态机第 5 项，不提交、不推送。

## 决定

在局部 `useWorkspaceOperations` 集中准备、打开、保存、关闭及其异步转换。操作状态为 ready、preparing、opening、editing、saving、closing；每次进入生产单具有独立 owner，同步状态兼任互斥守卫。保存或关闭失败回到同一 editing 会话，打开失败恢复原会话或 ready；准备失败回到 ready，保留原草稿与工程。没有通用状态机、依赖或新持久化协议。

导航步骤、只读、加载、工程有效性和稿件状态仍由原入口负责，不合并进操作枚举。浏览器返回／深链接改变查看步骤时，结束待打开的本地意图，保持在途互斥直至返回。成功的完整工程读回仍通过 owner／来源／revision 守卫更新当前工程，但不创建新会话或更改步骤；报错则触发原加载流程恢复，不重发打开命令。已发出的服务端命令不能撤回。卸载或切换生产单后，旧操作不能发布工程、导航、会话或错误；回到生产单由原权威读取恢复，不自动重发命令。

原命令及参数保持，准备保留首次／replan、旧工程 preserve／fresh 决策及兼容响应提示；打开仍检查占位和缺失来源。保存仍先由真实 EmbeddedStudioHost flush，再以来源工程、预期 revision 和文件 SHA 保存；关闭是独立命令，成功后才退出会话并恢复所选镜头。失败保留当前编辑器及原错误恢复路径，不重建工程、不放宽只读、stale 或恢复限制。原 legacy adopt 与内容、导航和读取协议保留。

## 验证

以 ProductionWorkspacePanel、真实导航上下文、EmbeddedStudioHost 消息和命令为公开接口；不 mock 操作模块。验证深链接、刷新、返回、延迟打开、重复操作、准备／打开／保存／关闭失败、保存后关闭使用最新 revision 和返回镜头。浏览器使用真实宿主及受控 iframe 协议／HTTP；不将模拟 iframe flush 描述为真实 OpenChatCut 持久化验证，不操作正式数据或供应商。
