# ADR-0021：按协议接入百炼首帧视频模型

2026-11-01，Accepted。沿用现有连接、模型设置和制作选择器，通过共享的已核实模型契约描述时长、分辨率、声音与请求参数；本期只接入现有 `input.img_url` 异步首帧协议兼容的万相模型。文生视频、参考视频和新版media协议继续禁用并说明原因，目录返回名称不自动授予任意执行协议。

补充ADR-0020：显式读取目录后仅持久化已适配模型ID及对应凭据版本、读取时间，用于再次打开、启用和制作选择；不保存原始目录或秘密。未设置仍仅启用原wan2.6-i2v-flash，不自动扩大已有选择。启用范围与原有快照不变，Worker按冻结模型的共享契约执行，不读取可变目录或启用范围。新提交采用Owner明确费用预留，不能把原flash的每秒15分假设套给其他模型。

账号费用与限额迁移到账号通用规则中的创作规则下方，使用同一个保存按钮、确认框和Owner配置事务；任一校验失败全部回滚，撤销恢复两类草稿。账务数据仍属账号预算控制，不写入版本化创作蓝图；系列继承摘要移除，但实际创作约束和历史快照保留。存储重叠提示列出实际冲突目录，不放松迁移保护或自动执行迁移。
