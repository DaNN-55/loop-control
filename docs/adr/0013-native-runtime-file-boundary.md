# ADR-0013：原生运行入口与项目文件边界

状态：Accepted。日期：2026-10-28。Owner 已认可逐项清理审计并授权实施；不提交、推送或操作现行业务数据。

## 决定

沿用 ADR-0008 至 ADR-0010 的原生本地架构，将其作为唯一可运行链路。删除退役的 Supabase/n8n、旧 App/控制面、远端发布和编排 CLI；当前界面、Worker、审核、冻结、权限和费用语义保持。

- `scripts/runtime/` 管理当前启动、应用装配、配置、秘密和迁移；`scripts/storage/` 管理共享备份格式、schema 适配、ACL、完整性与显式上下文恢复。阶段性隔离脚本退出维护。
- `src/local-app/main.tsx` 是静态前端入口。共享视图的缺省命令契约合并为 `src/lib/viewTransport.ts`，它只会拒绝未装配访问，不能创建客户端或发送网络请求；`contract` 后端仅供显式回归夹具，默认构建固定为 `local`。
- 当前任务消费者要求实际数据库端口与执行器，不再回退 REST 或旧 CLI。规划、并发、租约、重试及结果回写继续通过同一持久队列。
- 运行准备校验 `dist/worker` 和 `dist/local-app`，不再要求生成退役程序。清单版本升级，源码变化或编译失败时拒绝运行。
- 保留 `db/local/` 原始字节和 SHA；有效目录 SQL 参考契约迁入 `db/contracts/`，旧迁移补丁重放测试随旧迁移退役。当前功能测试继续保留。
- 历史验收保留结论、失败/豁免、关键证据和删除/恢复清单；重复源码、截图和完成日记归并。根 PLAN 只保留当前进度及接续点。

## 保留的数据边界

`.loop-control/local/` 中的媒体、秘密、历史正文、别名、运行状态和数据库卷仍是现行数据。文件清理不将“旧”视为“无引用”，不自动删除已存储版本或迁移用户工程。

## 验证

默认回归与清理前基线对照；类型检查；当前后台/Worker 和原生前端构建；一次性空库从本地基线和全部编号迁移重建；有效 SQL 契约的隔离 HTTP/实际数据库角色验证；只读页面及架构地图检查。结果及已知失败见 ../verification/project-file-cleanup-20261028/REPORT.md。
