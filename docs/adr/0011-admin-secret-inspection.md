# ADR-0011：管理员秘密查询与单项读取

状态：Accepted。日期：2026-10-27。Owner 已明确授权在当前主程序实施；不新增真实秘密、备份或付费调用，不修改现有密码与 Keychain ACL。

## 权限边界

Owner 是内容账号所有者，不等于全局管理员。可信、私有的日常运行配置 `secretAdministration.adminOwnerId` 单独指定一个现行 Owner ID；缺失或非法配置时关闭本功能。前端只接收服务端计算的能力布尔值，列表、详情、明文读取分别复核配置 ID 和有效会话。数据库全局引用核查函数只授予可信 `loop_app`，不授予 Owner/Worker；应用角色仍不能更新或删除审计。

每次单项查看或复制都重新验证数据库现行 scrypt 密码摘要，沿用凭据失败计数和 5 次失败锁定规则；使用 POST、精确 Origin、会话 CSRF、每管理员频率限制，密码行持锁至审计提交，并在返回响应前复核有效会话。明文只来自现有专用库的固定 helper/UUID 接口，未知 UUID 拒绝；不开放路径、服务名、命令或文件下载。

## 元数据与存储

按当前运行配置、命名索引及别名、实际连接绑定/未完成意图、历史结构化引用、保护映射与受保护文件中的 `keychain:` 标记计算引用。文件内容只在内存中扫描引用标记，按不可变内容 SHA 缓存引用集合；索引、别名和数据库元数据每次重新读取。接口返回名称、用途、分类、引用及核查时间，不返回数据库口令、密码摘要或文件正文。

系统解锁锚点不属于可读取的 UUID 条目，仅返回固定用途说明；现行应用/Worker 数据库控制凭据也只提供元数据。同值别名继承控制秘密的保护状态。

明文不迁入数据库。审计只追加操作者 ID、服务端时间、合法 reference、list/detail/view/copy、success/denied 与固定原因代码。频率窗口为独立非秘密表，不复用业务审计或已有历史任务。

## 浏览器与验证

明文响应 no-store；页面不使用持久浏览器存储或 URL 传递敏感内容。切换条目、关闭页面、隐藏标签、退出或会话失效时清除密码/明文并取消在途请求；查看最多保留 30 秒，复制完成立即清除页面明文。剪贴板仅由用户点击触发浏览器 Clipboard API 写入，不使用服务器 pbcopy。

通过隔离的真实 PostgreSQL/HTTP 测试验证认证、授权、CSRF、限流、会话撤销、未知引用、系统控制条目、Keychain 失败和无秘密审计。实际 Owner 当前密码若不可取得，由用户在正式页面输入；不从过期登录材料重置或绕过认证，生产明文不进入截图与测试输出。
