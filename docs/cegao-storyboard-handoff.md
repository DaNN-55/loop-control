# 策稿制作包：导入分镜脚本

交接仍采用同机版本化文件夹：

```text
handoff/in/<handoff_id>/v0001/
  script.md
  images/front.png
```

策稿交出的 `script.md` 保留 `loop-control-handoff/v1` 文件头和 `## 脚本` 章节；章节内必须是 Loop Control 模板版本 3，包括每镜的明确时长。图片在 `product_images` 中列为 `images/<文件名>`；镜头的 `素材名称` 写同名文件的文件名，不带目录。`## 商品事实` 是可选的人工检查资料，不混入主脚本。

1. 在 Loop Control 选择账号、系列，新建生产单。
2. 在「脚本确认 → 上传脚本」直接选包内 `script.md`，不用删文件头或剪贴正文。上传时先验证交接文件头、镜头格式、时长和引用名是否存在于清单，失败不覆盖现有草稿。普通 Markdown 和文本的上传方式不变。
3. 检查正文后，选择「保存待确认脚本」，或在明确要开始时选择「继续制作」。上传不是开工，不发起模型请求。
4. 按需在分镜台导入同包图片并应用到镜头。目前上传只读单个脚本，不会读取相邻文件、自动挂图、写回执或重复建单。

收到新版本时保留旧包，例如用 `v0002` 交付修订，并由操作者决定接到哪个生产单。完整交接的一键接收、跨设备同步仍不在本说明范围。
