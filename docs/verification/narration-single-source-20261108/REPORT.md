# 口播单文案与极简播放器

已更新本机正式服务。当前后端、Worker、准备产物版本一致，状态为 current；参见 runtime.json。

## 行为

- 一份“口播文案”用于生成；点击生成时记录输入。编辑或生成不会替换已采用声音及其字幕。
- 新镜头字幕默认跟随口播，首次明确采用时创建跟随字幕，后续采用使用该候选冻结文案。既有独立或关闭的字幕保留，可显式改为跟随。
- 准备页移除字幕模式与单独保存字幕，保留原生剪辑台已有字幕编辑能力。
- 齿轮统一为整期 TTS 设置，用于后续生成；保留音色搜索、试听与历史请求快照。
- 候选使用“文案 + 下方播放条”，支持原音频播放/暂停、键盘和拖动进度、采用、撤销及历史文案确认。已采用状态仍为绿色 tag。
- 操作统一显示“采用”“撤销”；删除候选下方的时长不匹配常驻说明。

## 兼容与迁移

154 迁移只替换两个已有口播保存函数，不更新已有业务行。旧字幕输入、启用状态及独立合同在保存口播时保留，新建输入使用原脚本文字并默认跟随。迁移前后全部 shot_preparation_drafts 行指纹一致（deployment.json）。保留旧函数定义于 previous-narration-functions.sql；遵循本机既有关闭自动备份的设置。

跟随字幕的初始时序是镜头/声音窗口中的种子时序，未声明声学对齐或人工核对已完成。完整采用确认、恢复历史文案核对和校时能力保持。
