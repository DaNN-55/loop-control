## Changes

- 在 DOM autoFocus 提交前记录入口；普通表单默认可输入字段，支持 data-dialog-initial-focus。新建生产单明确聚焦工作标题，ConfirmationModal 明确聚焦取消。
- 弹窗栈让 Escape/Tab 只由最上层窗口处理，包含子窗口等待状态移除活动按钮、焦点落到 BODY 的情况。
- Escape、取消、保存成功回到仍连接且可用的入口；入口消失时先回到剩余弹窗，否则回到 main（可用 data-dialog-focus-fallback 显式指定）。
- 新建生产单捕获提交异常并在当前表单 role=alert / aria-describedby 显示，保留标题供重试；自身提交 Promise 未完成时禁用重复提交与关闭。
