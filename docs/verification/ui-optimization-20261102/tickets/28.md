## 修改路径与行为

- `src/local-app/LocalHistory.tsx`：`totalHistory` 判断真正空库；与搜索、归档范围、仅有内容过滤造成的空结果分开。真空库提供只读重新读取；无匹配提供重置历史筛选，明确清空提交关键词、全部历史、关闭仅有内容、页码回 1。显式搜索按钮与 Enter 共用原读取；原详情、归档及删除协议不变。
- `src/local-app/HistorySources.tsx`：用已有不受筛选影响的 Owner sourceCounts 判断独立资料空库；无匹配保留输入/分类/范围，只有点击重置才清除并回全部来源。来源内容区分别说明没有登记文件/记录与内容搜索无匹配，提供显式搜索和清除内容搜索。真空库只读刷新保留已提交查询与页码。
- 两个面板说明生产单历史留存、独立导入资料与生产单列表归档分别管理，并提供实际查找入口。
- `src/local-app/historyEpisodes.ts`：同一已授权 Owner catalog CTE 增加 `totalHistory` 基础计数，在 query/contentOnly/archive/page 之前计算。它不含已永久删除的条目，不额外全量读取、不改变留存或过滤语义。
- `src/local-app/catalogNavigation.tsx`：仅本票 optional `openArchivedProductions` / `openHistorySources` context callbacks；保留 10 的全部 search URL 字段与内存 open 字段。
- `src/local-app/LocalCatalogApp.tsx`：归档入口导航到真实生产单 `visibility=archived`，清除会遮蔽归档作品的标题/账号/系列/状态并回首页；保留 history/source panel 全部查询和页码。归档生产单页提供返回独立历史资料入口。所有 view/filter/episode/panel 效果通过现有 `navigate` 的 `requestDraftLeave` 回调执行。保留 10 的 `WorkspaceTopbar ownerId`。
- `src/local-app/history.css`：只增加范围说明/链接的同表面换行布局与内容搜索窄窗换行；无新卡片、主题或依赖。
