## 具体改动与之前的差异

- `src/accounts/AccountWorkspace.tsx`：原弹窗仅按生产单总数禁用确认，并显示一段长说明和不可用的名称输入。现在打开时读取真实条件：生产单数量（含已归档数量）、未完成清理、未完成目录创建；对应提供「查看生产单」「查看清理任务」「归档账号」「重新检查」。受阻时不显示名称输入；无阻断时保留完整名称确认。
- `src/local-app/LocalCatalogApp.tsx`：查看生产单会切到该账号的全部生产单，包含归档，清除搜索、状态和系列等残留筛选并回到第1页。查看清理任务会打开4.2入口并定位原任务；归档仍走既有确认流程。
- `src/local-app/accountDeletion.ts`、`localRoute.ts`、`configurationCommands.ts`及纯类型`src/accounts/accountDeletionStatus.ts`：新增Owner只读GET `/api/local/account-deletion-status?accountId=...`。数量来自完整数据库，不从当前页推算；状态预览和原删除命令复用同一未完成操作查询。只有清理待完成、生产单已经消失时，前端也会阻止确认，避免等提交后才被后端拒绝。
- `src/accounts/account-deletion.css`：阻断项一行对应一个入口，窄窗自然换行；沿用既有确认框和按钮。
- 读取中／失败时禁止确认，失败提供重新检查；异步旧响应不会覆盖新检查。服务端仍在真正删除时再次检查，预览不构成删除授权。不新增账号级联删除，不改变归档或文件归属规则，不新增SQL迁移。
