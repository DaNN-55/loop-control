仅隔离 Owner 开启采集，日常开关未操作。以下计数严格限定本单 `episode_id`，不把夹具其他生产单混入。

| 操作事实 | 本单事件 |
| --- | --- |
| 创建 | `episode_created=1` |
| 制作步骤 | `workflow_milestone=8`：建单、脚本保存、脚本确认、准备、打开编辑、保存原生编辑、导出完成、确认导出各 1 |
| 音轨与声音 | `candidate_adopted=2`；`sound_used=3`，对应两条口播和一条配乐，两个指标不能相加作为素材采用总量 |

| 交付 | 入队、领取、attempt 开始／结束、交付完成各 1 |
| 保存和应用重开 | 既有事件保持，不重复计数 |

同版本额外验证覆盖：

- 采集默认关闭、关闭期间不记、重新开启不补造历史，跨覆盖期不编造导出开始／时长。
