## 最终行为

- 共用顶栏下方的紧凑通知区，居中、距顶部68px、宽度最多420px，窄屏两侧各12px；不挤动正文。重复信息合并，最多同时显示三条，其余排队；持续告警优先。
- 普通成功/信息提示默认4秒，可手动关闭；上传保留原回执的剩余有效期。鼠标悬停、键盘进入或页面不可见时暂停计时，不抢输入焦点；关闭当前聚焦通知后返回其他通知或原控件。
- 使用原生 manual popover；不支持时退回固定定位，不新增依赖。支持原生 ariaNotify 时只播报文字与操作提示，其他环境使用 ARIA live region；遵循减少动态效果偏好。
- 确认弹窗打开期间延后外部通知，弹窗内产生的简单反馈留在弹窗内。隐藏步骤不弹恢复消息；同一草稿的恢复提示关闭或到期后，在本次页面会话中不反复提示。
- 脚本与交付草稿恢复不再额外占行，未确认/未提交状态留在标题旁。脚本文件名收进上传控件的描述和可点击的“草稿信息”；正文旁云朵图标可查看文件名、恢复及保存状态。
- 素材成功上传只出现一次通知，不在清单上方重复显示。失败项保留文件名、错误、放弃和重试；后来又成功上传也只显示仍未完成的数量。
- 复制路径/交付文案/密钥、字幕保存、画面采用、查看副本保存、回收站/清理、系列调整、账务/存储位置等临时反馈接入统一呈现。设置页已有保存状态时沿用，移除模型保存的重复整行说明；连接基准变化及需要重新测试的说明继续可见。
- 字段错误贴近原文或时长输入，继续关联错误描述、聚焦字段；草稿无法保存、未知请求、版本冲突、刷新失败、上传失败及制作前置阻塞等必要提示保留。现有确认弹窗、读写命令、幂等及恢复机制不变。
