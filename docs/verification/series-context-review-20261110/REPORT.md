## 核对步骤

1. 打开预览，当前在“城市观察 → 系列规则 → 街角故事”。点击系列列表右上角“＋”。预期只需填写“系列名称”，“创作规则（选填）”默认折叠；展开后原字段仍可填写。
2. 填一个新名称并点击“创建系列”。预期一次提交，无二次创建确认；成功后自动选中新系列，显示 v1 与继承后的有效规则。只填名称时，数据库规则保持 `{}`，不会把账号默认值复制为系列规则。可展开选填并设置一个视觉风格，保存后仅该自定义值进入规则。
3. 在已保存系列标题旁点击“新建生产单”。预期窗口预选当前账号和当前系列最新版本，仍可主动调整；切换账号后系列清空，下拉只列新账号的系列；选择系列后可实际创建生产单。
4. 返回已有系列点“修改”，改规则并保存。预期仍出现版本确认，确认后新建生产单使用新版本，已经创建的生产单保持原版本。本轮样例“街角故事”当前为 v3，“上下文核对-城市”仍冻结 v2。

预览允许在独立数据中创建系列、修改版本、创建生产单；没有允许付费生成或日常配置写入。不要把本地创建完成理解为调用大模型生成。
