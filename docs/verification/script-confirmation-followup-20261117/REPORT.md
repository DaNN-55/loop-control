3. 模型选择去掉搜索；复用本地模型标志，DeepSeek 标志从已有固定版本 `@lobehub/icons-static-svg@1.102.0` 补入本地资源。图标、模型及连接左对齐；刷新收到标题图标，底部只保留轻量连接管理入口。

6. 每个分镜悬停或键盘聚焦时出现编辑图标；触屏保持可见。可编辑标题、画面、运镜、视频提示词及已启用的口播／字幕，支持字幕跟随口播。编辑期间暂停采用，错误保留输入，取消回到原方案；保存不调用模型、不改左侧原文与控制字段。
7. “继续优化”打开对话框，发送当前要求并呈现本轮要求／模型回复；每次携带最新回执。“允许大胆改编”及费用／原文保留说明在对话框内显式呈现，结果仍需采用。

## 数据与合同

`editShot` 只接收绑定上一已完成回执的镜头索引与文字补丁。Owner、生产单、脚本版本、原文、目标时长均需匹配；幂等键内容冲突拒绝。服务端白名单禁止时长、开关、来源和设置修改，复用制作合同及阅读时长验证，创建新的不可变 completed 回执，原回执与原文保留。保存本身不产生 Provider 发送与模型 usage，采用接口仍只接受原文＋回执身份。

只改画面／运镜等拍法文字沿用普通优化约束；改口播／字幕或既有改编时保留手动变化并使用明确的改编约束。回执链向后续模型提供实际手改方案。合同说明补充在 ADR-0072。

## 验证

- **72 项定向测试**：草稿、只读、导入、保存／启动恢复、一次采用、模型默认与记忆、无选择不派发、手改绑定／取消／错误保留、继续优化及改编确认。
- **18 项真实 PostgreSQL／HTTP 集成测试通过**（最终 19 项中仅浏览器驻留夹具跳过）；覆盖 Owner／CSRF／基准保护、幂等冲突、原回执不可变、零 Provider 的手动保存、后续请求携带手改计划、采用后的原文／计划与实际字幕合同。
- 在独立合成账号、原生 PostgreSQL 私有集群、SDK 副本和本地 Provider stub 中打开真实完整应用。浏览器实际完成普通示例→优化→对话加旁白→手改画面、口播、独立字幕→保存→采用→分镜台；画面提示词与口播草稿均已显示手改内容。没有真实模型调用、付费素材或生产单写操作。
- **329 文件／2,404 项全量测试通过**，类型检查、前端构建、Worker／后端准备与运行包完整性检查通过。保留现有主包体积提示，未夹带打包改造。
- 1401、900、390px 无横向溢出。正式页面仅只读观察，新布局、上传说明、DeepSeek 标志与已记忆模型显示正确。
