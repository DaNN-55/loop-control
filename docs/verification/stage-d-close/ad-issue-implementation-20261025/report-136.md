## 版本与权限围栏

真实模型 B 已完成计算后仅暂停其原始返回；正常保存 C，再释放 B。旧任务可以 completed，但不能覆盖 C 的正文、时序或 caption contract，也不能恢复旧正文确认。旧 Owner tuple 返回 409，已有真实对齐产物 SHA 不变；未修改租约、预算、任务时间或模型结果。

正常换入真实新静音音轨后，原 Owner tuple 同样返回 409。另在仅回滚的真实 PG 事务内，使用实际已确认记录重建夹具、切换到这个真实新音轨，验证正文确认、预览确认与 confirmed_at/by 均清空；ROLLBACK 后当前草稿哈希不变。该触发器检查和正常 HTTP 换轨检查分别记录，没有冒充同一次端到端动作。

4 种过期身份均 409；无会话 401、错误 CSRF/Origin 403。新确认函数仅 Owner 可执行，Worker/anonymous 不可执行。
