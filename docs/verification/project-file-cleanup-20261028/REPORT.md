日期：2026-10-28。Owner 已认可本会话逐项审计结论并授权执行。当前主目录已有大量未提交修改，本任务按磁盘现状保留并按批清理；没有提交、推送、Provider 调用或对 `loop_control` 的写操作。

## 结果

移除 1,185 个旧路径文件，其中包括 8 个迁移到新位置的文件；连接/历史样式和共享命令契约也包含合并后的旧路径。旧路径原始内容合计 38,556,319 字节。另清理旧独立编辑器的 153 个生成缓存文件、48,273,585 字节。上述为文件原始大小，不是实际磁盘释放空间测量。

- 删除 `supabase/`、旧 App/控制面、远端 Worker/编排/发布 CLI、旧启停入口与阶段性隔离工具；当前前端静态入口为 `src/local-app/main.tsx`。
- 当前应用装配迁到 `scripts/runtime/`；备份格式、schema 适配、ACL、完整性与显式上下文恢复迁到 `scripts/storage/`。运行准备只编译并核对当前 Worker 和后台，清单版本升级为 3。
- 保留 27 项从旧 App 测试中迁出的共享界面测试，其他共享组件测试改为直接导入。删除的是旧外壳、远端路径和迁移补丁重放的专属测试。
- 目录参考 SQL 移到 `db/contracts/episode-catalog.sql`，使用原生 Owner 身份。共享视图的缺省命令契约合并为 `src/lib/viewTransport.ts`，未注入操作会在网络前失败，不能创建云端客户端。
- 连接与历史的两层样式分别按原顺序合并成 `connections.css`、`history.css`；现行基础组件和来源许可保留，没有整目录删除 Dan UI。
- 删除 735 个过时/重复资料文件，包括源码 before/source 副本、重复图片和已被替代的规格/票单。原任务结论、失败和豁免、删除范围、恢复例外、当前生产脚本及有效报告继续保留。
- 根 PLAN 从历史日记改为当前进度；保留并行“节点侧栏与顶栏协调”任务原文，旧阶段链接归入 `docs/completed-work.md`。README、运行说明、当前产品约束、后续候选及架构地图已更新。

完整路径、原 SHA、归并目标和运行目录保护清单见 [manifest.json](manifest.json)。决定依据见 [ADR-0013](../../adr/0013-native-runtime-file-boundary.md)。
