# 浅红删除与字幕原因提示（2026-11-19）

仅修改视觉和提示呈现。保留当前原生编辑保护、自动任务条件、防重复提交、字幕编辑/保存/重试入口和所有时长。

## 行为

- 镜头删除 hover/focus：使用项目 danger-soft 浅红底与 danger 红色图标，二次确认、禁用和删除命令不变。
- 缺声音：在对应镜头的字幕状态中说明尚未自动校时；引导先采用口播/视频原声，或选择手工校时。
- 声音超出镜头：说明是时间范围不符，需到剪辑台手动调整镜头或声音时长，或手工校时；明确系统不会自动改时长。
- 剪辑器打开无法写回：根据后端明确错误文案给出浮动通知，提示先保存并返回，再采用已有校时结果，无需重新识别。没有把任意 409 都误报为剪辑器打开。
- 校时任务已完成但尚未写回：显示“字幕校时已完成，等待写回”，保留说明；通知消失后仍能看到现有结果状态。已有效的手工字幕和关闭字幕不误报缺声音。
- 未识别的失败保留通用提示，其他手工编辑错误与校验错误保留原信息。没有主动对每个缺声音镜头弹出通知。
