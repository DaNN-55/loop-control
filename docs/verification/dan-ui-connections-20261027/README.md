# Dan UI 连接配置页迁移

已将新的 Dan UI 免费 MIT React 组件用于本机「系统维护 → 连接管理」。表单使用 PC 标签列、480px 字段上限、36px sm 控件、细边框和轻阴影；保存结果、连接徽章与已存列表沿用统一视觉规则。其他业务页面源码未变。

沿用单一保存/测试入口、折叠列表与版本操作。共享 ExternalConnectionPicker 和创建、轮换、测试、重新绑定函数与本次起点逐字一致。凭据失败保留、成功清空和重复操作锁保留；新增测试覆盖可访问名称和切换连接后恢复密码遮罩。

采用的官方源码、MIT 许可及适配哈希见 `src/ui/dan-ui/UPSTREAM.json`。Tailwind 产物通过原生 CSS `@scope (.dan-ui)` 限定范围；没有向全局页面导入 reset。独立构建命令为 `npm run ui:build`，未启用自动 hook。

## 验证

- 6 个相关测试文件、51 项测试通过；`npm run build` 包含完整类型检查并成功构建。
- 真实已登录页面检查新建/现有连接、搜索及空结果、列表编辑、版本折叠、刷新、字段宽度与标签对齐。检查 1235×953 和 1280×720 PC 视口，无横向溢出；最终新标签页无控制台警告或错误。
- 导航、所有者菜单及应用根节点的样式值与改造前一致；基线之外没有其他业务源码变化。
- 未在真实连接上创建、轮换、撤销、删除或调用 Provider 验证。写入、失败重试及重复提交通过受控组件测试验证。未运行全量应用测试，也未做本轮手工深色/移动端视觉验收。
- Impeccable 对 3 个自有源码文件的正则扫描无发现；未运行依赖页面解析的元素规则，不能视为完整可访问性审计。

正式构建的 JS 约 799 KB（gzip 241 KB），Vite 给出 500 KB 提醒；本轮未为此跨页拆包。安装提示的 PostCSS 构建依赖已采用 8.5.32 修复版；其余旧依赖告警未扩范围处理。

首轮修正了旧弹窗对边框/字号/必填标记的影响、React Aria 冗余名称，以及切换连接时的密码显示状态。最终结果见 verification.json、tests.log、build.log 和 browser-metrics.json；after.png 为最终新建表单，edit.png 为现有连接表单。
