# 日志迁移验收

日期：2026-11-11。用户批准迁入右上角 Owner 菜单，并要求在个人偏好自定义日志存储位置。

## 交付

- 正式应用「所有者设置 → 日志」打开日志弹窗，复用当前主题与控件，中文说明和脱敏原文同步展开。工作台与生产单内部均可打开；关闭后保留原页面并恢复焦点。
- `/api/local/logs` 通过既有 Host／Origin／Owner 会话校验，只读取装配的默认旧文件与当前运行文件，不接受任意路径参数。每文件最多 1 MiB、返回最多 200 条、单记录最多 8 KiB；打开或手动刷新读取。
- 支持已有结构化 INFO／WARN／ERROR 及明确的旧文本错误与调用栈。凭据、常见正文键、URL 私密参数和本机路径在服务端处理，结构化原文使用允许字段。未记录日期／生产单／操作编号保持未知，不补造完整流程。不同请求只有显式同 operationId 和生产单身份才关联。
- 「个人偏好 → 日志存储位置」可填写绝对目录或调用本机文件夹选择器，独立保存。私有配置原子写入；目录必须现存、规范、属于当前用户且可写。新位置下次启动生效，当前进程保持原文件描述符；旧文件不迁移或删除。目录不可用则回到默认位置并显示原因。自定义文件名为 `loop-control-runtime.log`，默认旧文件为 `app-private.log`。
- 正式依赖图不包含原型、模拟数据、静态摘录或服务端日志模块。未安装依赖／ClickStack，未提交推送。
