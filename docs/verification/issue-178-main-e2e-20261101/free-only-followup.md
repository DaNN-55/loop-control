## 免费额度与生成判定

OpenAI 官方说明，免费 API 额度用尽后会继续使用已购 API 额度。赠送额度可覆盖 Images API，但读取模型成功不证明存在未过期的赠送额度，也不证明后续生成不会转为付费。现有项目密钥和连接验证接口没有提供可核实的免费余额证据；已发现的连接工具也不提供该连接所属组织的余额读取功能。

因此本次不提交图片生成。生成状态应记为「免费额度未核实，未执行」，不能记成「生成失败」「模型不可用」或「已免费生成」。这也不需要再次确认是否复用密钥，用户的复用选择已经明确。

模型页的「Free tier 不支持」是 usage-tier 限制，不等同于用户一定没有赠送 API 积分。
