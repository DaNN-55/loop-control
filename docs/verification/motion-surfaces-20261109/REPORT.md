# 设置浮层、上传提示与确认弹窗动效验收

日期：2026-11-09。范围为动效机会评估的后三项，保留前一批已采用的制作反馈和系统状态抽屉动效。

## 实现

- 生成设置浮层：沿用 React Aria 的进入／退出生命周期，透明度与 4px 位移使用 150ms ease-out 进入、100ms ease-in 退出。方向随实际 top／bottom／left／right placement 改变，退出时不接受指针命中；减少动态效果偏好下无过渡。
- 上传结果提示：保留原通知 ID、expiresAt、5 秒停留、手动关闭与上传记录。150ms 淡入并从下方移动 6px，100ms 退出。连续替换即时更新内容，旧退场完成不能移除新提示。
- 通用确认弹窗：180ms 淡入并从 .98 缩放至 1，120ms 退出。取消／确认回调立即执行，焦点按原逻辑恢复；仅在原状态移除内容后保留不可交互的退场表面。
- 共用 SurfacePresence 只负责短暂保留及动画，不接管业务状态、命令或表单。已接入账号／规则、脚本、画面与口播采用、调用确认、镜头删除、历史来源和生产单入口。未注册为动效表面的旧删除表单立即卸载，保留原有流程。
- 退场内容立即 inert、aria-hidden 并关闭指针命中；快速反向从当前计算样式继续。减少动态效果时不调用动画 API，偏好在播放中改变时立即结束当前动画。不支持原生动画 API 的环境即时显示和移除。

## 浏览器实际验证

使用隔离页面加载真实 WorkspaceComposerSetting、WorkspaceUploadFeedback、ConfirmationModal 和生产样式；按钮仅更新隔离页面状态，没有上传真实文件、采用日常候选或调用供应商。

1. 浮层实际自动翻到 bottom，观测到 opacity／transform 的 0.15s 进入和 0.1s 退出；关闭后浮层移除，焦点返回原设置按钮。React Aria 的透明 underlay 只在 open 时存在，不随退出动画拦截点击。
2. 确认弹窗的实际 Web Animations 参数为 180ms、opacity 0→1、scale .98→1。快速关闭再打开时，起点为当时的 opacity .299618、scale .985992，没有重新跳回起点，最终只保留一个弹窗。
3. 取消和确认立即记录完成，退出期间表面已 inert；取消后焦点返回原入口。处理中取消、确认禁用，Esc 不关闭。
4. 上传提示实际参数为 150ms、opacity 0→1、translateY 6px→0。查看上传记录会聚焦记录区域，提示关闭后逐项结果及重试入口保留。
5. 390×844 模拟窗口中，确认框宽 390px、无横向溢出，上传提示宽 358px。属于浏览器模拟，不代表真机触屏／GPU 验证。
6. 模拟 prefers-reduced-motion: reduce 后，确认框与上传提示实际动画数为 0；设置浮层 transitionDuration 为 0s、动画数为 0。

未进行帧率或真机测量。临时页面和偏好／尺寸模拟在浏览器检查后恢复；临时服务与目录在收尾时清理。代码未暂存、提交或推送。
