## 当前脚本的问题

已读出当前未保存的 91 行草稿。第 1 行 `# 04：地狱 Excel 豆包实测` 是有效一级标题，不要求字面填写“本期标题”。当前脚本第 21 行是 `## 旁白脚本`，缺少校验要求的 `## 正文` 区块，因此原通用错误错误地定位到第 1 行。

改进共享诊断为：`第 21 行：缺少“## 正文”区块；可将“## 旁白脚本”改为“## 正文”。`。将三种条件分别诊断：缺少一级标题、缺少正文区块、正文为空；保留 v2 解析和原格式要求。

使用实际草稿，在内存中只替换这个标题后，`mainScriptDiagnostic` 返回 null，见 [格式检查](script-diagnosis.json)。这说明当前格式错误可由该标题修正，不代表已经核验脚本中的实际录制数据或素材授权。没有改写、上传或提交该草稿。
