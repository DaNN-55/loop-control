## 交付与使用

连接管理只录入一次服务凭据，完成验证后，账号蓝图选择对应外部 Adapter 即可复用。唯一兼容的当前已验证版本自动带入；多个可用连接时显式选择。已有明确引用不会被静默替换。模型、预设、重试参数仍属于蓝图配置，最后保存蓝图。凭据不复制到蓝图。生产联网授权仍单独检查，未延长原授权。

已保存连接默认折叠，内嵌搜索位于展开后的列表内；名称、状态、编辑按钮使用独立列。顶部仍统一新建和编辑。

历史资料以生产单为入口，可搜索标题、账号或编号。同名不同编号不会合并；空标题显示“未命名生产单 · 编号前缀”。文件按脚本、分镜、素材、成片与发布包、其他文件折叠；原路径和摘要可展开，文件每页50项。历史记录单独折叠。原始业务标题、文件名及JSON不改写。不能确认归属的来源资料保留于底部默认折叠入口。

归档仅标记历史入口，可恢复，不归档当前业务生产单或删除文件。清理仅预览，明确区分共享、保护和待核查内容；待核查大小不等于可释放空间，没有删除接口。

用户可见“秘密”统一为“密钥”。密钥管理增加“如何阅读和使用”：API Key是密钥的一类；reference是引用编号，不是密钥值。系统控制仅元数据；连接使用区分现用和历史版本；历史还原表示旧资料依赖；未发现引用不等于可删除。查看/复制仍需当前登录密码，明文最多30秒。
