# 导出临时包回收与缓存清理

2026-11-16。用户批准修复导出回收并清理闲置 Remotion、旧 Node 缓存及闲置 Chrome 程序副本。未使用 skill，未修改 macOS 统计数据库或关闭用户浏览器。

## 已实施

- 一次性导出的数据、Remotion 默认构建包、浏览器等临时文件统一位于私有任务目录。保存父／子进程标记，完成或失败后回收；下一次启动只回收至少一分钟前、所有已记录进程均退出且没有打开文件的任务目录。未知目录、别名、权限不符及活跃进程的目录保留。
- 转发 SIGINT／SIGTERM 以关闭自己的渲染子进程，等待服务启动时识别信号退出，避免对已经退出的子进程无限等待。SIGKILL／断电无法依赖退出钩子，按上述启动回收处理；仍有活跃子进程时保留目录，不强删。
- 一次性 SDK 子进程关闭 Node 编译缓存。导出前维护共享 Node 缓存：2 GiB 软上限、7 天过期，保留最近一小时写入、正在打开、未知文件及共享／符号链接。维护失败不阻止导出；其他应用仍可继续生成缓存，活跃写入时可暂时超限。
- 不修改安装的 OpenChatCut 源码。既有 Worker 仍调用 `scripts/openchatcut-render.mjs`，修复在后续新导出中生效；没有重启日常服务。
