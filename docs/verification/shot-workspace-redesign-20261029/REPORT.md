## 正式修复

- 制作依据弹窗内容增加 24px 内边距；窄屏为 16px。
- 分镜放大内容使用受视口约束的纵向布局；镜头条只在自身横向滚动，不撑开弹窗或跑到其下方。1543×953 弹窗下沿 928.5px，镜头条下沿 916.5px；1024×720 时分别为 695.5px、683.5px。
- 逐镜头视频保留 `clamp(360px,52dvh,600px)` 媒体区域，完整卡片允许页面纵向滚动。1543×953 实际视频高度约 442px，浅灰底沿用主题表面色。该取舍优先保证视频可看，避免为了把缩略条塞进首屏而再次压扁画面。
- 生成依据改为逐文件纵列，显示文件名和缩短的 SHA-256，完整路径与指纹保留在 title 中。它们是生成分镜时的冻结输入，用于追溯输入版本。
- [现有原片选择与紧凑上传入口同行](shot-redesign-source-row.png)，导入过程状态保留；对齐按钮两列排列。1543 宽度下实测为 291px + 94px，两项同高且无横向溢出。
- 两个灰色按钮保持原有围栏，并补上实际缺项文字；未放宽正文核对、预览指纹或全期确认要求。

## 灰色按钮调查

只读 PostgreSQL 检查当前样片：10 个镜头的音频均 ready、时序均 completed，但 `caption_text_is_confirmed=false`，`current_preview_artifact_id` 与 `current_preview_project_artifact_id` 均为空，当前预览状态 pending。历史 `confirmation_status=confirmed` 不等于具有当前有效预览的确认。浏览器实际提示为「请先在声音与字幕核对当前音频正文」和「先生成并确认所有镜头的同步预览（0/10）」。
