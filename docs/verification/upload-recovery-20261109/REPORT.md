# 上传失败恢复展示精简验收

日期：2026-11-09。

## 结果

- 取消右侧常驻上传记录图标、成功历史列表及其浮层样式。
- 上传期间临时显示未完成项；失败后保留文件名、失败原因及「重试未完成项」，提示自动消失或手动关闭不会移除详情。
- 仅列未完成文件，成功项立即从恢复区移除；全部完成后恢复区及重试按钮消失，仅保留原有短暂成功提示。
- 提示中的「查看」直接聚焦并滚动到恢复区。重试沿用现有队列、导入回执和幂等命令，不改变素材、参考图或候选登记流程。
- 「导入本期素材」沿用已接入的共用提示与左侧失败详情，本轮未改动该入口的业务行为。
