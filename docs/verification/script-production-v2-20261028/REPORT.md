- 上传素材检索与冻结：保留原上传名称；本期优先，再查当前账号同系列的已批准素材；缺失和歧义不猜选；跨生产单复用时核验哈希并导入本期副本。
- 设置自动应用：稳定段落编号、确定性分镜、现有 TTS、字幕契约、构图、音量、音乐闪避、音效绑定及起点/长度、转场；保留本期人工修改和已有 Studio 工程。

- 动作提交前在同一事务重新核对脚本、授权、执行配置及当前制作状态；旧动作放弃。幂等标识稳定，原有预算预留、任务 ID、未知提交停止和恢复保护继续生效。
- v2 视觉规划只整理上传素材，移除任务里的图片生成分支；v2 前置检查将图片、配乐和音效按上传路径处理。视频接口继续走原有受控入口。
