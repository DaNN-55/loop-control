# 制作反馈与系统状态抽屉动效验收

日期：2026-11-09。范围为用户批准的前三项动效，不包含其他浮层、弹窗或页面切换。

## 实现

- 采用成功：仅在既有确认流程收到成功响应后，为对应缩略图增加 300ms 渐隐描边与 160ms 勾选反馈。失败、已有采用状态和普通刷新不触发。
- 生成完成：记录当前组件实际观察过的待执行／运行中任务；其新增可用候选在当前画面类型下出现时淡入 160ms。既有候选、未观察到的任务、导入素材、重新打开不重播，不自动采用或修改预览选择。反馈标记在 200ms 后清除。
- 系统状态抽屉：保留原有 Portal、焦点管理、滚动锁及关闭逻辑。使用原生 Web Animations API，进入 220ms、退出 160ms、水平位移 24px，快速反向前读取当前位置。退出期间设置 inert 并关闭指针命中，动画结束后卸载。
- 减少动态效果：候选 CSS 动画关闭；抽屉不启动动画，偏好在播放期间改变时立即完成当前动画。浏览器不支持原生动画时使用即时显示与关闭。
