## 用户核对

1. 打开专用预览，分镜台 → 配乐与声音 → 整期配乐。应直接看到添加本地配乐（MP3）和 MP3 · 最大 100 MB，不需要连接。
2. 点击添加本地配乐（MP3），选择本目录 test-tone.mp3 或自己的 MP3。上传后出现可试听候选；加入候选显示已加入候选且禁用；此时还没进入工程音轨。
3. 点击候选行的试听；再点击采用。进入剪辑工作台后可在时间线上看到整期配乐音轨；未经采用只会是候选。
4. 返回分镜台，选镜头 01，切音效，添加本地音效（MP3）。上传后同样为可试听候选；点击加入镜头才写入该镜头音效轨。
