## A-roll／B-roll 的结论

现行产品模型统一为“镜头”。[CONTEXT.md](../../../CONTEXT.md) 的视频来源约定和 [ADR 0018](../../adr/0018-per-request-production-and-account-storage.md) 明确说明旧 A-roll／B-roll 仅兼容读取，不再作为模型选择前提。当前工作台通过统一 video 能力解析选择。

实际 Owner HTTP 回归分别用旧 a_roll、b_roll 镜头提交同一 wan2.6-i2v-flash 模型，两者均成功入队为 video；没有执行供应商任务。历史 lineage、素材用途、适配器能力和旧页面仍可含 A/B 标识，不等于当前功能仍有两套限制。旧 EpisodeProduction／materialImport 等页面尚有历史名称，安排第三批清理，不能声称全仓文字已清零。

## 用户检查步骤

**当前逐项核对：脚本输入／预览项已批准并迁移，其他项继续待审。** 打开 http://127.0.0.1:5173/__second_batch；示例已带两个镜头和一张图片候选。该地址使用独立代码快照、临时 PostgreSQL 和测试素材，付费生成在代理层被拒绝，本次会话最多保持 12 小时。可实际修改脚本、采用图片、上传／试听／采用本地 MP3。

1. 点击“脚本确认”→“修改脚本”，粘贴两段正文，展开“镜头与字幕预览”，应有两个镜头；确认后进入初稿，字幕与预览一致。
2. 空脚本时使用结构化模板，分别尝试独立字幕和关闭字幕；画面提示词不进入字幕。已有工程的原生编辑不会因此被覆盖。
3. 在分镜台首次选择 Wan 模型，检查型号有效默认值；手动修改后换模型，应保留自定义并提示不兼容值；点击“按此模型恢复默认参数”才重置。无需点击生成，也不会产生测试费用。
4. 导入一张图片，“采用到当前镜头”应直接可见；“用作视频首帧”只选择首帧，不等于采用或提交生成。已有视频时留意备用图片／明确替换的提示。
5. 配乐与声音中点击“添加本地配乐（MP3）”或音效入口。上传后应出现可试听候选；工程音轨在点击“采用”前不变，相同准备按钮显示“已加入候选”。
6. 可在较窄窗口重复查看脚本预览、图片操作和本地音频入口。
