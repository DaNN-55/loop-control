## 部署与回滚边界

- 原 HTTP Owner 登录/CSRF 和日常付费配置保持；private Owner 会话只由认证 Unix listener 在进程内创建。
- native Studio 使用独立 local-only capability、环境白名单及本地插件汇编；不加载 SDK .env、paid/CLI 插件或 agent 工具队列。Node 网络 hook 不是 OS 级网络沙箱。
- 工作区私有 opt-in 配置使普通启动保留 socket；不提交机器专属配置、凭据、运行时归档或媒体。
- 同 PR 保留先前制作包接单基础代码及迁移 236，但默认不启用，主环境未执行该迁移。接单启用不属于本批上线范围。
- 回滚需通过受支持的插件禁用与原启动流程操作；不能将旧归档 ID 当成启动版本选择器。重启会涉及 Worker、数据库和 Keychain，不承诺零停机。
