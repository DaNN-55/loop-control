## 结果与范围

主流程为“生成成片 → 看实际 MP4 → 确认并完成 → 下载视频”。发布资料独立可选、自动保存，可 AI 起草、改写、撤回和分别复制；已有图片、真实视频选帧、本地图片均持久保存。旧人工问题入口、表、列表查询与 SQL 门槛已退役。新 v3 核心包不要求封面／文案；旧 v2 包继续严格验证。完成单首次保存实际编辑创建完整新生产单并停在剪辑台，原单不变。

合入并保留已有原生编辑权威改动 `8167c0ad8` 及后续字幕原因／删除悬停／验收清理 `55c6e27c8`，本任务迁移调整为 214–219，保留既有 213。原工作区已有提交及未提交内容未覆盖；根 `PLAN.md` 的其他任务未由本任务改写。最终提交以 Git 记录为准。

所有实操使用本轮独立 PostgreSQL 17、随机数据库、独立媒体目录和自有 Chrome for Testing 153／agent-browser 会话。未删除日常生产单，未重启日常服务，也未对日常数据库执行新迁移。日常启用仍需正常启动／迁移流程；本轮交付的是实现及隔离验收后的本地提交。

## 实际新手流程

1. 原始输入有三件商品。在浏览器分镜台删除第三件后进入真实 OpenChatCut，修改画面位置，明确点一次“生成成片”。
2. 播放实际 1080×1920 MP4；无语言模型连接、标题／简介／标签／封面全空，一次“确认并完成”，独立 Worker 完成后下载真实视频。
3. 接入已配置的真实 DeepSeek 连接，明确选 `deepseek-flash`，首次生成一套文案；手改标题并增加补充要求后明确重写。两次 Responses 请求均成功。实际输入均无已删第三件商品；第二次携带手改标题和要求。没有整段视频 AI／ASR 调用。
4. 撤回回到手改前替换快照。三按钮实际写入剪贴板，并用浏览器 CDP 用户手势读取核对标题、简介、带井号标签；CLI 无用户手势的读剪贴板被浏览器拒绝，未用 mock 宣称通过。
5. 三种封面实际保存，刷新恢复文案与封面。下载新旧 ZIP、工程、封面真实字节；完成后修改标题，新包 metadata 改变，视频 SHA 相同，原核心 ZIP 字节完全不变。
6. 打开完成作品、选择片段、未改保存：正式单数量仍为 1。实际修改后首次保存，进入新单剪辑台，零导出／零交付，不自动生成。返回分镜台改主声音／字幕，再进剪辑台，实际生成、确认并下载新视频。
7. 最终正式单共 2 张；原单工程 revision／content SHA／project SHA／导出／交付数量完全不变，副本独立完成。视频分别为 `c6274130…7052a` 与 `5fbb3555…fbc7`。完整值见 [browser-facts.json](browser-facts.json)。

另在全新隔离库完成 320px 纯键盘演练：登录、打开剪辑、生成、播放、确认、下载、三字段编辑／复制、选帧、详情、返回查看后退出与刷新；仍只有 1 单、1 次渲染、1 次交付、0 次 AI 请求。见 [键盘事实](keyboard-facts.json)、[键盘剪贴板](keyboard-clipboard.json)。原生下拉弹窗在 headless 驱动下不便用方向键确认，键盘选图改用实际成片选帧；已有图片来源另已用真实选择操作验证。

其他证据：[实际模型输入](live-model-requests.json)、[最终浏览器树](browser-completed.txt)、[副本编辑画面](copy-editing.png)。输入、画面与声音为合成验收素材，模型基于保留的已知画面安排起草；没有将合成色条说成模型真的看懂了杯子图像。

## 发现、修复与复验

- 退役表后列表查询仍引用旧表，浏览器列表 503：删除列表依赖与旧类型，新增迁移后实际 catalog 200 回归。
- 完成单刷新时，`undefined === undefined` 误判已有新包导致空白：显式要求 package 和 publication 均存在；新加载顺序回归先失败后通过，浏览器刷新恢复。
- 最新原生剪辑改动移除只读 inspect，完成查看一直连接：只恢复只读读取以识别未修改离开；编辑／导入继续归原生编辑器，额外宿主编辑动作仍拒绝。
- 原生 JSON 键顺序不同误判双版本修改：比较实际内容，保留数组顺序／值变化的冲突保护；副本回分镜改字幕后重新打开成功。
- 旧 `audio` 类型的已采用音轨未进入副本素材白名单：沿采用的 source artifact 身份收集，真实旧音轨副本与再次交付通过。
- 独立复审发现历史 ZIP 延后验证标记被下载接口拒绝：下载只读取并完整验证本次请求的包；真实 200／篡改 409／恢复 200 回归。
- 验收环境：最初临时目录 `/var` 别名和 SQL_ASCII、资源测试映射根与账号根同级均被安全检查拒绝，修正夹具真实路径／UTF8／账号映射，不放宽产品守卫。一次并行 Vite 构建清掉工作副本 `dist/runtime-manifest.json`，改为先 build、再 runtime:prepare、最后 Worker；旧用例也改为使用原生 `workspace.sha256`，不混用规范化业务工程 SHA。

### Modern Web Guidance

- **`forms`**：我给发布表单保留独立标签和按钮类型，防止复制按钮触发表单提交（“explicitly set `type="button"` on secondary or helper buttons”）。
- **`copy-button`**：我把复制反馈放在按钮外，并保持按钮可重复使用，避免复制后丢焦点（“DO NOT disable the button while showing feedback”）。React Aria 未透传 Invoker 自定义命令属性时沿用受控点击与 Async Clipboard，保留明确失败提示。
