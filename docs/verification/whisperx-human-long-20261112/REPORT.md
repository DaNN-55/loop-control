- 在现有专属隔离集群（54332）和样例生产单末尾新增镜头 03，前两个镜头保留。生产单为 `e2677236-6cd2-4682-9836-657f933daf1b`；本轮镜头为 `added-10c5a639-8ead-4721-b571-12c28c8bcd71`。
- 素材登记、镜头和口播准备使用实际 Owner API；排队、采用尝试、OpenChatCut 保存和重开通过实际页面操作。Worker 执行真实本地 WhisperX，未使用 mock 或手写候选时序。
- 复用现有本地模型缓存及禁止联网的 Python 启动器，没有下载模型或依赖，没有付费 API 调用。
