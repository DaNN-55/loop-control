# 管理员秘密管理验证记录

日期：2026-10-27。范围：当前本机主程序，`http://127.0.0.1:5174/`。

## 已实现

- 「所有者设置 → 秘密管理」仅接收服务端能力标记。私有运行配置 `secretAdministration.adminOwnerId` 明确绑定现行 Owner ID；Owner 身份本身不授予全局管理员权限。配置缺失不开放接口。
- 列表、详情、单项读取分别经过服务端管理员与有效会话检查；请求结束前再核对会话。元数据来自现行命名索引、别名、数据库运行配置、连接版本及绑定、待恢复意图、历史保护映射和文件中的引用标记，不依赖固定分类数量。
- 单项查看/复制使用 POST、精确 Origin、现行 CSRF、数据库当前 scrypt 密码摘要与既有失败锁定规则。元数据每管理员每分钟 120 次、明文操作每分钟 5 次；窗口持久化。密码行持锁到审计事务提交，防止读取期间密码被替换。
- 读取仅调用当前专用库的固定 helper UUID 接口。未知引用拒绝，现行数据库控制凭据及其别名、启动解锁锚点不提供网页读取。不接收路径、服务名或命令；Keychain 失败不降级、不改 ACL。
- 响应禁止缓存；密码/明文不进入 URL、浏览器持久存储、日志和审计。明文最多保留至服务端给定 30 秒期限。切换条目/筛选、关闭、页面隐藏、会话失效时清除并取消在途请求。跨标签页退出或身份变化会清除其他标签页的秘密页面。
- 复制在验证后由浏览器 Clipboard API 执行，复制完成不渲染明文。不提供修改、删除、导出或原始 Keychain 下载。
- 前向迁移 `064-secret-administration.sql` 新增仅追加的审计及限流窗口，未修改已应用迁移。审计记录操作者 ID、服务端时间、合法 reference、操作、结果和固定原因代码。未认证或尚未解析请求正文时，未知操作者/reference 留空。
