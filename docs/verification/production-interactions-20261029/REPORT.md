## 预渲染审核

用于检查合成前冻结的镜头媒体、叙述音轨、配乐及来源证据；逐项审核模式须批准后进入合成，仅 QC 审核模式主要供回看。成片的最终审核仍在“合成与 QC”。

实看发现旧展示只识别有 task 的 artifact/audio_track，误拒绝现有 SQL 冻结的 source_material，并且媒体定位只查 artifacts。现已支持冻结原片无 AI task 的证据，以及原片/音轨的冻结路径与指纹预览；仍交给原有资源接口执行所有权和指纹检查。这里只展示原片/音轨，没有把它们冒充最终合成效果，也没有改变生产关卡。
