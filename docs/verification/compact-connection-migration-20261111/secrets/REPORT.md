# 密钥固定详情迁移验收

日期：2026-11-11。范围：全局密钥管理，以及可嵌入连接固定区域的共享敏感详情。

## 结果

- 列表点击名称、查看或复制后，在同一内容区进入详情，不再在表格下方追加展开块。返回保留搜索、分类、页码并恢复对应名称按钮焦点。
- 详情保留引用、用途、当前连接、待恢复操作；历史名称、运行用途、历史引用别名、已撤销/历史连接、历史文件记录在“历史与技术信息”中。
- 查看、复制、验证、取消集中在固定底部；离开连接前先清除敏感状态。系统控制项只显示元数据。
- 密钥详情与敏感读取使用独立请求代次：切换引用丢弃旧详情；页面隐藏可完成非敏感元数据读取，但不会继续启动原本请求的密码验证。关闭、返回、页面隐藏、pagehide、会话失效均中断敏感请求并清除明文和密码。
- 密码仅用于一次POST验证；明文最多显示30秒，未写入浏览器持久存储。复制前检查当前请求和页面可见性；不明示明文。

## 共享接口

`SecretDetailPane`：`reference`、可选`csrf`、`initialAction`、`onBack`、可选`onOpenConnection`、`onStateChange(busy)`、`expectedConnectionId`、`expectedVersion`。详情读取后核对引用及期望连接/版本，再提供可读动作。省略csrf时不发送空头，沿用`localRequest`已有会话token恢复。

组件包含验证form，嵌入时应替换连接编辑内容，避免嵌套在另一个form内。

字典：`src/i18n/en/compactSecrets.ts`导出`compactSecrets`，由父Agent聚合到`src/i18n/en/index.ts`。
