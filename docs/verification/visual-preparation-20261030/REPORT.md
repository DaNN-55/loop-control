# 图片与视频统一准备验收

日期：2026-10-30。范围：素材准备页的图片／视频操作、图片生成任务、首帧联动、候选采用和剪辑入口检查。

## 实现

- 新镜头的图片、视频 Tab 均为空占位。上传模式只显示上传／本期素材选择，AI 模式显示生成设置。上传和生成均只建立候选，必须明确采用。
- 图片支持 1／2／4 张候选，左右按钮、键盘切换、胶囊计数与放大预览。采用和首帧按钮紧邻预览；使用设置按需展开。
- GPT Image 2 使用本期已配置连接；无参考图调用生成接口，有参考图调用编辑接口。支持参考图、画幅预设、质量和数量，PNG 结果逐张登记。API 支持情况依据 [OpenAI 图片编辑文档](https://developers.openai.com/api/reference/resources/images/methods/edit)。
- 视频首帧可来自本镜头图片、本期图片或单独上传。明确选择后，翻图不切换首帧；每次请求固定图片版本、SHA、构图、提示词和参数。实际送入模型前按工程画幅留边或居中裁切，不改写原图。
- 万相高级设置包含 720P／1080P、负面提示词、种子、提示词扩写、单／多镜头、声音和水印。只有适用模型显示这些选项；其他模型沿用既有路径。提示词提供具体示例。
- 上传视频可选择使用区间。服务端验证边界、短区间和时间线影响；原生工程保存真实起点与时长。
- 已采用视频优先；选用图片时可保留为备用和首帧。原生工程仍是实际画面的权威，候选浏览不会改写工程。
- 进入剪辑前，界面和服务端均检查实际画面与来源文件。参考图、未采用候选、排队／失败任务不算就绪。
- 图片沿用既有 Owner、连接、Worker、任务输出目录和预算账本，保留未知提交结果，避免重复付费提交。迁移只新增图片任务专属输出规则，未改写共享输出命名空间保护函数。
