## 从新建脚本到制作完成

主验收单：`529a7070-f80e-4d97-9ac0-80ee2e057ba5`。隔离 Owner、数据库、媒体目录与日常数据分开；UI、HTTP、PostgreSQL、原生工程保存、渲染与交付 Worker 均使用实际实现。口播/视频 Provider 在此链使用明确受控协议样本，在线连接另行实测。

1. 从普通页面新建生产单，上传脚本并确认。
2. 修订镜头能力为已冻结的 A-roll，明确重新规划并授权；保留原媒体和工程历史。
3. 保存默认声音，生成口播；在真实工作台明确采用当前口播为主声。
4. 保存隔离账号生成预算，提交首次 AI 视频，真实 Worker 完成后填入目标，2.4 秒使用窗口与 4 秒 Provider 输出分别记录。
5. 上传人工配乐。过短音频被拒绝，改用 12 秒测试素材准备并采用；实际混音保存为 -18 dB，保留口播主声和闪避设置。
6. 真实编辑器应用画面焦点 X=13，保存、关闭、重开后仍为 13。字幕保存 0–2400 ms 手工 cue，时序有效后明确核对正文。
7. 首次导出完成 5/5 技术检查。记录未解决问题时禁止确认；解决后才允许确认精确文件。
8. 人工复看发现配乐比画面长，通过真实混音操作移除过长引用，保留源文件。保存后旧文件确认失效，再导出并确认 v12。
9. 填写标题、标签、说明并选封面，切到脚本再返回，草稿保留；生成交付包，经真实交付 Worker 验证进入 `production_completed`。
10. 独立读回六类文件，逐一比对磁盘和 Owner HTTP 下载 SHA、大小及清单，验证交付视频就是已确认视频；ffprobe 和 ffmpeg 全片解码通过。
