## 补全连接与密钥流程

用户认可合并七个入口的布局后，要求补全「更换 API Key」与「验证后查看／复制」的隔离交互。本轮仍不迁移正式应用、不访问真实凭据或供应商。

新增模块 `src/local-app/owner-settings.prototype.credentials.tsx`，由原型根组件持有共同的示例连接与版本。连接可以修改名称和模型、填写新示例密钥、观察验证中和失败，成功后创建新版本并保留历史。只改名称或模型不创建密钥版本。连接与密钥页通过稳定引用互相定位；系统控制密钥继续只显示用途。

「查看／复制」现在有真正可交互的演示密码输入、错误、取消和进行中状态。查看成功后显示 30 秒倒计时，支持立即隐藏；筛选、切换页面、关闭窗口或页面隐藏会清除明文及未完成验证。复制成功会通过浏览器剪贴板 API 写入所选示例字符串，页面不展示密钥。可以使用「模拟复制失败」测试恢复。此剪贴板写入是本轮新增的真实本机效果，不能再把复制描述为只修改内存；它不会接触真实凭据。

接口始终为本地固定演示：新密钥只接受对应版本的 `demo-key-…` 示例值；演示密码为 `demo-password-123`。连接失败时不切换示例当前版本。正式迁移仍复用原有真实保存／验证、凭据版本与权限协议，不把这些固定结果迁入正式应用。
