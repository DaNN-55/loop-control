# 画面切换与口播区域精调

2026-11-08。对应用户六条标注，沿用现有设计 token、组件和业务数据。

## 六项处理

1. 图片/视频切换增加分段底色、边框及独立按钮底色，选中态浅蓝、未选中白色。样式仅作用于画面类型 tablist，键盘切换和焦点不变。
2. 视频时长问题确认为既有声画对齐规则：前端 voiceDriven 时 readOnly，后端也优先使用实际主声窗口。添加“跟随口播/视频原声”标记、按钮提示及具体只读原因，通过 aria-describedby 关联输入。没有主声时仍可手动输入；本次不改变音频、实际时序、服务请求参数或费用逻辑。
3. “裁剪与时长”增加与图片操作同式的次级说明：“选择使用区间，调整采用后的镜头时长”。保留裁剪区间、时长策略和采用前影响确认。
4. 删除页面常驻的本镜口播配置表单，将模型、中文音色搜索、语速和音色试听集中到一个齿轮入口。弹窗按“本镜 / 本期默认”切换：本镜参数继续保存在当前浏览器草稿，用于下一次生成；本期默认仍需明确保存。两种作用域和旧草稿均保留，不把本镜覆盖静默写进本期默认。
5. 候选默认将正文摘要、时长、试听和采用/恢复/撤回操作放在一行；完整正文、连接、模型和中文音色移入已有播放详情。保留完整播放器、失败与时长不匹配信息；出现采用确认或展开播放器时按内容增高。容器不足 420px 时允许操作另起一行。
6. 字幕模式与保存按钮移到正文下的同一操作区，与生成/人工口播动作并排，不再单设底部“字幕设置”块。字幕仍需明确保存，跟随口播与独立字幕的语义及正文草稿不变。

## 时长排查

修改前先运行 actual source and short TTS windows derive read-only / formats the actual voice duration 两项定向用例，2 项通过，稳定确认“已采用主声时只读、无主声时可编辑”。这不是输入事件故障；明确业务分支已能直接定位，因此没有添加临时日志或进行无依据的多假设修改。

读取当前 `readWorkspaceVisualTargets`、`resolveWorkspaceMainVoice` 和 `queueWorkspaceVisual`：实际使用时长来自原生工程中主声音频的帧窗口；服务时长按所选模型的最短值及整秒要求确定。后端不会因放开前端输入而忽略该主声窗口，因此本次保留约束并明确解释。真实页面再次核对值为 1.87、readOnly=true、原因可见；用户可更换/撤回采用来重算该窗口，无主声时可以自定。
