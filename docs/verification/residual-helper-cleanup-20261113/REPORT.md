## 逐项决定与调用链

| 删除的明确签名 | 原用途与判断 |
| --- | --- |
| `local_identity.history_episode_delete_plan(text,text)` | 旧历史专用删除的记录／文件／版本计划；旧入口已退役，无当前或原包调用者，删除 |
| `local_identity.history_episode_business_revision(text)` | 上述计划专用的历史业务行指纹；有效 SQL 调用者仅为同组计划，先删计划再删指纹 |

| `public.queue_frozen_shot_source_audio(uuid,boolean)` | 旧冻结镜头源音频派单；专属旧触发器已退役，当前原生源音频走独立制作链，无消费者，删除 |

四者均无传入 pg_depend 依赖，除同组计划→指纹外无有效 SQL 调用者。完整扫描当前执行代码和 23 个不可变原包，按精确标识符均无引用。初始子串扫描的 138 个文件命中全部来自 `lock_owned_account_row` 等不同的更长标识符；原始扫描私有留存，`runtime-audit.json` 保留前缀命中和精确分类。原包集合与完整树 SHA 在应用前后精确保持。

183 只有四条明确签名 DROP FUNCTION，默认 RESTRICT；没有 CASCADE、数据 DML、权限授予、触发器拆除、历史 SQL 或客户端类型修改。应用守卫只允许本组内部调用，任何外部 SQL 调用者或目录依赖均阻断。

必须保留的相关路径：

- `lock_owned_account_row` 及账号 directory／creation 等锁仍用于当前目录、规则和账号操作，不是本组旧账号锁。
- `lock_history_deletion_inventory` 仍由当前普通删除及旧回执续处理调用；它与 `history_external_reference`、`history_episode_row_matches`、引用核查及留存登记共同保持共享和依赖保护。已更正上一轮报告中将当前历史锁归为闲置残留的不准确分类。
- `protect_frozen_shot_preparation_inputs`、历史视图／表、原音轨和冻结证据、Owner／会话／CSRF、租约／次数／费用／未知提交／文件确认和发布保护保持。
- 旧运行包仍引用原 8 个兼容契约和 `record_episode_worker_preflight`，保留原定义与权限；后者被 21 个包引用，不当作无消费者候选删除。统计启停 SQL 是 ADR-0057 的明确授权边界，保留且不启用。
