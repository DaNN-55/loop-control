# Dan UI 历史资料页

本轮仅改造「系统维护 → 历史资料」，包含生产单内容和折叠的共享资料来源管理。复用 Dan UI 的输入、原生选择、按钮和徽章，并补齐同一 MIT 源码版本的 Checkbox，没有新增 npm 依赖。连接页和其他业务源码保持本轮起点摘要不变。

搜索筛选、列表行、分类折叠、文件与记录详情、分页和清理预览采用统一的边框、排版、间距及状态。长标题与路径可换行，原始 JSON 保持文本并在自身区域滚动。文件下载地址与原始记录精度不变。

## 验证

- 10 个相关测试文件、63 项测试通过，覆盖历史功能与连接页回归。完整类型检查与正式构建通过。
- 两个组件的读取、归档、恢复、预览及记录请求处理函数逐字保留。补充验证了新复选框、搜索参数、文件/记录独立分页、下载链接、JSON 精度及恢复失败重试。
- 真实已登录页面检查搜索空结果、显示范围、复选框键盘交互、生产单内容、文件与记录第 2 页、来源分类与文件浏览、只读清理预览。1235×953 PC 视口没有横向溢出或横向裁剪的交互元素。
- 连接页 6 个控件的字体、颜色、背景、边框、阴影和内边距与开始时一致。最初采样时内容尚未显示，几何值为 0，未将这些值用于对照。
- 分步编辑的中间态曾出现 Button 尚未导入和 CSS 尚未生成的热更新错误，现已修复。最终以全新标签页重新加载主列表与共享来源，无控制台警告或错误；开发期日志与最终日志分别保留。
- Impeccable 对 3 个自有文件的正则扫描无发现，未执行依赖解析页面的元素规则，不代表完成全量可访问性审计。

没有执行真实归档、恢复或删除；写操作通过受控组件测试验证。未运行全量应用/数据库集成测试，也未做本轮手工深色和移动端视觉验收。构建继续有大于 500 KB 的提醒；JS 约 808 KB（gzip 244 KB），本轮未跨页拆包。
