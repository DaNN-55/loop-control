本轮完成最新 9 条批注，仅调整脚本确认页及其聊天回执的展示信息。前一轮镜头删除、逐镜修改标记和型号扩展已提交 `a699f6f0e`，详见[前轮记录](../script-shot-models-20261118/REPORT.md)。未改其他页面布局、原文、已有工程或素材；无新增依赖、数据库迁移或真实模型请求。

## 变化

- 上下文说明并入顶部使用帮助，聊天区直接展示交流。发送仍自动带上同一脚本版本、原文、时长下的最新方案和已保存对话。
- 用户消息绿色、靠右，不显示“你”标题；模型回复灰色，标题展示实际模型图标和名称。历史名称读取不可变回执，切换当前模型不会改写旧消息归属；手动编辑／删除显示“本地修改”及本地回执信息。
- 拍法说明默认最多显示 100 个 Unicode 字符的概要；原始完整说明、原文安排、变化及提醒按需展开，保留完整数据。阻止继续的提醒默认展开。
- 历史与帮助复用同一图标按钮。历史内容分为版本、已确认拍法、选填备注和靠右的还原动作；取消还原保留草稿与备注并返回历史。
- 推理强度使用原生离散 range，仅包含所选型号支持的档位。方向键、触摸、焦点及无障碍名称保留，`aria-valuetext` 同步显示中文等级；选择档位不发送请求。
- 交流方式按钮的图标、无障碍名称、tooltip、输入占位和发送动作同步切换。镜头表单去除重复说明，取消／保存靠右；校验与错误提示保留。

## 两种交流方式的执行合同

| 行为 | 调整拍法 | 仅讨论 |
| --- | --- | --- |
| 输出 | 结构化新分镜方案及摘要 | 文字建议／解释 |
| 中间分镜栏 | 验证通过后显示新候选 | 当前方案保持不变 |
| 制作与保存 | 新候选需“采用并继续”后进入制作 | 本轮不能产生可采用方案 |
| 模型与上下文 | 使用所选模型／推理设置，自动附带上下文 | 同左 |

仅讨论中即使说“直接帮我改”，也不会修改分镜；需要切换调整拍法后发送。讨论后点击采用，会采用中间当前显示的已有方案，而不是自动应用文字建议。两种模式发送新指令都会调用模型并记录用量；切换配置／刷新／读历史本身不调用模型。相同请求恢复沿用既有回执，未知请求只核对、不重发。原文、时长或脚本版本改变后切换对应上下文，不混用方案。
