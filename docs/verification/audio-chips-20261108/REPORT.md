# 音频底部配置按钮

2026-11-08。范围：WorkspaceAudioPanel.tsx、workspace-audio.css、WorkspaceAudioPanel.test.tsx、ProductionWorkspacePanel.test.tsx、PLAN.md。

复用画面的 WorkspaceComposerSetting、Popover 和 Dialog，来源、定位方式、位置/偏移、时长变为底部摘要按钮，点击后打开设置；来源弹层保留选择、拖入、上传 MP3 和清除。原片声音的画面来源也放入同一来源入口。草稿仍保留在父级现有状态中，弹层关闭不丢值，不额外自动保存或调用业务接口。

操作文案缩短为“找音效”“导入音效”“保存配置”等；保留原无障碍名称、付费/准备/显式采用边界和原请求字段。底部使用现有 32px、4px 间距及 flex-wrap 模式，优先一行，空间不足自然换行，不固定页面宽度。

验证：55 项组件回归通过（音频 20、生产工作区 35），覆盖弹层默认隐藏、修改摘要、重开草稿保留、定位变化无写入、MP3 导入、来源选择、拖放与原声提取、已用音效混音及显式采用。旧直接定位控件的测试更新为先开弹层，保留请求/状态断言。首次测试出现“来源”同名歧义后改用 combobox 角色定位；类型检查发现测试中使用了不支持的 exact 参数，已去除并通过检查。

npm run check 与 Vite 前端 build（emptyOutDir:false）通过；原 jsdom 媒体警告和大包提示保留。

实际 5174 页面：1490×953 和 1152×790 下来源、定位、偏移、时长及两个操作按钮均同排，均 32px 高、无横向溢出。实际打开四种弹层，时长 1→2.5 后摘要同步，重开仍为 2.5，再恢复 1；Escape 正常关闭并回焦。来源上传和拖入入口可见，未上传日常素材。effects.png 为实际页面，layout-narrow.json 为窄窗测量。

没有检索、导入、保存配置/意图、准备、采用、撤销或付费调用。验收仅变更验证标签中的浏览器草稿并恢复原时长，之后恢复默认 viewport、关闭自建标签。业务数据未改；无需后端重启/迁移，未提交推送。
