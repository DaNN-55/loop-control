## 改动

- 桌面 grid 使用 `minmax(0,1fr) 320px`、20px 间距；取消预览 sticky 和 max-height，`overflow:clip` 不建立独立滚动容器。
- 作品媒体置顶，接标题、账号/系列、当前阶段/真实状态、原操作入口、主要参数。保留阻塞原因，去通用重复说明和脚本摘要。

- 回收站移到列表底部，原 openCleanup 入口不变；“显示”去掉前后图标。
- 无有效系列记录时“列表显示系列”置灰并解释；优先用完整筛选范围的 seriesEpisodeCounts，避免其他页有系列时被误置灰。保留已存显示偏好。
- 沿用列表标题 15px、辅助文字 12px、单元格上下 12px、36px 控件。1000px 以下沿用原生预览弹层及焦点返回；弹层自身可滚动以适配窄屏。
