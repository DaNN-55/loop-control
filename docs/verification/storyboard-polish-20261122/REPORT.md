## 播放选区建议（官方资料核查，未实际集成）

用户需要的是按时间截取（trim），即在播放进度上用起止手柄选中一段；不是在画面上裁掉边缘的空间裁切。

1. 推荐现有Video.js + React Aria多端滑块：当前VideoPreview已使用@videojs/react，并已有mediaRef、onTimeChange、onDuration、segment接口；项目也已有react-aria-components。官方Slider支持多个手柄、步长和拖动结束事件。需补缩略图带、选择区/播放头联动；原起止数值、校验和明确采用流程可以继续复用，不需要引入转码库。
2. WaveSurfer.js Regions：官方Regions支持起终点、选区整体拖动、两端缩放、最短/最长时长；官方亦有视频绑定示例。偏重波形，适合口播/音效或依声音找片段；若视频没有声音，纯画面缩略图更直观。
3. Pintura Video Trim：现成播放、帧预览、片段选择/截取和拖边缘同步预览。为商业视频扩展，需要购买升级；较适合希望采用完整现成编辑UI的情况。
