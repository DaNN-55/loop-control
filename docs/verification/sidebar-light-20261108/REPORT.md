1. `LocalCatalogApp.account.test.tsx` 2 项和 `LocalCatalogApp.navigation.test.tsx` 16 项通过。

4. 正式页面实际验证展开/折叠、账号选择、浏览器返回与刷新；收起后 64px，账号页面的选中行为保留。未启动或停止用户剪辑器。
