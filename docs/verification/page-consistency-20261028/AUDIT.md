# 逐页独立审查与取舍

| 页面 | 独立 Agent | 处理 |
|---|---|---|
| 工作台 | audit_workbench | 移除重复的首条“继续审核”；保留队列、各独立分页与必要计数；阶段小窗口栅格明确为3/2列。 |
| 生产单列表与弹窗 | audit_production_list | 筛选摘要/操作尾部统一基线；空态根据上下文给指引；精简删除范围标题，保留不可恢复及所有保护说明。名称 Tooltip 与整行打开是键盘/事件需要，保留。PC表格列不删。 |
| 待审核 | audit_reviews | 审查先误指退役 App，已补查实际 native 路径。移除新建入口和无效归档筛选，切入时恢复有效active范围；保留表格上下文、版本、行操作和API合法view。 |
| 账号/蓝图/系列/Harness | audit_accounts | 系列列表命名、版本登记重复标题/英文眉标移除、冻结说明收紧；字段/错误/确认/版本事实保留。顶部操作gap统一。 |
| 连接配置 | audit_connections | 业务空间字段辅助信息去重；保存行长名称操作顶部对齐；可用状态不重复标题。列表编辑/对象切换/局部连接复用承担不同任务，保留。 |
| 历史资料与来源 | audit_history | 嵌入区根据页面命名，子详情标题16px；清理预览各安全事实有不同意义，不机械合并删除。来源、预览、分页、下载和精度保留。 |
| 生产详情/逐镜头 | audit_production_detail | 展开工作台不重复标题；统一工作台间距；整期视频预算提取为一个入口，任务命令字段/金额校验保留并增加草稿/异步验证；Studio标题和路径收紧。阶段/审核/下一步表达不同事实，不合并状态。 |
| 交付/完成 | audit_delivery | 清理恢复文案指向当前连接配置；材料长名操作顶部对齐；统一中文“生产单/标签”。标准顶部关闭+底部关闭属于长弹窗可用性，不机械删除。 |
| 登录 | audit_login | 双栏/标签/认证错误与自动填充已符合规范，无需修改。 |
| 登录与安全 | audit_security | 删除与安全无关的新建内容账号说明；表单间距16px。保留安全边界、取消/关闭、12位和二次输入校验。 |
| 密钥管理 | audit_secrets | 顶部说明收紧，验证要求保留在帮助和实际验证处；长说明与刷新顶部对齐；所有敏感清除/权限/请求逻辑不动。 |
| 系统状态 | audit_system_status | 保持唯一底部入口；浮层主题/圆角/间距与native一致，attention用warning/offline用danger；状态时间频率失败与刷新保留。 |
| OpenChatCut | audit_studio | 实际编辑器源在被忽略的 .loop-control/local/OpenChatCut（独立运行时），本仓只维护启动/路由/工程适配。只整理本仓Studio宿主标题、间距、长路径，独立编辑器和真实工程/媒体不改。 |

所有审查均只读，执行由主 Agent 完成；唯 audit_production_detail 后续获单独执行任务，负责 WanShotGenerator.tsx 和其测试，主 Agent 负责父组件接线，无文件写入冲突。
