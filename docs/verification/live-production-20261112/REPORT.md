## 主单具体做了什么

- [完整适配脚本](01-caiyun-v2.md)保留参考脚本的六段口播，使用模板v2、9:16、独立镜头字幕；首帧引用和最终封面均使用用户指定的挂轴原图。未新增替代产品图片。
- 六个视频输出全部来自真实 MiniMax-H3-Lite / 768P，参考素材模式。使用原图，分别覆盖产品展示、山水细节、客厅和店铺场景。[视频抽帧](07-six-api-frames.png)。
- 六段真实火山 TTS，Vivi 2.0、语速1。实际音频为4.68 / 5.472 / 6.288 / 3.24 / 7.08 / 3.888秒。视频窗口最后按音轨帧长排列为141 / 165 / 189 / 98 / 213 / 117帧，共923帧，画面与口播无相互覆盖。
- 六段 WhisperX 使用现有离线缓存模型真实执行，全部 `method=local_whisperx`、`status=completed`，16个短语结果经正式 Owner API 采用。[对齐回执](real-alignments.json)。不是均匀分配文字的假对齐。
- MiniMax音乐接口实际返回410 / 2153，无使用资格；按用户确认改用 Freesound。实际采用 [A ride through chinese valley / neolein](https://freesound.org/people/neolein/sounds/573972/) 和检索得到的 `Trickling Stream.wav / mike_stranks`，来源及许可保留在项目和交付元数据中。配乐-12dB、遇人声降低10dB，音效-6dB；视频原声关闭，避免与口播竞争。
- 使用真实 OpenChatCut 原生编辑接口修改草稿，经页面“保存并返回”保存；随后正式导出、确认字幕、上传原图封面、填写标题/简介/标签、生成交付包。未直接覆盖工程文件或改任务成功状态。

| 已失效但尚未发送的 ready 视频让生成器一直显示繁忙 | UI统一使用既有任务呈现规则，失效历史不算活动任务 | [修复前](invalidated-ui-red.log)、[53项定向检查通过](invalidated-ui-green.log) |
| 上述未发送旧任务仍挡住新的明确请求 | 新增164迁移，只放行已失效且没有费用预留、发布和外发证据的未发送ready；running及付费/未知/hold围栏保持 | [复现](invalidated-queue-red.log)、[11项集成通过](invalidated-queue-green.log)。迁移仅应用在隔离库 |
| 菜单把缺少本机live验证回执的连接列为已验证，真正提交时409 | 连接投影使用与执行入口一致的资格＋live成功回执条件；缺回执直接提示重新验证，不读取或重写密钥 | [专项复现](connection-probe-red.log)、[真实集成通过](connection-probe-green.log)、[连接相关27项单测](final-connections-unit.log)。重启后实际已验五个连接仍可用，其余缺回执连接不可用 |
