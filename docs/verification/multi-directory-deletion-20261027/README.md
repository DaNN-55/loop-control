# 永久删除同步清理旧副本

2026-10-27。Owner 授权只修改功能，不删除现有数据。本轮所有真正删除使用独立临时数据库及临时文件；真实页面只打开确认框后取消。

## 范围与行为

- 从当前媒体部署映射中的账号相对路径发现同一生产单 ID 的旧副本，不扫描磁盘或素材库，不按标题或模糊名称匹配。当前目录及已存在的对应旧副本目录逐项列在确认框。
- 提交同时绑定确认文本、完整有序目录清单及版本，版本包含目录设备/节点身份。清单缺失、遗漏目录、目录出现/消失/被替换均拒绝继续。旧客户端忽略多目录字段时也会被拒绝，不能在未展示全部目录时追加删除。
- 外部盘未挂载或不可访问时阻止检查；目录或父级为符号链接时拒绝使用。文件删除只发生在已确认的 `episodes/<id>` 目录。账号素材库、其他生产单、未登记位置和其他路径保持；生产单目录内指向原始素材的文件/目录链接只移除链接，不遍历删除目标。
- 每个目录在自身文件系统内暂存，避免跨盘重命名。任一暂存失败或数据库事务失败时恢复所有已移动目录；数据库提交后逐个清理，全部完成后才登记完成。重试依据已提交回执中的原始清单及身份，不重新发现其他副本。
- 系统维护列出全部暂存目录，可重试部分未完成清理；旧回执保留原单目录范围，不追加未经旧确认包含的副本。
- 列表入口、详情入口和相关验收命令同步使用完整目录清单。Owner、归档、运行任务、资产锁、并发锁及只读历史保护保持。
