## 未分系列核实

这是账号下的默认文件收纳容器，不是会自动增加创作规则的普通系列。新建生产单省略 `seriesVersionId` 时，首次会创建该目录并收纳生产单；“调整收纳”也可把已有文件移到这里，而不更改创作系列基线。账号页入口目前总会显示，实际目录可尚未创建。
