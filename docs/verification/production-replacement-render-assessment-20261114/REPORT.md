### 技术链通过，画面仍有缺陷

实际查看两镜抽帧，棋盘格仍进入正式 MP4。隔离 SDK `src/editor/TimelineComposition.tsx:28` 定义 `GRID`，第 298 行在 `transparent=false` 时将其用于根背景；contain 留空处直接将网格输出。它是预览背景和正式输出混用，文件存在、解码、SHA 正确及 delivery_completed 均不能证明画面符合预期。

建议先独立修 SDK 输出边界，并加入实际画面检查。不能用强制铺满、裁掉内容或放宽检查来掩盖。本轮没有修改 SDK，也没有核查日常部署的 SDK 是否相同。

### 人工口播技术名称仍容易误解

本单人工上传音轨仍登记为 `generate_narration` 任务，混音中的主声音模式仍是 `tts`。实际 attempt=0、发送事件=0、费用预留=0，不能将这些登记行算成两次供应商生成。当前埋点在本单没有这样误算。

这是「用途、来源与执行方式共用旧枚举」的问题，兼有命名和结构含义；后续宜在当前模型明确 narration 用途与 manual_import／provider／source 来源。若拆任务类型，必须同步资格、领取、回执、约束和恢复；原任务行不重写，不能全文替换 tts 字符串。
