# 全项目下拉筛选空项检查

日期：2026-11-02。

所有数据筛选只显示有对应对象的选项；保留“全部”用于清除筛选。完整计数在搜索和分页之前计算，避免当前页或搜索结果为空时丢失筛选入口。当前选项的数据被清空时自动回到全部；范围切换加载中不依据旧计数重置。

| 页面 | 检查与处理 |
| --- | --- |
| 工作台 | 账号、系列按完整目录计数显示 |
| 生产单 | 账号、收纳系列、未归档／已归档按完整目录计数显示 |
| 连接配置 | 生产能力、验证状态按已保存连接显示，保留真实不可用连接的状态筛选 |
| 模型设置 | 模型范围、能力按完整模型目录和当前启用草稿显示 |
| 生产单历史 | 未归档／已归档按有生产内容的完整历史范围计数，不受搜索或分页影响 |
| 资料来源 | 分类、归档范围按完整来源计数显示 |
| 密钥管理 | 分类计数在受保护的完整库存中计算，不取当前页，不读取密钥明文 |
| 账号切换、连接版本、镜头、候选、素材、音轨、预览产物等对象选择 | 已从真实对象集合生成；保留已保存对象和必要的当前不可用状态说明 |
| 新建／配置表单、收纳目标、排序、用途、语言、时区、模式、操作菜单 | 保留实际支持的选项；这些入口用于创建或设置第一条内容，不能按现有生产单数量删除 |
