# 分镜台视觉对齐验收（2026-11-19）

本次只调整准备页视觉和恢复被错误取消的面板拖动。图片、视频、声音、字幕的生成、采用、保存和删除命令均未改变。原有删除二次确认保留，真实页面仅打开后取消。

## 结果

- 固定表格列宽仍为 72 / 300 / 72 / 84 / 44px；表头与正文文字左对齐，标题、首列、底栏均为 12px 左边距。操作标题和删除图标的左缘对齐。
- 左侧镜头标题栏和右侧主要页签同为 48px；触屏为 60px。子页签和单行控件以 32px 为基准，触屏页签保留 44px。移除开关标签旧外边距，声音/字幕/音效内容起点一致。
- 恢复 9px 可见分隔条；指针拖动、方向键、Home/End、双击复位、刷新记住宽度均可用。默认左栏 572px；右栏最少 360px。面板缩窄时表格内部滚动，列宽不变。
- 删除 hover 使用项目 error-solid_hover 实心危险色和白色图标。沿用现有二次确认；取消后镜头仍为 3 个。
- 独立 CSS 避免改写另一对话正在修改的 production-compact.css。修正刷新后 CSS 加载顺序覆盖和准备情况列旧 5px 边距；只读表格不误用操作列表头规则。

## 实际验证

- 先新增分隔条恢复测试：3 项失败；实现后对应测试通过。
- 定向回归：7 个文件 88 项全部通过，覆盖布局、镜头表、完成页/编辑页、主声音、口播和音效。测试有既有 jsdom 媒体 pause 未实现与 act 警告，不是实际浏览器错误。
- npm run check 与 npm run build 通过。构建仍提示既有大资源块警告。
- 已登录日常页面实际截图：图片、视频、声音、字幕、音效；参考图、图片/视频/语音来源、图片规格与质量、生成数量、构图/留白及其子选择、视频规格/输入方式/时长、主声音、语言、音频来源、准备情况列表。现有菜单按内容保持约 200–300px，参考素材面板约 420px，未强行统一不同用途面板宽度。
- 真实拖动 572→506px，表格仍 572px；右方向键至 522px，刷新仍 522px，双击恢复 572px。
- 1458×944、1280×720、1000×900、390×844 截图检查。窄屏自动上下排列，表格内部横向滚动；页面宽度没有横向溢出。测试用尺寸覆盖已清除。
- 独立测试标签页控制台 error 日志为空，测试后关闭；原标签页留给另一对话。未生成、采用、删除媒体，也未选择模型或修改业务配置。

未验证：被当前未选语音模型禁用的音色菜单、其他供应商才显示的动态参数，以及真实触屏设备。没有为检查菜单而改变用户模型配置。本轮不重复付费生成和全制作业务验收。
