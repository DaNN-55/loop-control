## 用户可见变化

- 在同一总览选择口播／画面／字幕，勾选镜头后一次准备；不勾选时处理当前类别可准备的镜头。采用、处理中、结果未知和关闭的项目不会被重新生成。
- 生成前统一核对逐项输入及预算预留，后台仍保留独立任务和回执。结果集中试听／预览／核对，通过后统一确认采用；不自动采用。字幕先依照已采用声音对齐，再集中预览实际时序与采用。
- 单镜头详情和本单制作设置保留高级配置入口，复用原有模型、提示词、首帧、时长和模板来源；缺失或不兼容输入明确转到详情处理。已完成作品仍沿用只读界面。
- 核对状态和已接受批次按 Owner／生产单保存；刷新可恢复。回执未知时使用原请求恢复，不创建替代生成请求。原子采用前重验当前输入和工程版本，任意项无效则整批不写工程。
