# 逐镜头 C 版正式接入

日期：2026-10-29。已按用户选择接入正式页面；不再需要 prototype 参数。

## 实现

- 左侧固定镜头列表，保留补充、删除、拖动及键盘排序；使用缩略图、编号、三行原文、A/B-roll 和时长辨认镜头，当前镜头自动滚入列表。增删和排序仍提交已有的带原因分镜修订，不直接改写已冻结分镜。
- 中间为真实的画面制作、声音与字幕、核对与确认。按素材、构图、片段标记排序；字段使用同一边框内的标签和值，移除重复外部标题，保留 aria-label、校验及焦点状态。短字段、对齐操作和安全区参数合理同行。
- 右侧预览稍宽于编辑区，媒体保持比例，浅灰背景；移除预览下方重复口播。保存与确认操作固定在编辑区底部，正文区域独立滚动。
- 移除逐镜头整期编辑和确认区的可编辑工程入口，整期编辑统一保留在合成与 QC。生成信息按需展开；生成与重试、AI 视频、本期声音和预算仍可从更多制作设置进入。
- 复用原有草稿、导入、TTS、音效、字幕、人工时序、对齐、预览与确认回调，不放宽正文核对、当前指纹或阶段围栏。失败保留草稿。

## 布局取舍

桌面三栏为 200px 镜头列表及 0.95:1.05 的编辑/预览比例；1350px 以下缩减列表与栏间距；1150px 以下将编辑区放到镜头列表和预览下方，650px 以下单列。各栏内滚动，避免压扁预览或让控件横向溢出。高度随视口调整；窄屏允许页面纵向滚动。

[桌面截图](desktop.png)，[800px 重排](narrow-800.png)，[确认区](confirmation.png)。1543、1280、1024、800 宽度下页面宽度与视口一致；展开槽位和字幕安全区后未发现字段横向溢出。S10 选中后完整滚入列表。

真实样片原片为 720×1280，已实看完整竖版。横版使用相同的宽预览和 object-fit:contain；本次未导入横版文件做媒体验收。
