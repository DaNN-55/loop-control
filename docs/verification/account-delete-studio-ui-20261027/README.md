## 账号删除

`studio-2` 没有生产单，但有一条历史导入的审计事件。删除账号原本会级联删除事件，历史审计标记的默认限制外键却阻止删除，接口返回 409「配置冲突或仍被引用」。

前向迁移 `065-account-audit-deletion.sql` 只把 `historical_audit_events.event_id` 改为 `ON DELETE CASCADE`。历史版本、来源、文件及投影结果保持独立；有生产单不能删除的规则不变。迁移已应用，所有旧迁移摘要核对通过，没有创建备份。

真实应用角色回滚验证：修复前触发 `historical_audit_events_event_id_fkey`；修复后 `delete_account` 返回 `true`，事务内账号数量为 0。回滚后账号、审计事件及历史标记摘要与原值一致，**未实际删除 `studio-2`**。

隔离测试只复制结构到临时空数据库，通过真实 HTTP、会话、CSRF 和 PostgreSQL 验证：删除返回 200、同键重试成功、同键不同内容拒绝、错误确认文本拒绝、其他 Owner 账号不可见、有生产单拒绝、附属记录与标记正确清理、其他账号及历史原文相关五表保持原值。测试数据库已清理。
