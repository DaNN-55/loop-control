## 实现范围

- `db/current/baseline.sql` 来自已核对的当前有效结构，建立第二代空库；不再从冻结平台基线逐条执行 162 次迁移。
- `db/archive/legacy-v1/` 保留旧基线和 162 份迁移，共 163 个 SQL 文件。逐文件与共同基线原始字节比较，全部一致；manifest 固定 SHA-256。
- `schemaMigrations.ts` 统一维护、恢复和隔离夹具的目录解析与 ledger 检查。拒绝未知版本、改变的摘要和历史缺口；空库只写新代际标记，不伪造执行过历史迁移。
- 第一代转换保留原 ledger，补齐旧迁移后，在一个事务中完成结构转换和第二代标记；重复执行为空操作。默认日常迁移器不跨代。
- 旧备份先核对原始业务行、序列、权限、媒体和冻结记录，再在全新恢复目标转换。恢复发布必须确认第二代标记，避免旧准备回执跳过转换。
- 15 个函数清理退役分支，保留签名与执行授权。无人调用、仅服务退役自动旁白的旧入口改为明确拒绝。连接约束拒绝新建退役服务；旧导出已有的历史连接保持原值，不换供应商、不生成、不计费。
- 测试中的物理 SQL 读取路径跟随归档调整；原 `db/local/NNN-name.sql` 逻辑夹具请求仍支持。未修改现行 UI、媒体执行器或技术参数。

架构决定见 [ADR-0047](../../adr/0047-clean-sql-baseline-generations.md)。
