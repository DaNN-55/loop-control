### 新发现：预览棋盘格进入实际成片

已提取并查看两镜头的实际 MP4 帧，与原始测试图对比。原图只有彩条，没有棋盘格；导出后的画幅空区有棋盘格。第一镜横向偏移来自本次明确的原生编辑，第二镜未偏移；`contain` 留空也属于本单选择，不能将这些设置当成缺陷或强制改成裁满。

固定测试 SDK `TimelineComposition.tsx` 的 28／298 行使用棋盘格作为非透明背景；`remotion/Root.tsx` 的默认参数为 `transparent:false`。已保存 [源码位置、内容和哈希](evidence/sdk-background-source.json)。这证明本次 SDK 的导出背景行为；本轮未连接日常运行环境，未确认其 SDK 是否同版本。

建议把预览装饰和最终合成背景分开：普通 MP4 明确底色，透明输出按实际支持格式另设。新增横／竖／透明素材、位移、空区和多镜头抽帧验收；不通过删除文件、素材校验或精确确认来处理。此问题本轮未修复。

## 埋点联验

已实际读取用户引用「埋店」对话 `01a1d24f-d6ab-7a20-ad89-8436bdc9b6df`，并核对当前实现。采集代码已经存在于当前工作区；本轮仅在专属测试 Owner 开启采集。

| 本单事实 | 实际事件 | 解释 |
| --- | --- | --- |
| 新建生产单 | `episode_created=1` | 只有一条创建事实 |
| 阶段变化 | `stage_changed=2`，`stage_transition_evidence=2` | 是两种记录，不能相加当四次推进；不足以拆出页面四步耗时 |
| 两条人工口播采用 | `candidate_adopted=2` | 对应两条主口播；不是全部素材采用次数 |
| 本地图片和配乐实际使用 | 工程含图片及一条配乐，没有对应的独立使用事件 | 现有候选埋点范围不包括完整素材使用，缺口已实际核对 |
| 交付任务 | 排队、领取、attempt 开始／结束各 1 | 人工导入没有 Worker attempt，不虚构生成次数 |
| 确认和交付 | `delivery_confirmed=1`、`delivery_completed=1` | 确认与完成不同，音轨正文另由实际 metadata 核对 |
| 保存重开 | 事件流水前后完全相同 | 重开没有重复计数 |

此外，本轮现有集成验证了：受控口播的冻结估算、请求标记／响应、采用／撤回／再采用、真实工程静音与恢复、显式重试归因、质量版本冻结、镜头删除、Owner 隔离、同键幂等／冲突、事务回滚、错误 lease，以及统计响应写入失败时不重复发送 Provider。真实主机单次采样写入也通过，未做 30 秒连续观测、跨重启采样或 GPU 验收。
