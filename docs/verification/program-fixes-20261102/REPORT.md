# 真实 E2E 后程序侧修复验收

日期：2026-11-02。范围：运行版本隔离、HTTP 错误提示、登录与制作流程加载状态、Keychain 提示。开发与故障注入在独立源码、独立 PostgreSQL 和受控供应商环境完成；本轮不处理模型质量，不调用付费服务。

## 修复结果

| 问题 | 修复行为 | 验证边界 |
| --- | --- | --- |
| 开发源码变化会阻断运行程序，旧后台可能启动新 Worker | 后台和 Worker 在启动时绑定独立运行版本；准备下一版本不替换旧版本，准备失败保留旧指针；继续检查固定产物的身份和指纹 | 独立目录、正式常驻调度器、真实编译 Worker 子进程、真实 Owner HTTP／PostgreSQL、受控口播 |
| HTTP 503 缺少可执行提示 | 运行程序未准备／损坏使用稳定错误码与准备、重启说明；其他故障使用安全提示，写操作要求先核对已保存结果 | 实际 HTTP 服务器；不向页面返回路径、凭据或底层诊断 |
| 初始加载闪出登录框，制作读取失败显示成“没有工程” | 区分会话检查、目录加载、未登录和失败；制作步骤显示读取中／读取失败；成功读取后才显示缺失或完成状态；重试仅重新读取 | 组件回归和真实浏览器，网关延迟与 503 注入 |
| 恢复工具遇到锁定 Keychain 只给笼统故障 | 先读取锁定状态，给出 `npm start` 解锁指引；系统授权拒绝单独提示；工具故障不暴露诊断 | OS helper 受控边界和真实 CLI 只读检查；不锁定、不创建、不轮换日常凭据 |

运行版本设计见 [ADR-0025](../../adr/0025-prepared-runtime-releases.md)。前端仍沿用 Vite 开发热更新，外部 SDK、Node 依赖仍沿用原部署方式；本轮固定的是后台编译模块、Worker 编译模块和正式规划执行脚本。旧运行版本保留，避免误删仍被进程使用的文件。
