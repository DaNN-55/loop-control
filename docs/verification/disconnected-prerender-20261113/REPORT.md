# 未挂载触发器与旧预渲染入口清理

日期：2026-11-13。状态：7 个目标均确认无当前功能、旧包或历史恢复消费者，已完成清理、完整隔离验证及日常完整备份候选演练。用户另行明确授权后，177 → 178 已在同一事务应用日常，统计采集保持关闭，服务未重启。不提交、不推送。

## 逐项决定

| 对象 | 当前证据与决定 |
| --- | --- |
| `public.confirm_frozen_shot_when_ready()` | 未挂载触发器，无有效 SQL／源码／保存包消费者；删除 |
| `public.queue_source_audio_after_frozen_clip()` | 同上；当前原声提取与结果回写使用保留链；删除 |
| `public.guard_b_roll_task_claim()` | 同上；当前并发、资源和领取保护由现行领取链负责；删除 |
| `public.create_pre_render_review_packages()` | 无有效 SQL／源码／保存包消费者；删除旧全局预渲染审核包组装入口 |
| `public.create_pre_render_review_packages_for_episode(uuid)` | 同上；删除旧逐期组装入口 |

7 个目标的有效 ACL 均仅 postgres 可执行；检查同时覆盖有效函数体和 `pg_depend`，未以目录依赖为空单独判断。全部 23 个保存运行包逐字节扫描无名称引用，原包树摘要见 `runtime-audit.json`。本组没有必须保留的目标。

178 只有 7 条明确签名的 `DROP FUNCTION`，使用默认 RESTRICT；没有 CASCADE、数据更新、权限授予或已挂载保护触发器拆除。移除 1 个陈旧公开 RPC 类型条目。旧 Studio／最终渲染、审核与冻结、历史复用、当前任务领取、费用／未知提交、文件及发布保护函数均保留，历史 SQL 原文和原包未改写。

## 非空历史与真实依赖验证

在含默认关闭 177 的隔离库构造非空旧任务、制作启用记录、规划选择、两代连接版本及绑定／intent、预渲染审核包和成员证据。预渲染包使用有效旧合同 `stage=production_ready`、`review_kind=pre_render`；成员引用真实数据库中的已完成渲染任务，保留依赖记录触发器。

完整 SQL 导出后恢复并精确对账，再执行 178。3 个触发器函数分别安装真实探针触发器，4 个入口分别建立真实视图依赖，7 次迁移均以 `2BP01` 阻断；每次移除探针后全量快照复原。中途注入 `22012` 整笔回滚；正常迁移仅删除目标 7 个函数并增加 1 条 ledger。业务行、序列、角色、其余目录／触发器／ACL 和旧 ledger 精确保持，重复计划为空。删除前业务角色无执行权限，删除后各角色均为 `42883`，历史不变。

同时实际执行原保存包的 46 个 Worker 模块启动／规划检查、23 个空扫描器和 23 个连接模块。旧派单仍拒绝、历史启用记录扫描仍为空；旧连接创建／轮换／验证／撤销仍使用本地合同。使用真实模块与 PostgreSQL、合成 SecretStore，不调用 macOS Keychain 或公网供应商，也不声称启动了整套旧应用。
