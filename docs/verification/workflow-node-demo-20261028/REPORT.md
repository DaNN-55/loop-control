# 节点工作区独立 Demo · 2026-10-28

交付：单文件 HTML，地址 http://127.0.0.1:58750/ 。真实应用5174及其源码、数据、认证配置未修改。仅在新的演示目录创建HTML，保留用户指定的原始HTML。

## 设计与交互

- 七个节点均可点击，只显示当前查看节点。实际生产阶段独立标记；点击/方向键/Home/End只切换查看，不推进模拟状态。
- 左侧为脚本/视觉/分镜/同步视频/审核成片/QC/交付预览，右侧为该节点的上传槽、设置和明确操作。完整阶段内容不再堆叠在下面。
- 已完成节点默认只读，创建修订后才可编辑。未到达节点可看资料要求，上传/审批/QC处理均禁用，不提前列出未来产物。
- 上传可填入示例，也支持选择/拖入文件并显示文件名及大小。所有数据只在本原型中模拟；不处理真实视频、不上传文件到服务端。
- 输入/镜头/分镜批注草稿按生产单、节点与镜头隔离；点击主题或其他重绘动作先记录草稿。文字、字幕、分镜批注、交付标题与对应左预览联动；画面布局可切换双屏。
- 逐镜确认会选择下一个未确认镜头，全部确认才进入预渲染。QC要求两项核对、审批理由和阻塞处理完成，明确批准后才进入交付。
- 产物索引为可搜索、带所属节点/版本/大小的列表浮层；审计为可按流程/素材/审核筛选的时间线。放大为预览卡右上角图标，保留名称、焦点及Escape返回。
- 原始HTML的历史资料/外部连接模块、顶栏子树、原有CSS直接保留。只将侧栏收敛为已认可的五入口及底部工具；旧独立待审核入口不恢复。
- 顶栏搜索、通知、场景菜单和配色切换可操作，沿用原型实现。所有账号、素材、凭据和动作反馈均为模拟数据。

## 验证

- 浏览器实际测试节点切换、当前阶段不变、Home定位输入且焦点保留、未来QC全部只读、草稿跨节点/主题保留、分镜两镜批注隔离和左预览同步、双屏构图、四镜连续确认至预渲染、QC未满足条件不推进、QC批准至交付、交付标题即时预览及完成反馈。
- 实测产物搜索qc-report只显示匹配行，详情可打开；审计筛选、预览放大与Escape关闭可用，关闭后焦点返回放大按钮。
- 历史资料与详情、外部连接与新建表单、全局搜索、通知、配色切换实际打开检查。浅深色在1280×720无页面水平溢出；当前DOM只有一个节点面板与一个操作表单。
- 独立只读审查发现并修复：QC处理按钮绕过只读、分镜批注不隔离、末镜不能推进；另修正未保存批注跨重绘的预览一致性。复核无阻塞项，主Agent重测相同步骤。
- 原始配置模块（47104bytes）、维护模块（32661bytes）、topbar和原CSS逐段一致；378个真实src文件哈希不变：verification.json。
- 内联JavaScript语法检查通过；手工Impeccable detector一次无发现，自动hook未启用。CSP的connect-src为none，不请求真实业务API。

## 确认范围

这是交互与视觉确认用Demo，不是生产实现。真实状态机、节点历史证据/冻结版本与编辑权限如何映射，应在用户认可本Demo后实施；不能用演示审批结果当作真实生产状态。

服务器仅监听127.0.0.1:58750，保留供用户确认；启动进程为本轮Python静态服务器，不影响真实5174服务。未提交、推送或迁移业务页面。
