# 逐镜头 A 版连续表单正式接入

日期：2026-10-29。已按用户选择将 A 版布局接入正式逐镜头制作，保留既有业务命令和阶段限制。

## 改动

- 镜头列表改为统一图标增删，保留原来的带原因分镜修订。支持 194px/170px 列表折叠为 70px；折叠后保留编号、缩略图、悬停简介、拖动/键盘排序和切换。折叠状态归 ShotWorkbench 管理，切换镜头后保持；不影响旧的横向分镜条。
- 构图示意、布局、槽位片段、填充、焦点和衔接集中到一个表面，取消分散小框和额外折叠。复用原有布局和片段映射回调，四宫格等布局仍可用。
- 片段增加同行入出点输入，保留原有标记轨道、锁长、逐帧、对齐和片段预览。输入允许中间空值，失效区间阻止保存，聚焦/离开不会擅自截断原始精度；锁长沿用既有 clipTiming。预览按需展开。
- 字幕定位图在大屏为 160×284px，右侧字段最大 210px；较窄桌面为 136×242px、字段最大 190px。字幕位置、自定义边距、行数和字数保持真实保存与校验。横版和方形按 data-aspect-ratio 适配。
- 口播编辑和恢复/生成放在同一编辑区，紧接真实试听；历史音轨与证据在音轨信息中保留。音色、语速、试听和恢复本期同行；只有编辑音色后才随普通保存提交覆盖参数，原有生成/预览及恢复回调保持。恢复失败时保留待保存状态并可重试。
- 跟随口播时省去重复的只读字幕正文，独立字幕仍可编辑；正文核对、时序、生成重试、预算、BGM、音效和确认围栏保留。整期编辑继续统一放在合成与 QC。
