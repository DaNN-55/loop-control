- 右上角账户菜单新增「个人偏好」「通知」，保留登录安全、管理员密钥管理和退出。
- 偏好按登录 Owner 保存至 PostgreSQL；显示名称用于账户菜单，外观支持浅色/深色/跟随系统，行距作用于工作台、生产单、蓝图能力、连接和历史列表。当前只有简体中文，不提供未实现的语言选项。
