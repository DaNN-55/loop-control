# 上传失败短提示与恢复入口

2026-11-08，按用户要求移除常驻的上传结果列表。

## 行为

上传批次结束后显示 5 秒提示，可手动关闭；单项失败保留文件名与具体原因，多项失败显示汇总。提示通过 status 通知辅助技术，不抢焦点。

逐文件状态、原 File、成功导入回执与候选登记状态继续保留。右上角“上传记录”默认收起，按需查看明细和重试；处理中仍可查看进度，重试按钮禁用，避免重复提交。取消或超时关闭提示不会删除记录。关闭/切换面板后，过期提示不重播，未完成项目仍可恢复。

上传/候选登记失败由本地界面提供反馈，父工作区不再重复显示同一错误。其他工作区错误不受影响。导入成功但候选登记失败时，重试只补登记；候选已成功但回执丢失时仍先核对现有候选。热更新后新条目编号接续当前缓存最大编号，避免已有记录标识被重复使用。
