# GPT Image 2 输入费用细化

日期：2026-11-02。已更新本地 5174 服务，未提交或推送代码。

## 改动

- 文本估算使用实际发送的完整 prompt，包含参考图用途／保留要求、构图和字幕留白、账号规则、系列规则。估算与任务入队共用 `imageRequestPrompt`，避免漏算拼接内容；实际请求格式保持原样。
- 按 Unicode code point 处理混合文本：ASCII 暂估每 4 字符 1 token，Han／日文／韩文每字 1.5 token，其他字符按 UTF-8 字节长度每 2 字节向上取整。各类合计向上取整，空白和标点计入。
- 逐张校验登记文件的 SHA-256／大小，通过现有 `ffprobe` 能力取得真实宽高。每张输入 token 本地暂估为 `2048 + ceil(宽×高/128)`，不再每张统一留 $0.08。保留每张 20 MB、合计 40 MB、最多 16 张及既有格式限制。
- 文本、图片输入分别使用已核实的 Standard $5／$8 每百万 token，输出仍按官方计算器与 $30 每百万 token。输入明细记录文本字符／token、各参考图尺寸／token、合计、输出档位和输出 token。
- 自动质量仅在预算中按 high；生成请求仍传原选择的 auto。保留 20% 余量、金额调整、单次上下限、冻结输入、一次消费和未知提交阻断。
- 参考图缺失、损坏或指纹变化直接拒绝，不将尺寸缺失按 0 计费。消费确认时重新读取并校验；文件变化后不排队，确认消费回滚。

文字权重、基础 2048 和面积系数均是明确标注的本地预算参数，未使用真实供应商 usage 校准误差。OpenAI 未公布可核实的 GPT Image 2 完整输入 token／缩放规则，因此不能保证本次建议等于实际账单；没有借用 GPT Image 1 或通用 vision 公式。依据与限制见 [研究记录](../../research/2026-11-02-gpt-image-2-input-estimation.md)。
