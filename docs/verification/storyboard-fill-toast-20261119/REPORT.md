# 镜头表铺满、字幕浮动提示与拉伸悬停

按本轮批注调整准备页呈现，字幕任务、重试、采用和删除业务均未改。

- 表格宽度为左栏 100%。镜头/时长/准备情况/操作列固定为 72/72/84/44px；脚本列占剩余空间，宽度不由内容决定。编辑态最小 572px，只读态最小 528px，窄于最小宽度时内部滚动。
- 删除 hover 从项目 error-solid_hover 改为浅一个色阶的 error-solid，保留白色图标与已有二次确认。
- 自动字幕处理和状态轮询提示使用现有 FeedbackNotice 警告浮层，默认 4 秒，可关闭、悬停/焦点暂停；移除主工作区占位文字。字幕页的状态、具体原因、手工调整和重新同步入口不变。
- 补充批注：左右分隔条与素材库高度拉伸条共用同样的颜色语义。默认灰色 3×30px 握柄，悬停/拖动为浅蓝底、蓝握柄；仅键盘 focus-visible 保留描边。没有修改拖动逻辑。

- 1000px 屏宽下上下布局，左栏/表格均 886px，辅助列不变；页面无横向溢出。测试尺寸覆盖已清除。
