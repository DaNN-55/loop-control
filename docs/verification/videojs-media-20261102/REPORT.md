# Video.js 10 媒体播放验证

日期：2026-11-02。依赖固定为 `@videojs/react 10.2.0`；用户确认采用 Video.js 10 后实施，并按后续要求统一音频入口。

## 已完成

- 工作台使用 Video.js 的 React 播放、时间轴、音量、全屏组件；原有封面／视频切换与产物 SHA 链接保留。
- 左右箭头透明、无边框，悬停也不加底色；暂停与播放使用相同的悬停显隐规则。键盘焦点在播放器内时保留可见控件，触摸可唤出。
- 项目自有界面 7 个文件的 12 处音频入口统一为官方 AudioSkin，包括口播候选、配乐音效、音轨、交付／历史／材料预览及两处动态音色样本。共用 `src/ui/media/AudioPreview.tsx`，原生 Audio 仅在 Video.js 内部渲染。
- 音色样本保留原请求，加载后播放；替换样本和卸载时停止旧音频，替换导致的异步播放中断不误报。样本 Blob 在替换与卸载时释放，播放结束后仍可重听。
- 只读工程继续锁定编辑控件，音频播放器保持可用。没有修改历史 HTML 解析规则或第三方剪辑引擎。

## 检查结果

- 定向组件回归：10 文件／88 项通过。
- 默认全量回归：186 文件／1247 项通过。随后发现并修复只读 fieldset 对播放器的禁用，相关 3 文件／40 项回归通过；最后这项修复后未再重复全量。
- 最终应用类型检查、前端构建、Worker／后台编译与运行产物完整性通过。构建保留大于 500 kB 的分包提示；本次没有进行全站分包改造。
- 首轮全量中，新增 jsdom AudioTrackList 补充未区分 Node 环境，导致 45 个 Node 测试文件无法装载；已增加环境判断，并更新 1 项旧音效按钮断言后，全量通过。没有屏蔽播放器实现或替换 Video.js 组件来通过测试。
- 生产依赖 npm audit 未报告漏洞。npm 默认审计仍提示开发依赖问题，本次未进行无关依赖升级。

## 浏览器验证

实际 Chromium 组件页面验证视频与音频播放，视频暂停在 0.03 秒后移出时播放条 opacity=0；时间轴键盘操作定位到 1 秒、音量调为 0.95，全屏进入与退出成功。浅色 1000 px 和深色 390 px 实际渲染已查看，窄屏 document.scrollWidth=390，音频组件无内部溢出。截图为隔离组件现场，使用本次生成的本地合成媒体，不是用户成片。

正式 5174 页面在独立临时标签内验证：真实 1080×1920、12.032 秒成片实际播放；暂停在 4.401688 秒后移出，播放条 opacity=0；箭头 background=transparent、border=0。已完成生产单的已有 5.98 秒口播通过 AudioSkin 播放至结束，编辑表单仍禁用，播放器所在 fieldset 不再禁用。临时标签已关闭，用户原标签未关闭或导航。

未调用付费 Provider、未生成音色样本、未修改真实业务数据、未重启服务、未提交或推送。没有逐一播放每条历史音频，也没有测试真实触摸设备；通过所有源入口接入扫描、组件回归和代表性真实文件验证。
