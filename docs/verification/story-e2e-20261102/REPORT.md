## 运行

```zsh
npm run test:e2e

# 只运行某条流程；仍会创建独立现场。
npm run test:e2e -- -t 'story 3'
```

需要当前 Mac 的 Node.js 24、Docker/Colima、FFmpeg、hdiutil、已安装的 agent-browser，以及项目现有 OpenChatCut 源码和依赖。运行器不下载依赖或镜像。默认使用当前 Colima socket 和已安装的固定 PostgreSQL 镜像。其他位置可通过 `DOCKER_HOST`、`LOOP_TEST_OPENCHATCUT_ROOT` 指定。

每次运行创建 `/private/tmp/loop-story-e2e-*/`，先打印证据目录。运行器复制源码及 SDK、隔离增量编译文件、生成 Worker／后台产物，然后建立无网络 PostgreSQL 容器，从版本化空基线和迁移初始化；不复制日常业务数据。浏览器使用随机独立会话，界面为真实 `LocalCatalogApp`。测试结束释放浏览器、监听端口、原生编辑器、测试数据库和私有 APFS 卷；运行器最后移除自己的数据库容器。源码快照和日志留在打印的临时目录，便于定位失败。

故事夹具拒绝日常运行上下文。不要用日常部署配置手动设置测试 gate。默认 `npm test` 继续排除这组集成测试。

## 测试替代与限制

- 供应商传输和秘密存储为合成、受控边界；未读取真实 Keychain 凭据，未调用真实供应商。没有使用真实充值余额或账单证明。
- Provider 的「已接收但回执丢失」与「已有远端 ID 后轮询失败」在传输边界模拟。浏览器网关故障分别位于请求到达服务端之前，以及真实命令已经返回 200 之后，返回 503／502，不伪造业务成功。
- 创建／迁移中断使用实际应用子进程 SIGKILL。应用重启会关闭并重新创建命令处理器；交付排队后的重启由原任务继续执行。本组未覆盖打包 Worker 在每一个文件写入点被强杀、30 分钟租约自然过期、所有供应商错误码或真实断电。
- 图像和视频是为新故事生成的确定性站台／黄伞／纸条图形，受控语音响应是合成测试音。字幕和请求正文是新故事原文；本组验证流程、来源和文件一致性，不验收真人语音内容、画面美学或实时供应商质量。
- 用户授权真实调用累计不超过人民币 5 元；本次实际调用 0 次、费用 0 元。实际生成的视频素材 4 秒，完整成片约 6.06 秒。
- 当前工作区存在其他聊天的并行改动。验证以每次运行保存的源码快照为准，本轮不覆盖那些改动，不提交或推送。
