# 工作台模板布局调整

用户要求参照原型首页，提高并加高右侧继续处理区、底部增加完整生产单按钮，中间改为原型列表样式；搜索提示采用 #838C9B。只修改工作台与该搜索提示样式，保持未提交。

## 最终行为

- 左侧审核提示与右侧继续处理顶对齐。PC 双列，右卡320px，最小高度740px，实际样例756px；底部完整生产单按钮始终在内容之后。
- 中间使用全部制作/待审核/制作中/需处理/已完成标签，搜索回车提交、账号/系列/排序均接入既有目录过滤和服务端分页。按行选择只切换当前作品；行末打开、下一步、底部按钮打开原有生产单。
- 原阶段数量条改为状态标签；表格保留名称、阶段、状态、最近更新。审核版本收为状态下方v标识，完整说明保留title。
- 右侧优先展示已登记发布封面，没有封面时展示当前实际渲染画面；没有媒体或失败时如实提示。复用Owner会话保护的详情GET和SHA绑定文件URL，不拼文件目录、不生成新媒体。仅加载当前选中生产单，切换中止旧请求，旧响应不会覆盖新作品。
- 保留审核跳转、阻塞说明与蓝图修复、系列特殊分组和分页；本轮不修改生成、审核、素材或业务写入逻辑。
- 修复原选择优先级：选中过生产单后，仍允许点击另一个列表条目切换右侧当前作品。

## 样式边界

浅色仅顶栏搜索提示文字改为 #838C9B，其他正文、图标和token不全局改变。深色提示继续使用既有浅色文字token，以保持对比。PC优先；1250px以下筛选栏可换行，1000px以下继续处理区移到主列表之后，640px以下纵向堆叠。断点为现有页面自然布局适配，不固定于用户截图尺寸。横向窄列表允许表格横向滚动，不引入嵌套垂直滚动。

## 验证

相关4个文件24项测试、前端TypeScript、隔离Vite构建及git diff --check通过。行为测试覆盖行选择与打开分离、服务端筛选回调、既有分页/待审/阻塞修复、预览竞态取消和SHA绑定、媒体错误提示、原顶栏与草稿流程。

真实浏览器检查默认1280×720与1543×953：审核提示和右卡顶部同为193.94px；1543视口底部完整生产单按钮底边929.06px；页面无横向溢出；真实视频readyState=4；浅色提示计算值rgb(131,140,155)，深色rgb(179,194,214)。制作中0空结果、搜索无结果/清除和底部完整生产单实际跳转均验证。临时视口已恢复，主题恢复浅色，右侧留工作台。

首次回归发现两个原断言需随已授权UI更新：完整审核版本由文本改为title；标题同时出现在装饰缩略块与主标题。导航回归还补充等待真实行内容出现，避免仅表框已挂载、数据尚未读取时的竞态断言。另一个Studio回归原先禁止任何详情GET，调整为明确只允许openStandaloneStudio这一条写请求，保留无生产单命令副作用的断言。本轮未执行真实生成、审批、上传、删除、发布或凭据变更。

只读子Agent已核查筛选/分页/待审/阻塞和真实媒体指纹边界。布局检测前后均无发现。构建仍保留项目既有大包体积提示，本轮未扩大性能重构。
