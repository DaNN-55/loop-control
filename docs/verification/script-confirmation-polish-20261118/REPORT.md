## “再次优化”的现状核对

依据 `src/local-app/scriptStudioRequests.ts` 的请求指纹和历史查找，以及 `src/local-app/useScriptStudioAssistant.ts` 的发送参数：同一所有者、生产单及脚本版本，原文、目标时长、模式、指令、模型连接与模型等请求条件完全一致时，会返回已有的成功结果，不重新调用模型。正在处理或结果未知的相同请求也不会自动重发；失败后可显式重试。

主“优化拍法”没有携带当前拍法回执；手动修改镜头后再次点击，可能取回原先的 AI 结果。“继续优化”提交修改要求时携带当前回执，基于当前方案；不同指令或父回执通常产生新请求。自动时长与手填同等秒数属于不同参数；脚本或连接版本变化也不能视为相同请求。
