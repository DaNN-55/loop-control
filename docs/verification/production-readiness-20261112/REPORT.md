1. 已失效且执行结束的旧未知提交，仍永久阻止完整备份。归档可保留历史事实，活动/租约/发布任务仍阻止；移动、删除保护未放松。见 [ADR-0045](../../adr/0045-backup-retains-invalidated-task-history.md)。

3. Freesound大预览下载超过30秒。只延长下载期限，搜索/大小上限/调用次数不变，错误可理解。
4. MiniMax旧连接缺失站点元信息时误显示国际站。从已有认证材料核对，缺失时显示未知，替换密钥必须选站点。
5. 前端进入瞬时发布围栏后停止自动读取。现在继续只读轮询，后台成功后自动显示结果，不重发任务。
