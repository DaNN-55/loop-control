# 第4项：实际存储故障与恢复

独立创建 256 MiB APFS 稀疏镜像，挂载到测试临时目录。没有卸载、填满或修改日常媒体卷。

- 实际卸载测试卷后，经 Owner HTTP 导入返回409；原路径没有在宿主机生成替代目录。重新挂载后，同一操作标识完成并可重复读取原回执。
- 素材目录实际 chmod 0500 后，新内容导入返回403；恢复0700后，同一请求成功。
- 实际写入约248 MiB直到操作系统返回ENOSPC，再导入12.8 MB文件，触发真实部分写入。APFS还保留约6 MiB，最初的小文件测试仍可成功，这不是应用失败，随后使用大于剩余容量的新输入验证。
- 修复前：清理要求完整输入长度，误把自身部分临时文件当成被替换，返回「输入发布文件已变化」。修复后：仍使用独占句柄记录的设备/inode，并核对实际写入前缀才清理，保留原始ENOSPC，提示检查空间和挂载。
- 释放测试填充文件后，原请求成功；原视频SHA保持，临时输入文件无残留。10项既有临时文件/恢复回执替换保护继续通过。
