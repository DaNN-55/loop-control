# 设置列表与回收站隔离预览

本次预览回答三个问题：连接列表能否减少同时争夺注意力的信息；密钥能否按稳定关联分组；回收站的容量规则能否被理解和操作。正式设置与生产单删除逻辑没有迁移。所有连接、密钥、余额和生产单都是内存中的合成数据，刷新即重置，没有业务 API、真实凭据或付费调用。

## 打开预览

在仓库根目录运行 `node docs/verification/settings-comments-20261111/demo/serve.mjs`。

- 连接：`http://127.0.0.1:5210/src/local-app/settings-review-v2.prototype.html?page=connections&variant=balanced`
- 密钥：同一入口使用 `page=secrets`。
- 回收站：同一入口使用 `page=recycle`。
- 密度比较：`variant=compact|balanced|spacious`，底部按钮切换并更新 URL。默认推荐 `balanced`。深色使用 `theme=dark` 或底部主题按钮。

## 布局与精简

连接列表保留现实长度的八个示例连接。主行收拢为「连接与服务」「模型与动态」「操作」三个区域；状态靠近连接名称，模型长名与最近验证、在途任务归在一起。更换密钥仍可直接点击，次要编辑、测试、完整模型、账务和版本信息在行内详情展开，不依靠横向挤压。没有删除业务能力；新建与编辑只模拟内存状态，不代表正式模块功能验收。

三种候选只比较行间密度，保持相同信息、按钮与展开结构：紧凑 12px、常规 20px、舒展 28px 的纵向内边距。常规在 1348px 窗口中可清楚扫描连接名称和模型，完整八项可在内容区滚动；紧凑更适合大量连接，舒展有利于阅读但需要更多滚动。窄屏改为单列，同一条连接的信息和操作保持相邻。

密钥首先按稳定连接 ID 分组，不依赖连接名称相同。当前制作密钥、账务密钥区分用途；旧版本在组内二级折叠，当前版本不与旧版本平铺争夺注意力。另列本机运行、历史还原、未引用分组。查看、复制仍需验证，演示密码为 `demo-password-123`，仅显示或复制 `synthetic-secret-*`。明文 30 秒后隐藏，切页立即清除。跨连接跳转定位到对应详情。

## 回收站建议与边界

建议默认上限为 5 GB，允许修改；删除先进入回收站，恢复回原账号与系列。达到容量上限本身不清理，超过时按移入时间从早到晚永久清理安全项目，直到回到上限内，不一次清空全部。

预览默认有 4.3 GB，点击「模拟删除一张生产单」新增 1.4 GB：合计 5.7 GB 后自动清理最早的 1.8 GB，剩余 3.9 GB，清理记录可展开。支持恢复、手动永久删除确认、容量修改和素材盘离线场景。仍被其他生产单引用的示例会跳过自动清理，也阻止手动永久删除；磁盘离线时保留超限提醒，不虚报释放成功。

这需要新的软删除与恢复协议，不能把现有「文件清理」改名后直接上线。当前 `episodeLifecycle.ts` 是精确清单暂存、提交数据库删除、最终清理文件；`recoverDeletion` 只恢复尚未提交的删除，不恢复已经删除的业务生产单。`episodeDeletionTargets.ts` 对其他生产单与历史资料引用、路径授权、文件身份和指纹作保护，正式回收站也必须沿用。正式实施还需确定账号已归档/删除后的恢复目的地、活动或未知任务能否入站、共享文件如何计量、目录离线后的恢复、容量降低时的清理授权与永久删除审计，不在本次预览中启用真实自动删除。
