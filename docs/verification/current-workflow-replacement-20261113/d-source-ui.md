# D：统一旧来源选择与接入入口

日期：2026-11-14。状态：本来源入口子批完成，完整 D 和 A–G 仍未完成。依据已批准实施规范 D、共通保护及 ADR-0066。本批不删除旧 SQL 或历史数据，不改共享 SDK，不提交、不推送。

## 实现与实际影响

- 空工作区的 GET 在同一 Owner 只读事务内返回 `workspace-source-options/v1`，不另发一次有竞争的来源探测；已有当前工程直接返回，不扫描或重新解释旧来源。
- 最近保存的原生工程优先；不可读或缺少基准时保留不可用原因。没有原生工程时列出完成的 HTML／JSON 工程，按原冻结关系匹配当前分镜；原工程存在但不可核验时阻止回退重建。没有这些原工程时，保存计划与原镜头工作版本通过明确选择接入。来源摘要不是文件验证或执行授权，真正接入仍重新核对。
- 已确认镜头保留原采用，待确认／跳过／混合来源走当前输入与候选接入。没有旧来源的新单保持本地准备；没有恢复旧整期启用、连接、预算或外部请求授权。
- 脚本确认先等待对应来源读取，不再由回调直接发新建命令。现有工程的明确修订仍按确认回执的新脚本 ID 继续更新，保留修订原因，不要求第二次输入原因，也不依赖父页面已立即刷新 ID。
- 原生／HTML／计划／镜头来源的写操作统一经过 `useWorkspaceOperations`。下拉框只选择，明确按钮才发命令；重复点击只有一次操作。脚本变化、转只读或当前新版本到达时，迟到回执不覆盖它；未知结果沿用只读核对。来源基准不匹配和非法回执明确报错。
- 移除历史查看组件中两处分散的接续按钮及仅为它们读取工程的准备页 effect，原生／HTML／分镜等历史查看和下载保留。等待选择时不再显示无内容的分镜面板。
- 390px 实看发现主题会把 Select 内置 Label 裁为屏幕阅读器专用的 1px。改用工作流现有的外层 label 结构，标签可见且保持控件关联；没有改全局 CSS、公共组件或另建视觉规范。

两个上一轮实际缺口现已修复：确认脚本后不再跳过来源选择；保存计划接入遇到登记的 HTML／JSON 原工程返回 409，不再从计划重建当前工程。原文件、计划、草稿和冻结来源保持。
