# D 备份与历史字段修复：两轴审查

固定D基线22XAKR/source，五个源文件差异。Standards与Spec分别以独立新上下文只读审查，不修改文件、数据库或历史包。

## Standards

`/root/d_backup_standards`：原格式扩展与更新后的历史解码／测试产物路径均无可行动违规。SQL保留原引号、历史JSON解码去壳；测试显式T13路径优先、默认当前批次或独有目录，复制拒绝覆盖保持。

## Spec

`/root/d_backup_spec`：初次发现P2共享消费者遗漏，decodeCopy会产生带引号的错误字段键。串联回归先红，再只对已验证列名去引号；JSON大整数与boolean保持，SQL仍使用原始columns。复核原问题闭环，无新增阻断。拒绝分号、表达式、注释、额外转义及未配对引号，未扩大SQL注入能力。
