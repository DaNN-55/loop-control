## 实际变化

原待确认镜头的 source 意图转换为严格的 `workspace-voice-input/v1` 当前输入，固定准确音轨／画面 SHA 和视觉区间，不携带连接、预算或执行授权。导入不等于采用：原确认不伪造，当前主声仍需 Owner 明确选择。原草稿、音轨、任务、文件和冻结证据保持。

新增原登记原声的明确采用操作，核验同单音轨、准确产物、有效完成任务和真实 MP3。采用独立音频文件，不声称重放原视频提取。当前 `workspace_audio_preparations` 保存受保护的登记文件采用回执，后续明确换成当前原片提取结果时，以实际来源证明转换；不制造任务、素材或原历史。原生元数据提示不能冒充回执。

替换与重复采用保留人工音量、开始位置、裁切、声轨、路由及静音；清除原 TTS 候选身份，调整引用及选择关系。先检查资产身份，完整可信回执才允许无变化返回；缺回执时明确重采用须重核验原画面和轨，只补登记而不改变工程字节。当前原生资产冲突仍拒绝。

原片声音入口放在「字幕与口播」面板，明确区分原登记文件、当前原片准备和结果采用。选择不提交，双击只提交一次，跨工作区迟到回执不发布；只读、过期、非活动、未知及待发布状态保留原保护。原登记文件回执不冒充已提取任务，不阻止当前原片的首次明确准备。

当前原声任务的状态核验改为实际登记文件 SHA 与冻结窗口，不再依赖候选采用后可能为 null 的初始镜头来源。复用同一次工作区读取已经完成的文件核验，不增加按镜头／历史窗口重复读取整片的开销；重试及采用仍重核验，不建立跨请求缓存。
