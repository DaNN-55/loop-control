## 输入与测量边界

使用真实 Owner HTTP、独立 PostgreSQL、实际文件、SDK HTTP 文档所有权和保存，以及本机真实导出／Worker 交付。无真实 Provider 或视频 API。各档串行独立运行；每档记录一次采集关闭时的实际修改保存、一次开启后的实际修改保存、一次内容不变保存及一次精确导出，不从单次差值推断长期性能。

耗时使用 `performance.now()` 包围实际命令。透明 `ffprobe` 包装器转发全部原参数与进程信号，单独计现有声音观察参数的调用数，并保留原始参数日志；其他探测不混入声音观察次数。没有使用磁盘读取系统追踪器；实际底层读盘量、磁盘缓存冷热、独占进程 CPU／峰值 RSS 为 unknown。主机负载、内存及现有 30 秒资源采样只作当时环境事实，包含其他进程。

声音事件逐实例核对：开启后的变化应产生 16／64 条 `sound_changed`，实例哈希唯一，不产生 `sound_unresolved`；内容不变保存不再探测或写事件。实际工程和 HTTP 下载成片分别核对 SHA 与字节数，实际解码成片，核验每个来源的频率振幅，不能以「有音轨」替代可听验证。导出开始／结束对账，重启后声音事实不变。交付通过真实 Worker 领取与执行，不代替原 attempt／lease 校验。
