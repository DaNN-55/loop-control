# 真实生产节点迁移验收

已完成用户确认的生产单详情迁移；保持未提交，未修改其他业务页面、数据库或 Worker。当前真实样本仍在 QC 审核，不推进状态。

## 交付范围

- 七节点可随时浏览，完成用绿色对勾、选择用蓝色下划线。切换仅改变视图，访问过的节点保留草稿。
- 左预览、右侧操作；文件点选在左侧展示并可返回节点资料。主脚本 Markdown 修订仅作用于待导入草稿，保存后重新确认；已确认的不可变版本保持原合同。
- 视觉参考与完整制作依据双页签。旧审核元数据不完整时，按审核包 artifact_id 读取登记产物，仍经 Owner 权限和 SHA 校验；不补造冻结元数据。
- 分镜显示真实冻结参考；缺少可预览图时明确提示。镜头轴位于预览下方，支持点击联动，结构拖动/插入进入现有原因填写和后台结构修订任务。
- 逐镜头保留原片、TTS、音效、字幕正文、人工时序、声音和构图、同步预览、确认、批量生成/失败重试、Studio 入口。冻结审核版本不被本地排序覆盖。
- 预渲染成员只展开当前项的证据；QC 问题优先在右侧，记录表单按需打开。历史 QC 不提供修改；最终成片重试限定原服务允许阶段。
- 交付左视频右封面，元信息在下，文件及原有交付表单在右侧；未到达交付时禁用。提交复用原载荷和校验，防重复提交，失败有明确反馈。
- 产物索引、审计和管理均保留，弹窗展示。浅深主题共用原 token；生产页只有抽屉这一处纵向滚动，镜头轴只有横向滚动。
