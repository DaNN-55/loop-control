# 自动校时移入分镜台

2026-11-12。按用户批准的方案实施。自动校时现在位于 **分镜台 → 字幕与口播 → 字幕**，跟随当前镜头；保留原生手工字幕和保存能力，清理剪辑台新增的两处自动校时入口与宿主侧栏。旧 SQL 基线、埋点、组件迁移和其他暂缓项未执行。

## 行为与边界

- 字幕正文下展示校时状态与操作，不再提供重复的字幕片段选择器。选中另一镜头时，使用该镜头自己的音轨、正文、任务和输入指纹。
- 字幕有未保存草稿、字幕关闭、音轨不可用或操作正在提交时禁用对应操作；不会自动请求、采用或重复提交。切换口播/字幕页签保留当前校时操作的恢复状态。
- 复用现有 3 秒读取节奏，增加当前校时任务的只读状态刷新；完成后显示“对齐完成，待采用”，失败保留详情及重试。采用前仍校验任务、音频/文本指纹、工程版本和 Owner 权限。
- 编辑器仍打开时，外部采用请求被原有后端保护拒绝，须先保存返回；字幕修改、原生 SQLite 工程和不可变保存版本仍经过现有权威链路。
- 删除 `LoopControlCaptionAlignment` 注入、宿主 captionEditor/侧栏/消息接点、专属面板布局和不再使用的独立 CSS。保留原生字幕面板、手工正文/时间编辑、通用 `apply-captions` 协议和 SDK flush 保存。
- 本轮只增加现有任务状态的读取字段，没有新增依赖或 SQL 迁移，也没有改数据库配置、并发或自动备份开关。
