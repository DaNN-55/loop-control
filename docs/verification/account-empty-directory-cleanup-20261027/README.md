# 账号永久删除清理空账号目录

2026-10-27。仅修改并部署功能，没有对现有账号或生产单发起删除。

## 行为与边界

账号数据库删除成功提交后，检查该账号全部蓝图记录中的资产根及其已登记媒体部署副本。只把事先确认为空、目录身份可核验且没有剩余账号蓝图引用的位置写入该请求的内部幂等回执，实际删除前再检查设备、节点身份和全账号引用。

仅使用非递归 `rmdir`；任何文件、隐藏文件、子目录或链接都会保留账号目录。目录或父路径为链接、位置被替换、外部盘未挂载、权限不足或引用检查不可用时保留，不追随链接、不删除媒体根和账号父容器。非空目录不会安排后续自动删除。全账号引用函数跨 RLS 检查剩余蓝图的相同、父子及部署别名路径，但只返回是否被引用，不返回其他账号资料。

只有数据库事务成功返回后才清理文件系统，事务失败不提前移除目录。公开响应仍是原布尔值。相同幂等请求重试仅尝试回执中的原空目录及原身份；旧布尔回执不追加目录，本轮不追溯清理已删除账号。后续目录清理失败不撤销或误报已提交的账号删除；不可清理的位置保留。

覆盖本机/已登记副本/旧蓝图空根删除；隐藏素材、空子目录、链接、原始素材和合成历史文件保留；其他 Owner 的共享目录保护；目录替换、新文件出现、权限故障后原请求重试、幂等响应及确认冲突；数据库删除后回执写入失败回滚时目录身份不变；账号仍有生产单时拒绝；Owner/CSRF/运行任务等原有边界不变。全部测试删除只涉及临时目录及一次性数据库。
