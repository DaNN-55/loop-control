## 手动检查

1. 刷新 http://127.0.0.1:5174，新建一条测试期，准备两镜本地图片，保留默认字幕。直接进入“检查与交付”导出，应无需先进入剪辑器空保存。
2. 在没有旧手填草稿的 5 秒镜头打开“视频”→“生成时长”，应显示 5 秒。仅检查数值即可，不必付费生成。
3. 给同一镜头添加 2～3 秒本地视频候选，预览后应显示“素材可用…短于当前镜头…”。点击“调整采用时长”，应直接展开时长选项；保留镜头时长时仍不能采用短素材。
4. 在测试期剪辑器拖开两镜之间的位置，保存返回后导出，应提示具体画面空档。合拢后重新检查；如同时修改了字幕或主声窗口，按提示重新校时。
5. 对已有未知调用查看展开的任务信息并点击“刷新核对结果”，应保留原任务和预算，不生成第二个请求。工作台中的当前失败或未解决问题应显示受阻，实际编辑后最近更新时间应变化。
