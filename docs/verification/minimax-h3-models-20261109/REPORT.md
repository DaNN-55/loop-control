## 可使用的功能

- 在原 MiniMax 连接下新增 `MiniMax-H3-Highspeed`、`MiniMax-H3-Lite`，复用同一不可变连接版本、Keychain 密钥与 `/v2/video_generation`，未创建或轮换连接。
- 两个新型号：480P／768P、4～15 整数秒、现有首帧／首尾帧／参考图片与视频模式。参数经过界面、确认、入队、Worker、网络准入到实际 API 请求；没有仅添加下拉名称。
- Lite 参考素材模式明确传入时间线对应的 16:9／9:16／1:1，避免供应商不支持的 `adaptive`。首帧／首尾帧继续按输入自适应。
- 增加实际可选分辨率，确认框和制作记录显示冻结规格；更新中国／国际站按型号、分辨率、参考视频时长及超额图片计算的费用。
- 原 H3 继续默认 768P，同时可选择已有官方支持的 2K。切换到新型号时不会携带不兼容的 2K。
- 音频参考、纯文本／单尾帧没有在本轮扩展，不把供应商全部能力冒充为现有 UI 已接入功能。

## 短候选处理

只对明确标记为候选的 MiniMax 工作区输出，保留合法 MP4 的实际时长，记录 3.75 秒而不伪装成 4 秒。该标记由受保护的 SQL 队列从 `origin=candidate` 写入冻结数据，Worker 不猜测提示词版本。首次自动填入与历史传统生产请求仍要求原完整时长；其他供应商校验不变。

新增真实 HTTP／Worker 回归，使用 3.75 秒文件和 4 秒目标镜头：结果能保留为候选；按“保持目标时长”采用被拒绝；原时间线不变。没有补帧、循环、变速或自动截断声音。
