### 尚存输出缺陷

已实际查看第二镜抽帧：图片上、下留空区域存在棋盘格。固定 SDK 的 `src/editor/TimelineComposition.tsx:28` 定义 `GRID`，第 298 行在 `transparent` 为 false 时仍将它作为根背景；`remotion/Root.tsx` 使用该组成画面。预览与正式渲染共用了装饰底色。
