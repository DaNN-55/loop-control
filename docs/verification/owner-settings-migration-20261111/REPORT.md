## 保留的操作

- 个人与界面、存储位置分组；通知按接收方式、提醒内容分组。保留真实保存、恢复默认、头像处理、素材迁移和日志存储状态。
- 连接列表直接显示更换密钥、测试。详情、新建和编辑在当前窗口中显示；模型、账务、版本与撤销保护保持真实功能。
- 连接详情可打开对应名称的密钥列表；密钥详情可返回当前连接。查看、复制仍需当前登录密码验证，离页立即清除敏感状态。
- 未保存的个人、安全、存储和账务输入需确认后离开；连接与模型继续使用原有草稿保护。切换设置不处理后台脚本或交付草稿。
- 模型与账务写入上抬 busy；写入期间阻止关闭或切页。持久化素材迁移仍可关闭后再查看，不全程锁住设置。
- 统一窗口负责焦点和 Escape。跨页触发按钮卸载后，将焦点交给目标页标题。长账户名称省略显示，悬停保留完整值。

验收期间修复了两个层级问题：密码页底部操作栏被公共样式的间距覆盖；设置层级过高导致离开确认窗及连接子窗被遮挡。最终浏览器实测确认窗可点击、继续编辑保留输入、放弃后完成跳转；模型窗口和菜单均显示在设置之上。

`regression-final.log` 保留 React Aria/JSDOM 账务关闭确认路径的非失败 act 提示，没有屏蔽日志。未运行整个仓库的默认套件；本次覆盖受影响设置、连接、导航、草稿、安全、日志和清理的测试。合成接口没有转发真实 API，不读取或修改真实密钥，不执行供应商测试或付费生成，不修改真实密码和存储位置。
