# 编辑器加载检查与布局方案（2026-11-19）

本轮按用户要求做加载检查和独立 HTML 骨架方案；正式产品只修改“镜头导航默认收起”。补充工具位置仍等待用户选方案，加载缓存架构也未直接改动或部署。当前日常编辑器保持运行，未导航、保存或改写用户正在编辑的工程。

## 当前加载路径

点击进入剪辑 → 核对当前工程/来源 → 保留原生工程和复制所需媒体 → 创建随机端口及本次 Vite 缓存 → 准备 Remotion 导出程序包 → 启动 Vite → 加载编辑器模块 → 原生写连接就绪。

当前已经做了：相同素材按实际字节跳过复制，保留预览/波形缓存；SDK 与宿主有 main.tsx / Editor.tsx 的启动预热；webpack 编译缓存有安全清理和容量保留。代码证据：`src/worker/openchatcutStudio.ts`、`scripts/openchatcut-embedded.mjs`、`scripts/openchatcut-cache.mjs`。

仍有机会：Vite 使用每次新建的临时缓存并在退出时清理；Remotion 导出程序包在编辑器服务开始监听之前准备。前者使不同次打开难复用前端编译结果；后者让用户先等一段导出准备工作才看到编辑器。

## 隔离实测

只用空白骨架工程、独立媒体根和随机项目身份，未连接正式业务数据库。SDK 源码只读，原生数据与 Vite 编译缓存均独立；日常编辑器继续运行。交替测试当前启动和“预先准备同一个导出程序包”实验，各三次；数值只代表服务就绪阶段，不包括业务核验、真实大素材或完整点击到可剪辑的总时间。

首次导出程序包预备约 1.67 秒。第一轮当前启动为 3.779 / 2.157 / 2.176 秒；预备后为 1.134 / 1.191 / 1.170 秒，中位数由约 2.176 降到 1.170 秒。首次当前样本含额外冷启动开销；两轮均保留真实安全校验，不跳过来源检查。

第二轮重新验证：当前启动为 2.993 / 1.916 / 1.891 秒，预备后为 1.179 / 1.167 / 1.178 秒，中位数由约 1.916 降到 1.178 秒。测试正常结束（1/1）。首轮测量完成后的浏览器驻留等待曾超时；已按 PID/项目身份关闭该独立进程，第二轮取消不必要驻留并完成清理。

Chrome DevTools 另检查独立编辑器：Vite 已热、禁用浏览器 HTTP 缓存时，三次播放工具栏出现约 1.232 / 1.445 / 1.224 秒；每次约 250 个资源请求，其中 239 个脚本，约 7.47 MiB 传输。它说明前端模块加载/执行仍有成本，不是正式生产单速度承诺。

程序预热和实际页面就绪是两个阶段，不能把两组时间直接当作全流程前后对比。精简测量回执见 `measurements.json`。

## 建议按收益顺序推进

1. **工作台启动后的空闲时段预备导出程序包。** 一次构建，多次编辑复用；按 SDK、宿主适配、依赖锁文件和运行时版本的内容指纹失效。后台工作失败时保留点击后的正常准备路径。现有 `CC_REMOTION_BUNDLE` 接点已用真实启动验证，适合作为第一步。
2. **把前端依赖编译缓存放进受限程序缓存目录。** 缓存与生产单工程、SQLite 和素材分开，只保留最近两个程序版本/明确容量；重开可复用编译结果。不能只按 mtime 判断有效，也不能无上限留住所有临时缓存。需要补失效、并发和清理验证后再实施。
3. **预热只准备程序，不提前打开正式生产单。** 工作台可见且空闲后触发，优先退出型预编译；是否常驻整个 Vite 服务要先实测内存与真实收益。进入某条生产单时仍重新核对当前文件、版本和权限。
4. **再测实际业务单的核验与媒体复制耗时。** 本轮小工程不覆盖大量视频；先加阶段计时，再决定是否需要调整文件校验或 I/O。当前按 SHA 保留素材副本的行为继续保留。

不建议一开始就隐藏 iframe 打开生产单：这会启动真实编辑会话和工程恢复，已经超出纯程序预缓存的含义。

## 四份独立骨架方案

目录：`.scratch/studio-tools-20261119/demos/`，没有进入产品构建或 Git 提交。

- A 右侧停靠：工具独立滚动，原生时间线高度保持；会占一点横向宽度。
- B 左侧覆盖抽屉：不改变工作区尺寸，临时遮住部分素材区。
- C 底部候选区：适合横向比较，多占一些高度。
- D 浮动工具窗：可拖动、缩放，尺寸不挤压编辑器；可能遮住画面。

每份 HTML 自带 CSS/JS，无外部库或真实编辑器依赖。可切换画面/声音/字幕、关闭重开和 Esc 关闭；D 可拖动及缩放。为了比较位置，demo 默认打开工具，正式版仍按需打开。已检查桌面与390px宽布局、关闭入口可达、Esc返回触发按钮和无横向溢出。确认后停止本轮静态服务器并整目录清理即可。
