# 剪辑台新增功能怎么测

适用：上一轮提交 fe68a376e，以及本轮镜头导航默认收起。请用一条测试生产单，准备两张图、带声音和无声的视频、两段口播、一个配乐 MP3。无需调用付费生成。

源码更新、构建检查和日常服务已加载新版是三件不同的事。上一轮未执行正式 212 迁移或重启日常服务；本轮也保留当前打开的编辑器。如果当前服务仍是旧版，先保存退出，再按日常更新流程应用迁移/运行包和重启，然后测试。

| 功能 | 怎么操作 | 应该看到什么 |
| --- | --- | --- |
| 镜头默认收起（本轮） | 进入编辑器，点左侧展开，再收起；退出后重新进入 | 初次进入是窄编号条，完整简介隐藏；可随时展开，定位仍可用；重新进入默认收起 |
| 保存不离开 | 调整一个片段位置，点“保存” | 留在编辑器，重新打开仍有这次调整 |
| 保存并返回 / 前往交付 | 分别使用两个入口 | 保存完成后才离开；失败时保留当前编辑器 |
| 回分镜修改后继续 | 返回分镜台换第二镜头图片，再进入剪辑 | 同一工程继续，第一镜已有剪辑保留，定位到刚改的镜头 |
| 编辑器内准备与采用 | 打开补充工具，上传图片/视频或 MP3；先预览，再明确采用 | 准备和试听不改时间线，明确采用才变化；采用后有正确的已采用状态 |
| 配乐 / 音效归属 | 分镜台打开音效，再去编辑器补充工具 | 分镜台准备镜头音效；整期配乐在编辑器准备，普通音量、淡入淡出、闪避仍直接使用原生控件 |
| 默认只替换选中片段 | 原生切开第一镜头，选其中一段，准备新视频并采用 | 默认范围是选中片段；另一段、第二镜头、口播和字幕保留 |
| 明确替换整条分镜 | 将替换范围切为整条分镜，核对影响再确认 | 第一镜的多个画面变成一个新片段；其他镜头、口播/字幕和独立音效保留，不自动把其他镜头挪动 |
| 绑定原声跟随画面 | 用新带声音视频替换，再用无声视频替换 | 关联原声使用新视频来源；无声时明确提示并移除旧绑定声音，独立口播仍保留 |
| 原生历史恢复 | 整条替换后，打开原生历史，恢复“替换整条分镜前”并保存 | 整个工程恢复到替换前；后续重新打开仍可读到旧素材 |
| 新口播重校字幕 | 保存前先给字幕改样式/位置，再采用另一段口播 | 跟随口播的正文与时间更新；独立正文保留；样式和位置保留。同文新声音也重校时 |
| 人工修改保护 | 自动校时等待期间手工改字幕句子时间，再等待旧任务返回 | 后来的自动结果不能覆盖这次人工修改 |
| 锁轨保护 | 锁定同一分镜中另一段所在的轨道，再尝试整条替换 | 清晰提示解锁，不出现替换了一半或提前创建恢复版本 |
| 拆分后连续保存 | 拆一个片段，保存；继续修改，再保存一次 | 两次都成功，不误报“工程身份或文件版本已变化” |
| 采用过程保护 | 开始上传/采用时立即尝试切工具、返回、点时间线 | 操作完成前关键入口不可用，完成后恢复；不会中途跳走造成半完成 |
| 最终交付 | 保存前往交付，导出、播放检查、确认成片与字幕，再生成交付包 | 技术检查通过，下载视频、ZIP 和可编辑工程都可打开 |

最快一轮：保存停留 → 返回修改再进入 → 上传配乐但先不采用 → 明确采用 → 拆分后局部替换 → 整条替换及恢复 → 连续保存 → 导出交付。

原生整轨字幕模板会覆盖同轨局部样式，保留正文、时间和位置；原生配乐闪避按主轨片段区间生效，片段内停顿也在区间内。这两项是复用原生行为，没有另做一套配置。
