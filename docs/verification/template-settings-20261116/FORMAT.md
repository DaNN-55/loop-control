# 模板配置与兼容约定


> 产物清理记录（2026-11-18）：本目录的历史测试生成附件已按用户要求清理；本文验收结论保留。源测试输入、恢复资料、生产单和数据库未删除。

本次扩展继续使用模板版本 `3`；既有 v2 脚本与 v1 原生渲染预填仍可读。新增原生渲染字段保存为 `workspace-render-preferences/v2`，未知版本/字段/效果明确报错。没有把 SDK 私有 shader、插件、特效、LUT 或连接字段开放给模板。

当前 v3 所有字段的已接入/仅保存/待补齐状态见 [字段接入清单](FIELD-STATUS.md)。解析器接受不代表当前制作选择或导出会自动采用。

## 缺省与优先级

- v3 可选字段省略、空值或 `默认` 都是不提供覆盖值；v2 专用字段在 v3 中即使填空值/默认也报错。v2 保留历史解析规则，新建/修订脚本仅接受 v3。
- 已填整片值先继承，再由已填镜头值覆盖；空镜头字段不会擦除整片值。
- `关闭` / `无` 是明确关闭；数值 `0` 保留，例如音量 0 dB、音效起点 0 秒、动画幅度 0%、转场时长 0 秒。缩放必须为 0.05～16，音效时长必须为 0.01～3600 秒，0 不在这些范围内。
- 初次组装写入字幕约束；初次采用占位素材写入缩放/动画/转场。后续打开、保存、替换素材以原生编辑为准，不重新套模板。不覆盖已交付工程。

## 新增字段

| 字段 | 支持值 | 行为 |
| --- | --- | --- |
| 缩放 | 0.05～16，1 为原比例 | 在明确选择的构图/fit 基础上乘以该倍率 |
| 动画 | 无 / 慢推 / 拉远，或 `none` / `slow-push` / `zoom-out` | 写入原生 zoom envelope；随片段当前实际时长播放 |
| 动画幅度（%） | 0～100 | 仅填写动画时生效；填写动画但没填幅度时使用 10% 的内置动作幅度 |
| 转场 | 硬切 / 关闭 / 无 → `cut`；轻推 / 推进转场 → `anticipation-zoom`；叠化 → `cross-dissolve`；淡出到黑 → `dip-to-black`；柔和擦除 → `soft-wipe` | `轻推` 是双输入原生推进转场，不是片段缩放。没有填写时新工程硬切 |
| 转场时长（秒） | 0～5 | 上述四种双输入原生转场使用该长度（旧 `fade` 仍为固定 0.35 秒）；未填时效果自身默认 0.35 秒；0 明确不加转场 |
| 转场方向 | 左 / 右 / 上 / 下，或 `left/right/up/down` | 传入原生转场的方向参数 |

原有 `fade` 保留片段首尾淡入淡出语义，不改成叠化；`studio` 保留原有工作台衔接语义。需要双画面叠化时写 `叠化` 或 `cross-dissolve`。旧审核渲染路径遇到新增缩放/动画/原生转场会明确要求使用当前工作区，不静默忽略。

转场填写在**进入该镜头的接缝**上。首镜没有进入接缝；整片值应用于后续镜头。相邻两段必须同轨且接缝准确，视频源必须具有所需前后余量；不足会阻断当前采用，不冻结首帧、不移动口播、不自动换效果。图片没有视频源帧余量限制。分屏/多个片段只在实际相邻的不同镜头边界建立转场，不给同一镜头内部片段自动加转场。

## 字幕与声音

字幕行数、每行字数、位置、安全区和开关在首次组装继承已填值。原生手工字幕使用显式换行/分页；字号边界计入 SDK 的 80% 容器宽度与文本盒内边距，避免一个 14 字逻辑行再次折行。

脚本音效起点/时长预填到镜头；只有用户明确选择/上传/准备/采用声音时才执行。已有候选和已采用人工时点不重置。自然速度播放，不因请求长度自动伸缩或循环；源音频过短明确报错。带脚本时序约束的音效区间还需落在实际镜头内。原有人工跨镜头声音编辑保持原语义。

所有位置按工程 fps 量化。30 fps 下 0.75 秒对应第 23 帧，即 0.766667 秒；正数子帧时长至少保留 1 帧，只有明确 0 的转场是硬切。对于实际采用了已填脚本时序音效的工程，平台最终 MP4 导出会使用同工程原生 WAV 音轨重新编码封装，消除 SDK H264/AAC 路径约 43 ms 的统一延迟；视频码流原样复制，音轨不挪动、不伸缩。未填项目保留原导出路径。实导六处 880 Hz 探针分别在 0.77/2.77/4.77…秒出现，每段 0.4 秒。此精度是帧网格及 10 ms 测量窗口，不能宣称任意秒数都是采样级精确。

SDK 独立编辑器自带导出尚保留其原 AAC 链路；平台的最终导出/交付才使用上述音频校正。独立工程用于继续编辑时，正式成片应走平台导出，不能把独立 SDK 的下载当作平台已确认交付。

```markdown
## 制作设置
- 模板版本：3
- 字幕最大行数：2
- 每行最大字数：14

## 正文
### 段落 01
- 口播：第一段。
- 画面来源：图片
- 音效起点（秒）：0
- 音效时长（秒）：0.4

### 段落 02
- 口播：第二段。
- 画面来源：图片
- 缩放：1.1
- 动画：慢推
- 动画幅度（%）：20
- 转场：轻推
- 转场时长（秒）：0.4
```

## 制作预填与素材引用

工作区读取其冻结的 v3 脚本，不使用后来未确认的新脚本。画面提示预填图片输入；视频提示词预填视频输入，省略时回落画面提示。浏览器已有人工草稿（包括主动清空）、已保存口播/音乐设置优先；打开或刷新不会重套已采用工程。口播音色/语速/语言须与实际模型兼容，未知值保留供人工修正，不静默替换。

素材名称、音乐、音效与封面按当前生产单最新素材名称/别名匹配，不跨生产单。文件名忽略常见媒体后缀并做 NFC 规范化；同名相同 SHA 合并，多个不同内容提示歧义。唯一匹配只预选候选，准备/采用仍显式执行；封面进入交付也重新核对 revision/SHA 并核验文件。音乐/音效“无”表示不建议候选，不清除既有轨道。

视频费用以分为单位预填本次确认弹窗，仍按实际模型费用范围校验；人工确认值优先并冻结到调用快照。模板不授权自动付费。

## v2 当前入口退役

新建/修订 v2 脚本和从 v2 新准备工程均明确要求改为 v3；不迁移或改写历史脚本、已保存计划、工程及交付。v3 不再接受“首帧素材、生成时长（秒）、视频生成提示词、镜头类型、视频模型”，首帧与模型在制作面板选择，其余分别使用“镜头时长（秒）”“视频提示词”和统一镜头。
