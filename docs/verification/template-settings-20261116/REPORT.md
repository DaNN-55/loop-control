## 已落地

- 当前 v3 首次组装继承字幕开关、行数、每行字数、位置、安全区；整片已填值不会被未填镜头字段擦除。实际复现并修复 14 → 16；实导又复现逻辑两行被 SDK 自动折成四行，已按原生容器及文本盒宽度修复字号边界。实际画面确认 2 行 × 14 字、1 行 × 10 字。
- 音效准备继承已填起点/时长，保留起点 0、音量 0 dB；用户仍明确选择、准备、试听并采用。已有人工编辑不重置，短音效不伸缩、不自动循环。脚本时序需符合实际镜头，既有人工跨镜头编辑语义保留。
- 首次采用素材时接入静态缩放、按当前片段真实时长播放的慢推/拉远；原生工程继续编辑后不重新套用模板。
- 基础原生转场：轻推 → `anticipation-zoom`、叠化 → `cross-dissolve`、淡出到黑 → `dip-to-black`、柔和擦除 → `soft-wipe`。检查实际同轨相邻关系及视频源余量，不换成片段 zoom、不移动口播。缺省硬切，明确 0 时长硬切，正数子帧至少 1 帧。
- 宿主补齐 SDK 的 GL 双输入转场构图：transform、关键帧、zoom、裁切及圆角进入预览和导出；原 SDK 安装源码未改。编辑器会话和平台导出均使用适配后的 Remotion bundle。
- 真实测得 SDK H264/AAC 音频统一晚约 43 ms，而同工程 WAV 对齐。平台针对已采用脚本时序音效的成片，流式导出同冻结工程 WAV，再复制原视频码流、单次 AAC 编码封装。没有硬编码偏移、移动音轨或改变音色。

字段、别名、时序和兼容边界见 [FORMAT.md](FORMAT.md)。v3 可选空字段/默认保持缺省；v2 原空字段规则和 v1 预填可读；新增预填使用 v2，未知值报错。完整模板常量包含可选的新字段；后续核对确认当前无界面下载入口引用该常量。实际“使用示例”入口已另行更新，逐字段状态与缺口见 [字段接入清单](FIELD-STATUS.md)。

## 必要边界

- 只给首次素材采用应用模板；已编辑/已交付工程不会因这次代码更新被批量重套。
- 视频原生转场需要前后源余量；没有前余量的源入点 0 会明确失败，需在原生剪辑中保留余量或明确改硬切。没有自动裁掉源开头或冻结首帧。
- 平台最终导出已校正上述 AAC 延迟；**SDK 独立编辑器自带下载仍沿用其原 AAC 链路**，不能替代平台最终确认和交付。
- 样片保留 `contain` 原画面；正方形产品图上下仍可看到 SDK 既有棋盘留边。这是既有背景问题，本次未扩展为背景修复或重新构图。
- 验收是帧网格/10 ms 声音测量及关键帧检查，不是全帧逐像素比较或真人口播听审。素材频率探针用于验证时点与自然速度，不代表语音质量验收。
- 原生转场 bundle 复用会话；时序校正增加一次仅音频导出和封装，WAV 流式落盘以限制内存。未测长期并发、GPU 峰值或大时长资源上限。
- 本次独立验收进程已关闭，临时数据库/源码副本及不再使用的派生缓存已清理；可编辑工程、独立素材、有效样片及复现证据保留。回执见 temporary-cleanup.json，重新打开使用上面的启动命令。
