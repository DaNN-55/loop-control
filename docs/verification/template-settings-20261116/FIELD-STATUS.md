# v3 模板字段接入清单

2026-11-16，按当前四步制作路径核对。**解析成功、保存到制作基准、预填制作选择、写入原生工程、最终导出是不同步骤。** 本文的“已生效”指已接到当前工程/采用路径，不表示写模板就会自动调用供应商或采用素材。

## 示例入口与使用方法

- 界面“使用示例”实际读取 `src/local-app/workspaceScriptInput.ts` 的 `workspaceScriptExample`，此前只有 118 字符的极简内容；现为三个镜头，展示继承、镜头覆盖、0 起点、动画与转场关闭、字幕关闭。
- `src/reviews/productionScript.ts` 的 `productionScriptTemplate` 是完整模板常量，目前没有生产界面的下载入口引用它。此前报告中的“下载模板已更新”表述不准确；实际入口和这份常量本次均已核对、更新。
- 示例包含已接入的执行和预填字段；音色、素材名称、封面与费用使用“默认”占位，可按实际需要填写。三个镜头都采用图片意图，避免示例的叠化要求视频源额外余量。
- 全局值先继承，再由镜头明确值覆盖；v3 可选字段省略、空值或 `默认` 不提供覆盖。`0`、关闭、无只在对应字段允许时才有效，例如音效起点可为 0，音效时长不能为 0。已保存或已编辑工程不会因示例更新而被重套。
- 在空脚本中点击“使用示例”取得新版；现有脚本/操作草稿不会自动替换。画面提示与视频提示词分别预填到生成输入框；已有人工草稿（含主动清空）优先。口播、配乐和音效仍需明确选择、生成/上传并采用。

## 32 个设置字段逐项核对

当前 30 项 v3 设置均已接入相应的初始化、预填或明确采用路径；另 2 项 v2 专用设置退出当前写入，保留历史读取。下面明确标出每项的执行条件，不把预填等同于自动生成或采用。

| 字段 | 当前状态 | 实际行为 / 还需补齐 |
| --- | --- | --- |
| 画幅 | 已接入 | `9:16` / `16:9` / `1:1`，创建 1080×1920 / 1920×1080 / 1080×1080 工程画布；只允许全局。 |
| 旁白音色 | 已接入预填 | 整片→镜头继承，预填口播音色；已保存设置优先。所选模型不支持该音色时明确提示并阻止保存/生成，须人工选择兼容值。 |
| 旁白语速 | 已接入预填 | 0.5～2 预填口播输入；镜头值覆盖整片。已保存值、人工草稿优先；按实际模型语速范围校验，不静默截断。 |
| 旁白语言 | 已接入预填 | 仅允许全局，预填可见的口播语言选择；与实际语音模型和音色共同校验。 |

| 每行最大字数 | 已接入 | 1～24，按实际字体盒宽度约束换行/分页；上一轮实导已验证 14 字与 10 字。 |

| 转场方向 | 已传入，有条件 | 左/右/上/下或 `left/right/up/down` 写入原生 TransitionItem；只对本身使用方向的效果有意义，不给叠化等无方向效果制造方向。四个方向未逐一实导复核。 |
| 缩放 | 已接入 | 0.05～16，首次采用素材时乘到构图倍率上，1 为原倍率。 |
| 动画 | 已接入 | 无/关闭→`none`、慢推→`slow-push`、拉远→`zoom-out`；首次采用写入原生 zoom，按当前片段时长播放。 |
| 动画幅度（%） | 已接入，有条件 | 0～100，需配合动画；仅填幅度不创建动画。已选动作且未填幅度时为 10%。 |
| 构图 | 已接入 | `full` / `2up-horizontal` / `2up-vertical` / `pip` / `grid-4`，创建对应占位片段与轨道；多槽位仍须逐个匹配素材。 |
| 旁白音量（dB） | 已接入，有采用条件 | -60～12，在采用 TTS 或原声时预填主声增益；不自动创建音轨，不覆盖已有人工混音。 |
| 音乐音量（dB） | 已接入，有采用条件 | -60～12，首次采用配乐使用；不同镜头的值可形成分段配乐，后续编辑优先。 |
| 音效音量（dB） | 已接入，有采用条件 | -60～12，首次采用音效使用；0 dB 不会被默认值覆盖。 |
| 音乐闪避 | 已接入，有采用条件 | `off/light/medium/strong`，首次采用音乐时写入 follower 音轨 ducking。仍需有可用的主声音轨。 |
| 背景音乐素材 | 已接入候选 | 按当前生产单最新素材名称/别名匹配音乐候选；唯一匹配预选，点击准备后仍须明确采用。无匹配/歧义会提示。“无”仅表示不建议候选，不删除已采用音乐。 |
| 音效素材 | 已接入候选 | 按当前生产单名称/别名解析并预选，整片→镜头继承；准备与采用仍显式进行，采用时使用已接入的音效时点、时长和音量。 |

## SDK 有能力但模板尚无字段

下列内容目前不在解析器白名单中，填写相应自造字段会报“未知字段”，不能承诺通过模板执行：

- LUT、滤镜、GL 特效、自定义 shader、任意插件 ID。
- 旋转、平移、裁切、透明度、任意关键帧曲线、变速；当前模板的缩放与两个 zoom 动作只覆盖其中很小一部分。
- 帧率、画面背景/留边、生成模型/分辨率/画质/数量、完整音轨路由、音乐或音效总开关。

这些能力的编辑器操作或制作面板功能，与“模板已接入”是两回事。

## 当前仍未执行的内容

- “首帧要求、制作备注、必须出现、禁止出现”仍是备注，不会自动拼入生成请求，也没有成为结果强制检查。
- LUT、滤镜、特效和上面列出的 SDK 扩展能力，仍未开放模板字段。
- 素材引用范围仅当前生产单，不跨账号/系列猜测；同名不同内容必须人工选择。同名相同 SHA 合并为一个候选。音乐“无”不等于切换现有工程音乐开关。
- 模板不自动选择生成连接、不自动付费、不自动采用素材；人工修改、已采用工程和历史交付优先。
