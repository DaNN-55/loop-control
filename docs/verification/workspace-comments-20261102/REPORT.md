## 现有入口的实际意义

1. “添加本期素材”：从已导入本期的图片／视频登记为当前目标的候选，不再上传文件，也不自动采用。
2. 下方“上传素材”：从电脑导入新文件，再加入当前目标的候选，仍须明确采用。
3. “用作视频首帧”：把候选图片的素材 ID 填入视频生成草稿，切到视频／AI 生成页；不会提交生成、扣费或替换当前时间线。
4. “本期在线制作”：按生产单和脚本版本保存在线制作授权。供图片／视频生成、口播及在线声音检索等请求检查；与连接凭据是否已验证是不同状态。上传和本地编辑不需要这项在线授权，点击授权本身不会生成内容。
5. 已完成工程目前由前后端同时禁止写入：前端 ProductionWorkspacePanel 的 readOnly 与后端 ProductionWorkspaceCommands 的完成态检查一致。若要续剪，建议单独提供“继续修改”：建立新修订、保留旧交付，修改后重新检查和确认。这项业务变化待用户确认，本轮未实施。

## 图片生成配置建议（待确认）

当前真实请求只开放 size、quality、count；参考图另传入，输出固定 PNG，服务端也严格校验 PNG。界面的“画面比例”实际上对应固定像素尺寸，例如 9:16 使用 864×1536。

| 优先级 | 建议 | 后续影响与边界 |
| --- | --- | --- |
| P1 | 分开显示比例与实际像素，提供符合所选模型限制的标准／高清档，按最终画布预填 | 当前竖图 864×1536 用于 1080×1920 成片时需要放大；分辨率会影响清晰度、费用和生成耗时 |
| P2 | 为参考图补充用途和保留要求：角色、产品、风格、构图；明确哪些内容可变 | 影响跨镜头人物和产品一致性；这是提示词组织，不承诺模型一定遵循，也不伪装成数值权重参数 |
| P3 | 构图与字幕留白预设：主体完整、预留字幕区域、允许的画面裁切 | 减少后期裁切主体或字幕遮挡；构图要求进入提示词，采用阶段仍由实际构图／填充方式控制 |
| P4（按需） | 背景：普通画面／透明素材 | 对产品抠图、贴纸、叠加图有意义；gpt-image-2 的透明背景仍标为 preview，不默认开启 |
| P5（低优先级） | 输出格式、压缩程度 | 目前 PNG 已适合制作；若增加 JPEG/WebP，要同时调整服务端文件签名、候选与交付处理，不只是加下拉框 |

建议优先 P1–P3，P4／P5 放高级设置。静帧／轻微推拉、视频使用区间及目标时长处理已在候选“使用设置”中，不重复增加相同字段。暂不新增 seed、采样步数、参考强度等未经当前服务适配的控件；gpt-image-2 输入图已按高保真处理，无需再加 input_fidelity 开关。

官方依据：

- [图片生成参数](https://developers.openai.com/api/reference/resources/images/methods/generate)：实际像素、格式、压缩及模型相关约束；gpt-image-2 透明背景支持处于 preview。
- [GPT Image 2](https://developers.openai.com/api/docs/models/gpt-image-2)：所选模型能力。
- [图片提示指南](https://developers.openai.com/api/docs/guides/image-prompting)：gpt-image-2 的输入图默认高保真，应省略 input_fidelity。

以上为结合项目代码的产品建议，本轮没有提交生成或验证新增参数的真实收费请求。
