## 预算含义

账号生成预算是应用内该内容账号多个生产单共用的额度授权，不是供应商账户余额。总额度约束图片、视频和口播等受管理的生成请求及预留；试片额度主要约束视频试片阶段，允许使用完整额度后视频可使用剩余总额度。预算字段单位为分，100 分等于 1 元；本次费用预留字段单位为元，表示当前请求占用的应用内额度，并非供应商实际账单。保存预算不充值，也不提交生成。

上述含义已根据当前 Owner 预算命令、图片／视频／口播入队及 Worker 预留校验核对；本次未调整这些服务端逻辑。
