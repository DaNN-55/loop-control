## 怎么操作，预期看到什么

样例执行成功会消耗对应样例，不会自动重新制造失败；当前剩余任务以实际列表为准。

1. 打开隔离链接，看到「恢复未提交删除核对」与「继续文件清理核对」两个任务。关闭后，可从右上角所有者菜单→文件清理再次进入；生产单筛选保持。
2. 第一项点击「恢复文件」：应提示未提交的删除已恢复，该任务从列表消失；生产单记录仍在，文件恢复到原位置。后续若要删除，必须重新核对范围。
3. 第二项点击「继续清理」：应提示文件清理已完成，该任务消失；生产单记录不会被恢复。只清理原已确认文件，样例中「手放保留.txt」仍保留。
4. 核对失败提示：关闭弹窗，在生产单列表找到「清理未完成提示核对」，行尾更多→永久删除；如提示归档，选择「归档并继续」，输入完整名称并确认永久删除。样例首次清理会模拟文件占用一次：记录已删除，但出现清理未完成提示。
5. 点击提示的「查看清理任务」：应定位该任务，显示「示例文件暂时被占用，请重试文件清理。」刷新页面后仍显示此任务与错误；点击「继续清理」后应成功并移除任务，只处理这项任务。此故障注入仅存在于隔离预览fixture。
