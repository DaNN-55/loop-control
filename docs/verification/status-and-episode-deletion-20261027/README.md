# 状态自动读取与归档生产单永久删除验收

2026-10-27。Owner 授权实现功能；本轮不删除现有业务数据，不启用备份或快照，不调用 Provider，不提交或推送。

## 实现

- 系统状态在页面加载时自动读取，打开面板和手动刷新仍会重新读取；读取中打开不重复发请求，卸载后的旧结果不回填。
- 已关闭的完整备份与未启用的部分快照保持中性颜色，分别显示「已关闭」「未启用」；没有检查结果显示「尚未执行」。旧备份或快照记录不覆盖关闭状态。
- 已归档的普通生产单和测试生产单均显示「永久删除」。前后端和数据库取消测试标记要求，保留归档、Owner、会话、CSRF、确认文本、路径与版本、运行任务、有效资产锁、并发任务锁、目录暂存、失败恢复及清理重试。
- 账号仍要求所有关联生产单归零；提示现在说明先清理生产单，或归档账号保留历史。
- 新增前向迁移 068，仅替换三个函数；公共删除函数相对 034 仅移除测试标记条件，关联清理正文逐字比对一致。未修改历史迁移。

## 验证

- 59 项聚焦回归通过：LocalSystemStatus、LocalCatalogApp 工作区/会话/账号、AccountWorkspace、目录删除。
- 独立空数据库仅复制当前 schema，使用合成 Owner、普通生产单、任务、产物、审计记录和临时媒体文件。真实 loop_app/Owner HTTP 验证：未归档拒绝；缺 CSRF 和跨 Owner 拒绝；错误标题/路径/版本拒绝；运行任务、有效资产锁、并发任务锁拒绝；数据库失败恢复目录；成功删除任务/产物/审计与目录；相同幂等键返回同一结果；无关文件与其他 Owner 生产单保留；最后一个生产单删除后账号删除成功。该集成用例通过。另一个独立旧账号删除用例未开启 opt-in，不计为本次通过。
- 前端类型检查、本地后端编译、Worker/编排构建及源码摘要检查、原生 Vite 构建、受影响差异空白检查、修改过的验收脚本语法检查通过。Vite 保留大分块提示，无构建失败。
- 原来交付脚本中「普通单删除应拒绝」断言同步为「归档普通单可删除」；未运行完整旧交付生产验收脚本。
- 真实应用新标签页在点击状态按钮前已显示正常、已关闭、未启用；归档筛选中的普通生产单菜单可打开删除确认，错误确认文本保持禁用。只关闭弹窗，没有点击确认删除。原用户标签页未用于这些验证。

## 运行与数据

仅应用 068 迁移并登记 SHA256，正常 stop/start 加载新后端。迁移前、迁移后、服务重载和界面验证后的账号与生产单 ID 摘要完全相同（全库 10 个账号、16 个生产单，含其他 Owner 验收夹具）；详情见 migration.json。没有删除任何现有账号或生产单。

所有删除验收均在新建临时数据库和临时媒体目录完成；验收后已清理。本轮初次隔离连接因管道缺少 ref/unref 超时，补齐后发现合成会话缺 credentials 外键前置条件；补齐真实依赖后默认 30 秒内通过，未增加超时或放宽断言。首轮遗留临时数据库与空目录已清理。
