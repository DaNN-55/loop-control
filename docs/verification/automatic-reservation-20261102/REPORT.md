# 自动费用预留验收

日期：2026-11-02。已应用本地 5174 服务，未提交或推送。

## 已完成

生成表单不再要求手填费用。点击图片、视频或口播生成时，服务端根据当次选择自动计算建议值，确认框允许调整人民币金额，保留原最低预留和 1000 元单次上限。在线音效继续预留 0 元，金额不可修改；上传和采用已有素材维持原流程。

估算使用实际供应商请求时长，包括主声窗口驱动的取整和模型允许时长，不用画面上的目标秒数直接代替计费秒数。万相还区分模型、分辨率和声音；图片计入数量、像素、质量与参考图，自动质量按高质量保守估算。

建议值在费用估算上加 20% 余量，向上取整到分，并满足现有最低预留。口播仍保留每字符至少 1 分的系统限制，此限制独立于供应商按量价格。美元按 1 USD = 7.2 CNY 的规划假设折算，界面明确说明，不宣称实时汇率。

确认接口仅增加可选的 `reservationCents`。金额必须是合法整数分，非数字、空值、低于最低预留和超出上限均拒绝；模型、素材、正文仍不可在确认时替换。校验后同一事务保存最终金额和授权摘要、消费一次确认、创建实际任务；Worker 使用最终冻结金额。并发、幂等、过期、租约和未知提交保护继续生效。无需数据库迁移。

价格表随应用版本保存；当前不后台刷新价格。确认框提供官方说明链接。自动估算是预算辅助，不是供应商报价或保证实际费用不超过预留。
