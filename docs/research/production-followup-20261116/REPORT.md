## 3. 模板配置

**可以扩展。** 建议“整片默认＋镜头覆盖＋工作台手动修改优先”；按实际片长换算关键帧，避免 TTS 变长后动效时间跑偏。

- 首批：音效素材／音量／偏移、基本缩放与位移、基础转场预设。
- 后续：动画、FX、LUT 使用版本化预设库和稳定素材引用，限定范围；不让模板直接承载任意 shader 或 SDK 内部 JSON。
- 已安装 SDK 支持大部分能力，但当前项目模板与原生工程的适配尚不完整。本次每行 14 字曾落成默认 16、音效偏移需手调；必须补“写入→回读→重开→渲染”的验证，再承诺自动应用。

例如可规划“日照金山 v1”：轻推近 100%→106%、完整保留挂轴、硬切、固定音效偏移、可选暖色 LUT；这是未来预设建议，**不是当前模板已支持的新字段**。[实际 SDK 核查与建议](template.md)。

## 4. Freesound 与免费兜底

三次均卡在搜索后的预览下载：1 次 122.368 秒超时（当前 deadline 为 120 秒），另两次约 4／5 秒中断。没有底层错误码，不能断言具体是代理、DNS 或 CDN。

已找到并实测 **Openverse 音频搜索＋`wikimedia_audio` 来源＋CC0**：搜索成功，Wikimedia 原站小范围下载 HTTP 206。它是免费候选检索，不是免费 AI 生成；还需完整文件、时长和许可校验后采用。Openverse 若仍返回 Freesound 源，就不能解决同一 CDN 故障。

建议兜底顺序：已许可本地库 → 非故障来源的 Openverse/Wikimedia 候选 → 提示人工选取。Freesound 官方免费 API 仅限非商业用途，不能因素材为 CC0 就把 API 当商业免费源。[Freesound 官方条款](https://freesound.org/docs/api/terms_of_use.html)、[Openverse 官方 API](https://api.openverse.org/v1/)、[失败与下载探针](freesound.md)。本轮未接入新适配器或自动替换素材。
