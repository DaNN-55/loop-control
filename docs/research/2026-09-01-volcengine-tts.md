## 结论

给 `01-电脑体检打假` 这类单人、约 40 秒的短视频配音，适合先用 **豆包语音的「语音合成大模型」公版音色**，而不是声音复刻或双人播客。官方把该能力列为短视频/广告场景，并说明它会依上下文预测情绪和语调；产品页展示的公版试听音色有“小何 2.0、Vivi 2.0、小天 2.0、云舟 2.0”。“哪一个最好”没有官方排序，必须在控制台用同一段口播试听后再定。

对于这条中文实测视频，先从沉稳的男声（如云舟 2.0 / 小天 2.0）或自然女声（如 Vivi 2.0 / 小何 2.0）各导出一版即可；这是基于视频“如实测试”语气的制作判断，不是官方效果承诺。

## 接入方式

最小接入路径：在 [豆包语音控制台](https://console.volcengine.com/speech/app) 创建语音技术应用、完成实名并开通所需服务，取得 `appid` 和 `access_token`，选择一个公版 `voice_type` 后调用 V3 单向流式接口输出音频。官方 V3 API 列表推荐大模型音色使用 V3，称其时延表现更好。

| 需求 | 官方接口 | 适合度 |
| --- | --- | --- |
| 这条脚本一次性生成成品 | `https://openspeech.bytedance.com/api/v3/tts/unidirectional`（HTTP Chunked）或 `wss://openspeech.bytedance.com/api/v3/tts/unidirectional/stream` | 推荐。整段脚本一次提交，流式拿到音频。 |
| LLM 边写边播 | `wss://openspeech.bytedance.com/api/v3/tts/bidirection` | 当前不需要。 |
| 浏览器消费流 | `https://openspeech.bytedance.com/api/v3/tts/unidirectional/sse` | 当前不需要。 |

接口和鉴权依据：

- [语音合成大模型 API 列表](https://www.volcengine.com/docs/6561/2228192?lang=zh) 列出上述 V3 WebSocket、HTTP Chunked 和 SSE 地址，并说明大模型音色推荐 V3；最近更新时间 **2026-04-14 17:59:24**。
- [鉴权方法](https://www.volcengine.com/docs/6561/1105162?lang=zh) 说明 `appid`、`access_token`、`secret_key` 在控制台创建应用后获得，支持 Bearer Token 或 HMAC256；最近更新时间以页面实时显示为准（本次检索结果未返回该字段）。
- [控制台快速入门（旧版）](https://www.volcengine.com/docs/6561/163043?lang=zh) 说明在服务详情开启试用；最近更新时间 **2025-12-09**。

## 对 tk-workflow 的最小建议

1. 先在控制台试四个公版音色，每个只合成开头 2 句；人耳选定一个后再生成全稿。
2. 调用 V3 单向流式接口，把生成的 mp3/ogg/pcm 作为旁白输入；不要接声音复刻、播客或实时双向接口。
3. 保存 `voice_type`、完整文案、生成日期、请求字符数和账单截图；这足以复现一次配音和核账。
