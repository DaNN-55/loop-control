# 日志隔离预览

在项目根目录启动：

```sh
npm exec vite -- --config src/local-app/logs.prototype.config.mjs
```

访问 <http://127.0.0.1:5199/src/local-app/logs.prototype.html>。停止时在启动终端按 `Ctrl+C`。

本页沿用当前 `--lc-*` 主题、Button、NativeSelect 和品牌标记。仅一个已确认的布局；深浅色切换、筛选、展开与同次操作上下文只保存在当前页面内存，刷新恢复初始状态。

模拟数据包含上传、启动和上传失败，另有独立的真实历史日志副本。通过 `episode + operationId` 关联同一次操作；`requestId` 继续区分入口请求与后台处理请求；查看上下文时临时忽略原筛选，返回后恢复。选中记录的中文说明和原始 JSON 同步展开。生产单名称和编号分列。

入口独立于 `main.tsx`，不连接 API、数据库或外部供应商，不修改主程序导航，也没有全局 fetch 替换。正式应用入口不引用这些文件，主程序构建不打包此页；不安装新依赖。

已确认的演示规则：每次操作独立 `operationId`；自动尝试用 `attempt` 标记。新增的后台开始记录使用不同 `requestId`，仍属于 OP-002，保留任务编号 TASK-001。仅表示已开始，不表示制作完成。

原始日志标注「已脱敏」。固定示例数据在进入页面前就不含凭据或正文原值，上传示例以 `[未记录]` 标记，保存路径为生产单内相对路径；没有先存秘密再用界面遮盖。此页未实现或接入生产日志采集／脱敏管线。

保留规则示例为 14 天／1 GB：关键开始、结果和异常一起保留，不逐函数记录；优先整组清理较早已结束操作。时间范围中的「2026-10-22 · 已过期示例」只展示过期状态，不保留或伪造历史日志；过期不能推断为没有执行或没有错误。页面不执行文件删除、自动过期或实际容量限制。业务记录、素材、快照和回执不在日志清理范围。

未来接入前需核对真实操作关联、异步传递、采集端字段白名单和容量清理边界；另外决定实时更新时的阅读位置。业务未记录的信息不能由界面推断为事实。本页不代表已完成日志采集。

本轮已验证：生产单与时间组合、错误筛选、无结果、时间边界与非法范围、同操作隔离与返回恢复、共享下拉实际选择、单条双栏同步展开。浏览器尺寸 1440／1024／375／320px，深浅色、无横向溢出；未观察到运行错误、业务 API 或外部资源请求。独立入口依赖树 TypeScript 检查通过。全项目类型检查当次被并行任务测试中的未使用导入阻断，不能视为全项目通过。
